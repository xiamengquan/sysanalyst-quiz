# 第5章 数据库系统 ★高频

> 出自《系统分析师教程》知识点精炼 · 第一篇 · 基础知识（第1—9章）分章。

## 本章考什么

三级模式、关系代数/规范化、事务ACID与并发控制、**数据库安全（标识鉴别/授权粒度/视图/审计vs跟踪/备份分类）**、ER模型、分布式数据库、数据仓库/OLAP/挖掘、NoSQL。综合题与选择题均高频。

## 核心知识点/概念

### DBMS与三级模式

```
外模式(用户视图/子模式) ←→ 模式(逻辑/概念模式) ←→ 内模式(存储模式)
         ↑ 外/模式映像              ↑ 模式/内映像
```

- **两级独立性**：逻辑独立性（模式改变不影响外模式）、物理独立性（内模式改变不影响模式）。
- **数据模型**：概念(ER)、逻辑(关系/网状/层次)、物理。

### 关系数据库

**基本概念**：关系、元组、属性、域、码(候选码/主码/外码)、主属性/非主属性。

**完整性**：

| 类型 | 含义 |
|------|------|
| 实体完整性 | 主码非空且唯一 |
| 参照完整性 | 外码要么为空，要么引用存在的主码 |
| 用户定义完整性 | 业务规则约束 |

**关系运算**：并、差、交、笛卡儿积、选择(σ)、投影(π)、连接(⋈)、除。

**规范化**：

| 范式 | 要求 |
|------|------|
| 1NF | 属性不可再分 |
| 2NF | 1NF + 消除非主属性对码的部分函数依赖 |
| 3NF | 2NF + 消除非主属性对码的传递函数依赖 |
| BCNF | 每个决定因素都是候选码 |
| 4NF | 消除多值依赖 |

**异常**：数据冗余、修改异常、插入异常、删除异常。

### 并发控制

**事务ACID**：

| 特性 | 含义 |
|------|------|
| Atomicity | 原子性，全做或全不做 |
| Consistency | 一致性 |
| Isolation | 隔离性 |
| Durability | 持久性 |

**并发问题**：丢失修改、读脏数据、不可重复读。

**封锁**：X锁(排他)、S锁(共享)；**两段锁协议(2PL)** 保证可串行化。

**封锁协议**：一级(改X锁)、二级(读S锁+改X锁，避免脏读)、三级(读S锁到结束，避免不可重复读)。

**隔离级别**：读未提交、读已提交、可重复读、串行化。

### 数据库安全性 ★必考

**两层实现**：DBMS自身措施 + 应用程序控制。

| 措施 | 说明 |
|------|------|
| **用户标识和鉴别** | 最外层保护；口令认证、强身份认证(数字证书/智能卡/指纹等) |
| **存取控制(数据授权)** | 按角色授权；操作类型+数据对象 |
| **密码存储和传输** | 远程终端加密传输 |
| **视图保护** | 通过视图授权，隐藏敏感数据 |
| **审计** | 事后监督，日志长期保存作证据 |

**权限角色三类**：数据库登录权限类、资源管理权限类、DBA权限类。

**授权粒度（由大到小4级）**：**数据库级 → 关系级(表) → 元组级(行) → 属性级(列)**。

**视图**：

- 虚拟关系，存储SELECT语句而非数据本身。
- 作用：简化查询、逻辑独立、**安全控制(限制用户可见列/行)**。

**审计 vs 跟踪**：

| 对比项 | 审计 | 跟踪 |
|--------|------|------|
| 目的 | 安全检查、稽查证据 | 系统调试分析 |
| 保存 | 长期保存日志 | 通常不长久保存 |
| 时机 | 事后监督 | 开发/调试阶段 |
| 与认证关系 | 认证=事前防范 | — |

### 备份与恢复 ★必考

**按实现方式**：

| 类型 | 子类 | 说明 |
|------|------|------|
| **物理备份** | 冷备份(静态) | 关闭DB，复制文件；最快最安全，备份期间不可用 |
| | 热备份(动态) | 运行中备份；可用但需日志配合 |
| **逻辑备份** | — | exp/imp等工具；适合小库，大库慢 |

**按数据量**：

| 类型 | 备份内容 |
|------|---------|
| **完全备份** | 整个数据库 |
| **增量备份** | 上次任意备份后变化的数据 |
| **差异备份** | 上次完全备份后变化的所有数据 |

**组合策略**：通常1次完全 + 多次增量/差异。

**日志文件**：记录每次更新；热备份必须配合日志；恢复时 Redo(重做已提交) + Undo(撤销未完成)。

**故障恢复**：

| 故障类型 | 恢复方法 |
|---------|---------|
| 事务故障 | 撤销(Rollback) |
| 系统故障 | 日志Redo/Undo |
| 介质故障 | 后援副本+日志 |

### 数据库设计

**6阶段**：需求分析 → 概念设计(ER) → 逻辑设计 → 物理设计 → 实现 → 运行维护。

**ER模型**：实体、属性、联系(1:1/1:n/m:n)；冲突(属性/命名/结构)；集成(一次/逐步)。

**ER转关系规则**：

- 实体→关系；1:1可合并；1:n合并到n端或独立；m:n→独立关系+两端主码。

### 分布式数据库

- **分片**：水平(行)、垂直(列)；完备性、重构性、不相交性。
- **复制**：提高可用性和性能。
- **透明性**：分片、位置、局部、重复、事务。

### 数据仓库与OLAP

- **数据仓库**：面向主题、集成、相对稳定、反映历史变化。
- **OLTP vs OLAP**：操作型(事务) vs 分析型(决策)。
- **OLAP操作**：钻取、切片、切块、旋转。
- **数据仓库结构**：源数据层、数据存储层、OLAP引擎、前端。

### 数据挖掘

- **任务**：分类、聚类、关联规则、序列模式、偏差检测。
- **方法**：统计、机器学习、神经网络、遗传算法、模糊集。

### 非关系数据库(NoSQL)

| 类型 | 特点 | 代表 |
|------|------|------|
| 列数据库 | 列存储，分析型 | HBase |
| 文档数据库 | JSON/BSON | MongoDB |
| 键值数据库 | 简单KV，高性能 | Redis |
| 图数据库 | 关系网络 | Neo4j |

- **CAP定理**：一致性(C)、可用性(A)、分区容错(P)，最多同时满足两个。

## 易混对比

| 对比项 | 逻辑独立性 | 物理独立性 |
|--------|-----------|-----------|
| 改变 | 模式 | 内模式 |
| 不影响 | 外模式/应用程序 | 模式/应用程序 |

| 对比项 | 2NF | 3NF | BCNF |
|--------|-----|-----|------|
| 消除 | 部分函数依赖 | 传递函数依赖 | 所有非候选决定因素 |
| 强度 | 弱 | 中 | 强 |

| 对比项 | 完全备份 | 增量备份 | 差异备份 |
|--------|---------|---------|---------|
| 备份量 | 最大 | 最小 | 中等 |
| 基准 | — | 上次任意备份 | 上次完全备份 |
| 恢复速度 | 快 | 慢(需链式) | 较快 |

| 对比项 | 冷备份 | 热备份 |
|--------|--------|--------|
| DB状态 | 关闭 | 运行中 |
| 速度 | 最快 | 较快 |
| 可用性 | 备份期间不可用 | 仍可用 |
| 日志 | 可选 | 必须 |

| 对比项 | OLTP | OLAP |
|--------|------|------|
| 目的 | 日常事务 | 决策分析 |
| 数据 | 当前、细节 | 历史、汇总 |
| 操作 | 增删改查 | 多维分析 |

| 对比项 | X锁 | S锁 |
|--------|-----|-----|
| 读 | 不允许其他读/写 | 允许多读 |
| 写 | 独占 | 需升级为X锁 |

| 对比项 | 视图 | 基本表 |
|--------|------|--------|
| 存储 | SELECT语句 | 实际数据 |
| 更新 | 有限制 | 完全 |
| 安全 | 可隐藏列/行 | — |

## 常考数字/结论/口诀

- 授权粒度：**库→表→行→列**（4级，由大到小）。
- 审计=**事后**；标识鉴别=**事前**。
- ACID：**原一隔持**。
- 范式递进：**1→2→3→BCNF→4NF**。
- 备份口诀：**物逻分，冷热全增异**。
- 增量备份基于"上次任意备份"，差异备份基于"上次完全备份"（易混！）。

## 应试钩子

**案例可能怎么问**：给定业务表与函数依赖，要求判断范式级别并分解至 3NF/BCNF；或给出并发/死锁场景，选隔离级别与加锁策略；备份恢复题常考「完全+增量/差异」组合与 RPO 对应关系。

**论文怎么用**：数据迁移/多源集成类（23上、24上）可写「源库→中间层→目标库」割接步骤、一致性校验与回滚；OLTP/OLAP 分离、读写分离、缓存与索引优化可作为性能段落素材。
