## 概述

**成本效益分析（NPV、回收期）** 属本科目大纲考点。常考：**NPV / 回收期 / ROI / 盈亏平衡**  ·  计算题必考。

## 定义

- **成本效益分析**是对拟建系统比较成本与收益（如 NPV、投资回收期）以支持立项决策的方法；**用于**可行性研究与规划阶段比选方案。
- **成本效益分析（NPV、回收期）**是考纲规定的知识范围；**用于**选择题、案例或论文中的相关论述。核心要点：NPV = Σ(CI - CO)ₜ / (1 + i)ᵗ 多方案比较：投资额、时间相同 → NPV 越大越好。 内部报酬率 IRR：使 NPV = 0 的折现率 i。 折现率影响：i 越高 → NPV 越小 → 越难通过评价。

## 要点

### 6.5 净现值 NPV

```
NPV = Σ(CI - CO)ₜ / (1 + i)ᵗ
```

| NPV 值 | 含义 |
|--------|------|
| = 0 | 达到基准收益率 |
| > 0 | 可行，有超额收益 |
| < 0 | 不可行 |

**多方案比较**：投资额、时间相同 → **NPV 越大越好**。

**内部报酬率 IRR**：使 NPV = 0 的折现率 i。

**折现率影响**：i 越高 → NPV 越小 → 越难通过评价。
