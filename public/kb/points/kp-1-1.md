## 核心知识点/概念

### 计算机系统层次

```
应用层：应用软件
系统层：OS、语言处理程序（编译/汇编/解释）
硬件层：传统机器级 → 微程序级 → 硬联逻辑级
```

- **冯·诺依曼**：运算器、控制器、存储器、输入、输出；存储程序。
- **软件分类**：系统软件（OS、语言处理、服务程序、DBMS、网络软件）、应用软件。
- **固件(firmware)**：EPROM/EEPROM中程序，性能介于软硬件之间。

### 存储器系统

**三级结构**：Cache → 主存 → 辅存。

**存取方式**：顺序、直接、随机、相联。

**主存**：RAM(DRAM需刷新/SRAM不需)、ROM(BIOS)。

**辅存**：磁带(顺序)、硬盘(HDD/SSD/SSHD)、RAID、光盘(CD-ROM/CD-R/CD-RW/DVD)。

**硬盘**：寻道时间 + 等待时间 + 读写时间；Ta≈Ts+Tw。

**RAID级别**：

| 级别 | 特点 |
|------|------|
| RAID0 | 无冗余，性能最高，故障率高 |
| RAID1 | 镜像，50%利用率，安全性最高 |
| RAID2 | 海明码，少用 |
| RAID3/4 | 独立校验盘，位/块交叉 |
| RAID5 | 分布式校验，无独立校验盘 |
| RAID6 | 双分布式校验 |
| RAID10 | RAID0+1组合 |

- 依据：**程序局部性**（时间局部性、空间局部性）。
- 平均周期：**t3 = tc×h + tm×(1-h)**（h为命中率）。
- 映射：直接映射(K=I mod C)、全相联、组相联。
- 替换：随机、FIFO、LRU。
- 写策略：写直达(Write Through)、写回(Write Back)、标记法。

**网络存储**：

| 类型 | 特点 |
|------|------|
| DAS | 直连，扩展差，已基本被NAS替代 |
| NAS | 文件级，NFS/CIFS，小文件共享 |
| SAN | 块级，FC SAN/IP SAN(iSCSI)/IB SAN |

- 实现层次：对称式/非对称式；数据块虚拟/虚拟文件系统；主机级/设备级/网络级实现。

### I/O系统

**5种工作方式（由低到高）**：

1. **程序控制**：无条件传送、程序查询（CPU效率低）
2. **程序中断**：CPU与外设并行，5阶段（请求→判优→响应→处理→返回）
3. **DMA**：DMAC控制，CPU暂停/分时/周期窃取
4. **通道**：字节多路/选择/数组多路
5. **I/O处理机**：功能最强，可独立运算

**总线**：地址总线、数据总线、控制总线；并行/串行。

**总线带宽** = 总线宽度 × 总线频率（注意周期与猝发传输）。

**端口编址**：独立编址(I/O指令) vs 统一编址(存储器映射)。

### 指令系统

**CISC特点**：指令多(100~250)、使用频率20/80、寻址方式多(5~20)、变长指令、微程序控制。

**RISC特点**：指令少、固定长度、Load/Store结构、硬布线控制、流水线、寄存器多(32+)、指令/数据Cache分离。

**RISC性能公式**：**P = I × CPI × T**

- RISC的I比CISC长20%~40%，但CPI≈1(vs CISC的4~10)，T约为CISC的1/3。
- **综合：RISC比同规模CISC快3~5倍**。

**RISC关键技术**：延迟转移、指令取消、重叠寄存器窗口、指令流调整。

### 多处理机

- **MIMD**：多处理机，各自独立程序。
- **SIMD**：并行/阵列处理机，单控制器多处理单元，适合矩阵运算。
- **MPP**：海量并行；**SMP**：对称多处理，共享内存。

### 操作系统

**功能**：进程管理、存储管理、设备管理、文件管理、作业管理。

**进程状态**：就绪、运行、阻塞；切换保存上下文。

**进程同步**：信号量、管程；PV操作。

| 条件 | 定义（答卷） |
|------|-------------|
| **互斥条件** | 互斥条件是指资源一次只能被一个进程占用，其他进程必须等待 |
| **占有且等待** | 占有且等待是指进程已占有至少一个资源，同时又在等待获取其他进程占有的资源 |
| **不可抢占** | 不可抢占是指已分配给进程的资源在使用完毕前不能被强行剥夺，只能由占有者主动释放 |
| **循环等待** | 循环等待是指存在若干进程形成首尾相接的资源等待环路，每个进程都在等待下一进程占有的资源 |

**存储管理**：

| 方式 | 特点 |
|------|------|
| 分区 | 简单，碎片 |
| 分页 | 物理块，无外部碎片 |
| 分段 | 逻辑段，有外部碎片 |
| 段页式 | 结合两者 |

**虚拟存储（OS 侧）**：请求分页/分段，页面置换(FIFO/LRU/OPT)。

**文件结构**：逻辑结构(流式/记录式)、物理结构(连续/链接/索引)。

**目录结构**：单级、两级、树形、无环图。

## 应试

**案例可能怎么问**：Cache 命中率与平均周期计算；按 I/O 场景选查询/中断/DMA；死锁四条件识别与破坏策略；虚拟存储分页/分段与置换算法选型；局部性原理解释 Cache 或应用层缓存设计。

**论文怎么用**：性能优化可写「Cache/局部性→存储层次→I/O 方式选型→虚拟存储与并发」；可靠性场景可写 RAID 冗余；分布式系统可类比 DMA 减轻主节点负担、虚拟存储类比弹性资源池。

**常考结论**

- Cache公式：**t3 = tc×h + tm×(1-h)**。
- CISC **80/20**：20%指令占80%时间。
- RISC性能：**P=I×CPI×T**，快 **3~5** 倍。
- RAID1利用率 **50%**。
- USB最多 **127** 设备；1394最多 **63** 节点。
- I/O方式递进：**查询→中断→DMA→通道→I/O处理机**。
- 总线带宽 = 宽度 × 频率（注意单位换算）。
