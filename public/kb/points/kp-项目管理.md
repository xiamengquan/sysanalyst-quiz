## 定义

- **PMBOK知识域**：范围、进度、成本、质量、资源、沟通、风险、采购、干系人、整合。
- **项目特点**：临时性、独特性、渐进明细。
- **范围说明书**：产品描述、验收标准、项目边界、约束假设。
- **WBS**：面向可交付成果的层次分解；最底层=工作包。
- **WBS原则**：100%规则、互斥、可管理粒度。
- **范围控制**：变更以WBS和范围基准为依据。

## 核心知识点/概念

### 项目管理概述

### 范围管理

- **范围确认**：干系人验收可交付成果。

### 进度管理

**6过程**：活动定义→排序→资源估算→历时估算→进度计划→进度控制。

**依赖关系**：

| 类型 | 说明 |
|------|------|
| FS(完成-开始) | 最常见 |
| FF | 完成-完成 |
| SS | 开始-开始 |
| SF | 开始-完成 |

**依赖性质**：强制(硬逻辑)、自由(软逻辑)、外部。

**网络图**：PDM(节点法/AON)、ADM(箭线法/AOA)。

**关键路径**：最长路径，决定项目最短工期；总时差=0。

**进度压缩**：赶工(加资源)、快速跟进(并行)。

**估算方法**：专家判断、类比、参数(COCOMO)、三点(PERT)、自下而上。

**PERT**：期望时间 = (乐观+4×最可能+悲观)/6。

### 成本管理

**估算方法**：

| 方法 | 说明 |
|------|------|
| 类比估算 | 类似项目参考 |
| 参数估算 | COCOMO/功能点 |
| 自下而上 | WBS逐级汇总 |
| 德尔菲 | 专家匿名多轮 |

**COCOMO模型**：

| 模型 | 说明 |
|------|------|
| 基本 | 仅规模(KLOC) |
| 中间 | +15个成本驱动因子 |
| 详细 | +阶段/模块因子 |

**功能点法**：输入/输出/查询/文件/接口 × 权重 × 复杂度因子。

**成本预算**：WBS工作包→活动→时间分布→成本基准(S曲线)。

### 挣值分析(EVM) ★计算必考

| 指标 | 公式 | 含义 |
|------|------|------|
| PV | — | 计划值(计划完成工作的预算成本) |
| EV | — | 挣值(实际完成工作的预算成本) |
| AC | — | 实际成本 |
| CV | EV-AC | 成本偏差(>0节约) |
| SV | EV-PV | 进度偏差(>0超前) |
| CPI | EV/AC | 成本绩效(>1节约) |
| SPI | EV/PV | 进度绩效(>1超前) |
| EAC | BAC/CPI | 完工估算(典型) |
| ETC | EAC-AC | 完工尚需估算 |

### 配置管理

- **配置项(CI)**：软件/硬件/文档等可管理单元。
- **基线**：通过评审的配置项集合，变更需正式程序。
- **5过程**：配置标识→版本控制→变更控制→配置状态报告→配置审计。
- **变更控制**：申请→评估→批准→实施→验证→关闭。

### 质量管理

**McCall质量模型**：运行(正确性/可靠性/效率/完整性/可用性/风险性) + 修正(可维护/灵活/可测试/互操作/可移植/可重用/可理解) + 转移(可移植/可重用/可互操作)。

**ISO/IEC 25010**：功能适合性、性能效率、兼容性、可用性、可靠性、安全性、可维护性、可移植性。

**QA vs QC**：

| 对比项 | QA(质量保证) | QC(质量控制) |
|--------|-------------|-------------|
| 性质 | 预防性 | 检查性 |
| 阶段 | 全过程 | 结果检查 |
| 手段 | 过程规范 | 测试/评审 |

### 人力资源管理

- **OBS**：组织分解结构。
- **RAM/RBS**：责任分配矩阵(WBS×OBS)。
- **RACI**：R(负责执行)、A(批准)、C(咨询)、I(知情)。
- **团队建设**：培训、团建、认可奖励。
- **冲突解决**：回避、缓和、强制、妥协、合作(面对)。

### 沟通管理

- **渠道数** = n(n-1)/2（n为沟通参与者）。
- **沟通方式**：正式/非正式、书面/口头、内部/外部。

### 风险管理

**过程**：规划→识别→定性分析→定量分析→应对→监控。

| 策略 | 威胁(负) | 机会(正) |
|------|---------|---------|
| 消极 | 规避/转移/减轻/接受 | — |
| 积极 | — | 开拓/分享/提高/接受 |

### 文档管理

**GB/T 8567软件文档标准**：

| 阶段 | 文档 |
|------|------|
| 可行性 | 可行性研究报告 |
| 计划 | 项目开发计划 |
| 需求 | 软件需求规格说明(SRS) |
| 设计 | 概要/详细设计说明 |
| 实现 | 用户手册、操作手册 |
| 测试 | 测试计划/分析报告 |
| 维护 | 维护手册 |

## 易混对比

| 对比项 | 关键路径 | 非关键路径 |
|--------|---------|-----------|
| 总时差 | 0 | >0 |
| 影响工期 | 直接影响 | 超总时差才影响 |
| 压缩 | 优先赶工 | 资源调配 |

| 对比项 | 总时差(TF) | 自由时差(FF) |
|--------|-----------|-------------|
| 定义 | 不影响总工期 | 不影响紧后活动最早开始 |
| 关系 | TF≥FF | — |

| 对比项 | 赶工 | 快速跟进 |
|--------|------|---------|
| 方法 | 加资源 | 并行活动 |
| 风险 | 成本增加 | 返工风险 |

| 对比项 | PV | EV | AC |
|--------|----|----|-----|
| 含义 | 计划完成预算 | 实际完成预算 | 实际花费 |
| 时间 | 计划 | 实际 | 实际 |

| 对比项 | 配置管理 | 变更管理 |
|--------|---------|---------|
| 范围 | 所有配置项 | 变更请求 |
| 目的 | 版本一致 | 控制变更 |

| 对比项 | 范围确认 | 范围控制 |
|--------|---------|---------|
| 目的 | 验收可交付 | 管理变更 |
| 时机 | 阶段/项目末 | 全过程 |

## 常考数字/结论/口诀

- 沟通渠道：**n(n-1)/2**。
- PERT期望：**(O+4M+P)/6**。
- 挣值：**CV=EV-AC，SV=EV-PV，CPI=EV/AC，SPI=EV/PV**。
- CPI/SPI **>1** 好，**<1** 差。
- WBS **100%** 规则。
- 网络图规则：单起始、单终止、无回路、无双向箭头。
