## 概述

**电子商务** 属本科目大纲考点，侧重概念辨析与案例/论文回扣。

## 定义

- **电子商务**是通过信息网络进行商品/服务交易与商务活动的模式；按交易主体可分为 B2B、B2C、C2C 等，涉及支付、物流与信用体系。
- **用于**电商架构、安全支付与电子合同等考点，并与电子政务、企业门户对比边界。
- **特征**：是全球性、虚拟性、交互性、低成本、高效性。
- **标准**：是EDI、ebXML、RosettaNet。
- **技术**：是Web、EDI、支付、安全(加密/认证/CA)。
- **企业信息化**：企业信息化是企业在生产、经营、管理等活动中**全面应用信息技术**，开发信息资源、培养信息人才，以提升管理与决策水平的过程。
- **BSP**：BSP（企业系统规划法）是从企业业务过程出发，通过 U/C 矩阵分析业务与数据类关系，进而导出信息系统总体结构的规划方法。
- **CSF**：CSF（关键成功因素法）是识别企业实现战略目标所必须把握的关键成功因素，并据此确定信息系统支持重点的规划方法。
- **SST**：SST（战略集转化法）是将组织战略目标转化为信息系统战略，使 IS 规划与企业战略保持一致的规划方法。
- **ERP**：ERP（企业资源计划）是建立于信息技术之上、以系统化集成管理思想为核心，整合企业内外部资源并提供决策与运营支持的管理平台。
- **CRM**：CRM（客户关系管理）是以客户为中心、整合销售、营销与服务流程，实现客户关怀与价值提升的管理系统。
- **SCM**：SCM（供应链管理）是贯穿计划、采购、制造、配送、退货等环节，对供应链上下游进行集成协同的管理系统。
- **BI**：BI（商业智能）是对企业内外部数据进行采集、清洗、存储、分析与展现，以支持管理决策的信息系统。
- **EAI**：EAI（企业应用集成）是通过技术手段将异构应用系统、数据与业务流程连接贯通，使企业 IT 资源协同工作的集成方案。

## 要点

### 电子商务

| 类型 | 说明 |
|------|------|
| B2B | 企业对企业 |
| B2C | 企业对消费者 |
| C2C | 消费者对消费者 |
| B2G/C2G | 对政府 |
| O2O | 线上到线下 |

- **特征**：全球性、虚拟性、交互性、低成本、高效性。
- **标准**：EDI、ebXML、RosettaNet。
- **技术**：Web、EDI、支付、安全(加密/认证/CA)。

## 应试

**案例可能怎么问**：按业务场景选 ERP/CRM/SCM/BI；BSP/CSF/SST 规划方法选型；EAI 集成层次（数据/应用/界面/过程）与 CRM-ERP 集成关系。

**论文怎么用**：企业数字化转型类可写「以 ERP 为核心、CRM 管前端、SCM 连上下游、EAI 打通孤岛」的集成架构；信息化规划段引用 BSP/CSF 方法论证 IS 与战略对齐。

**常考结论**

- SCM五环节：**计采制配退**。
- BI三组件：**仓库+OLAP+挖掘**。
- ERP实施三阶段：**准备→试运行→交付**。
- 电商类型：**B2B/B2C/C2C/B2G/O2O**。
- 政务模式：**G2G/G2B/G2C/G2E**。
