# 电子商务

> **大纲**：6.5 · **教程**：第6章 · **分组**：科目1 · 4. 企业信息化基础知识 · **状态**：工坊精修 v1.2.8 · 审计通过

## 概述

**电子商务**：- 特征：全球性、虚拟性、交互性、低成本、高效性。 - 标准：EDI、ebXML、RosettaNet。 - 技术：Web、EDI、支付、安全(加密/认证/CA)。

## 定义

- **电子商务**是通过信息网络进行商品/服务交易与商务活动的模式；按交易主体可分为 B2B、B2C、C2C 等，涉及支付、物流与信用体系。
- **用于**电商架构、安全支付与电子合同等考点，并与电子政务、企业门户对比边界。

## 要点

### 电子商务

| 类型 | 说明 |
|------|------|
| B2B | 企业对企业 |
| B2C | 企业对消费者 |
| C2C | 消费者对消费者 |
| B2G/C2G | 对政府 |
| O2O | 线上到线下 |

- **特征**：全球性、虚拟性、交互性、低成本、高效性。
- **标准**：EDI、ebXML、RosettaNet。
- **技术**：Web、EDI、支付、安全(加密/认证/CA)。

## 应试

**案例可能怎么问**：按业务场景选 ERP/CRM/SCM/BI；BSP/CSF/SST 规划方法选型；EAI 集成层次（数据/应用/界面/过程）与 CRM-ERP 集成关系。

**常考结论**

- SCM五环节：**计采制配退**。
- BI三组件：**仓库+OLAP+挖掘**。
- ERP实施三阶段：**准备→试运行→交付**。
- 电商类型：**B2B/B2C/C2C/B2G/O2O**。
- 政务模式：**G2G/G2B/G2C/G2E**。
