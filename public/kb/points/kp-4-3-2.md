## 概述

**开发（存储、管理、处理、分析、部署）**：存储 → 管理 → 处理 → 分析 → 部署。

## 定义

- 数据管理四块： 1. 元数据管理：技术元数据 + 业务元数据（数据源、ETL 规则、仓库、报表、接口、商业、日志） 2. 数据关系图谱：血缘（归属性、多源性、可追溯性、层次性）+ 关联分析 3. 数据安全：认证 + 授权（Kerberos、RBAC、Sentry/Ranger）；产生→存储→使用→传输→展示→销毁全链路；S1—S4 表安全等级 4. 资源监控：机房网络、组件存活、Metrics、Runtime 探活、集群指标、任务状态、趋势预测

## 要点

### 3.1 数据生命周期

**存储** → **管理** → **处理** → **分析** → **部署**

****：
1. **元数据管理**：技术元数据 + 业务元数据（数据源、ETL 规则、仓库、报表、接口、商业、日志）
2. **数据关系图谱**：血缘（归属性、多源性、可追溯性、层次性）+ 关联分析
3. **数据安全**：认证 + 授权（Kerberos、RBAC、Sentry/Ranger）；产生→存储→使用→传输→展示→销毁全链路；S1—S4 表安全等级
4. **资源监控**：机房网络、组件存活、Metrics、Runtime 探活、集群指标、任务状态、趋势预测

**数据处理**：
- 实时：数据不断到来、不能积压、TB/PB 级、结果快速展现
- 离线：数据量巨大、批量复杂运算、数据预先到位不变、方便查询结果
- 图计算：顶点/边、路径搜索、中心性、社群发现（GraphX/Spark）

**数据分析**：
- 机器学习：监督/非监督/强化学习
- 搜索推荐：ElasticSearch、Solr
- 可视化：Tableau、Datawrapper

**ETL/数据转换六步**：发现 → 映射 → 提取 → 代码生成 → 执行 → 审查

**数据清洗**：缺失值、异常值、重复记录、标准化、干净数据回流
