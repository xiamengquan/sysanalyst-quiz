## 定义

- HTTP 无状态（答卷·定义）：HTTP 是无连接、无状态的请求-响应协议，服务器默认不保留客户端历史请求上下文；用于简化服务器设计，但跨请求的用户状态须借助 Session/Cookie 等机制维护。
- **HTTP 无状态（答卷·定义）**：HTTP 是无连接、无状态的请求-响应协议，服务器默认不保留客户端历史请求上下文；**用于**简化服务器设计，但跨请求的用户状态须借助 Session/Cookie 等机制维护。
- Session（答卷·定义）：Session 是服务器端为识别同一用户会话而维护的状态存储机制，通常通过 Session ID（常存于 Cookie）关联；用于在无状态 HTTP 之上跟踪登录态、购物车等跨请求业务状态。
- **Session（答卷·定义）**：Session 是服务器端为识别同一用户会话而维护的状态存储机制，通常通过 Session ID（常存于 Cookie）关联；**用于**在无状态 HTTP 之上跟踪登录态、购物车等跨请求业务状态。

### 3.1 通信协议

| 协议 | 用途 |

| SMTP/POP3 | 邮件收发 |
