# 开发（容器、注册发现、通信、安全、监控）

> **大纲**：20.3 · **教程**：第20章 · **分组**：科目2 · 5. 微服务系统分析与设计 · **状态**：工坊精修 v1.3.4 · 审计通过

## 概述

**开发（容器、注册发现、通信、安全、监控）**：- 服务多、依赖链长 - 需契约测试（Consumer-Driven Contract） - 需测试替身（Mock/Stub）与测试容器 - 分布式环境搭建复杂。

## 定义

- **微服务架构**：是将应用拆分为可独立部署、围绕业务能力组织的小服务。**作用**：用于云原生、弹性伸缩与团队自治。
- **服务注册与发现**：是实例动态注册并被客户端/网关发现。**作用**：用于 Consul/Eureka/Nacos 等选型题。
- **API 网关**：是统一入口、路由、鉴权与限流。**作用**：用于南北向流量治理。
- **容器编排**：是Kubernetes 等负责调度、伸缩与自愈。**作用**：用于 DevOps 与 5.3 开发运维一体化。

## 要点

### 3.1 测试特点

- 服务多、依赖链长
- 需契约测试（Consumer-Driven Contract）
- 需测试替身（Mock/Stub）与测试容器
- 分布式环境搭建复杂

### 3.2 测试过程与类型

**过程**：单元（单服务）→ 集成（服务间）→ 端到端 → 性能 → 容错 → 安全

| 类型 | 要点 |
|------|------|
| 功能 | API 正确性、业务规则 |
| 性能 | 单服务与链路延迟、吞吐 |
| 容错 | 熔断、降级、故障注入 |
| 安全 | 认证授权、传输加密、漏洞扫描 |
