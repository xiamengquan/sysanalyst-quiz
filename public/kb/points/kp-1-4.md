## 定义

- **CISC特点**：指令多(100~250)、使用频率20/80、寻址方式多(5~20)、变长指令、微程序控制。**作用**：用于题干场景下的概念识别、对比选型与案例/论文回扣。
- **RISC特点**：指令少、固定长度、Load/Store结构、硬布线控制、流水线、寄存器多(32+)、指令/数据Cache分离。**作用**：用于题干场景下的概念识别、对比选型与案例/论文回扣。
- **RISC关键技术**：延迟转移、指令取消、重叠寄存器窗口、指令流调整。**作用**：用于题干场景下的概念识别、对比选型与案例/论文回扣。
- **程序局部性**：程序局部性是程序在执行过程中访问存储单元时呈现的非均匀分布规律，包括时间局部性与空间局部性。**作用**：用于题干场景下的概念识别、对比选型与案例/论文回扣。
- **时间局部性**：时间局部性是最近被访问过的存储单元在不久的将来很可能被再次访问的特性。**作用**：主要用于 Cache 设计——近期用过的数据块可保留在 Cache 中以提高命中率。
- **空间局部性**：空间局部性是当前被访问单元邻近的存储单元在不久的将来很可能被访问的特性。**作用**：主要用于 Cache 块传输与预取设计——一次调入相邻数据块可提升后续访问命中概率。
- **Cache**：Cache 是位于 CPU 与主存之间、由高速 SRAM 构成的小容量缓冲存储器。**作用**：主要用于利用程序局部性，在 CPU 与主存速度差距之间建立缓冲，降低平均访存时间。
- **虚拟存储**：虚拟存储是在主存与辅存之间通过操作系统与硬件配合、为进程提供比物理内存更大逻辑地址空间的存储管理机制。**作用**：主要用于运行大于物理内存的程序、实现内存保护与进程隔离，并通过请求分页/分段与页面置换算法管理内存分配。
- **程序中断**：程序中断是 CPU 在执行程序过程中响应外设请求、暂停当前程序转去执行中断服务程序、处理完毕后再返回原程序的 I/O 控制方式。**作用**：主要用于使 CPU 与外设并行工作，提高 I/O 效率；适用于中速设备，CPU 仅在请求到达与处理首尾阶段参与。
- **DMA**：DMA（直接存储器访问）是由 DMA 控制器直接在内存与外设之间批量传送数据、无需 CPU 逐字节参与控制的 I/O 方式。**作用**：主要用于高速、大批量数据传输，减轻 CPU 负担并提高并行度；CPU 仅负责预处理与后处理（如启动传输、处理完成中断）。
- **死锁**：死锁是两个或多个进程因互相等待对方占有的资源而无法继续推进的运行状态。**作用**：用于理解死锁定义与四条件是分析死锁产生原因、制定预防/避免/检测与恢复策略的基础。

## 要点

### 指令系统

**CISC特点**：指令多(100~250)、使用频率20/80、寻址方式多(5~20)、变长指令、微程序控制。

**RISC特点**：指令少、固定长度、Load/Store结构、硬布线控制、流水线、寄存器多(32+)、指令/数据Cache分离。

**RISC性能公式**：**P = I × CPI × T**

- RISC的I比CISC长20%~40%，但CPI≈1(vs CISC的4~10)，T约为CISC的1/3。
- **综合：RISC比同规模CISC快3~5倍**。

**RISC关键技术**：延迟转移、指令取消、重叠寄存器窗口、指令流调整。

## 应试

**案例可能怎么问**：Cache 命中率与平均周期计算；按 I/O 场景选查询/中断/DMA；死锁四条件识别与破坏策略；虚拟存储分页/分段与置换算法选型；局部性原理解释 Cache 或应用层缓存设计。

**论文怎么用**：性能优化可写「Cache/局部性→存储层次→I/O 方式选型→虚拟存储与并发」；可靠性场景可写 RAID 冗余；分布式系统可类比 DMA 减轻主节点负担、虚拟存储类比弹性资源池。

**常考结论**

- Cache公式：**t3 = tc×h + tm×(1-h)**。
- CISC **80/20**：20%指令占80%时间。
- RISC性能：**P=I×CPI×T**，快 **3~5** 倍。
- RAID1利用率 **50%**。
- USB最多 **127** 设备；1394最多 **63** 节点。
- I/O方式递进：**查询→中断→DMA→通道→I/O处理机**。
- 总线带宽 = 宽度 × 频率（注意单位换算）。
