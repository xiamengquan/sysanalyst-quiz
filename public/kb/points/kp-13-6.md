# 遗留系统

> **大纲**：15.6 · **教程**：第15章 · **分组**：科目1 · 13. 系统运行与维护 · **状态**：工坊精修 v1.2.9 · 审计通过

## 概述

**遗留系统** 属本科目大纲考点。常考：**遗留系统四象限策略**  ·  案例大题。

## 定义

- **遗留系统**：指仍在运行但技术/架构陈旧、文档不全、与现架构难以直接集成的已有信息系统。
- **用于**案例讨论「改造/替换/集成/放弃」四类演化策略（四象限）选型。
- **遗留系统**是考纲规定的知识范围；**用于**选择题、案例或论文中的相关论述。核心要点：高业务价值 │ 改造 │ 集成 (高技高值) │ (高技低值) ────────────┼──────────── 高技术水平 淘汰 │ 继承 (低技低值) │ (低技高值) │ 低业务价值 ---。

## 要点

### 6.3 四象限演化策略（必考）

```
        高业务价值
            │
  改造      │      集成
 (高技高值) │ (高技低值)
────────────┼──────────── 高技术水平
  淘汰      │      继承
 (低技低值) │ (低技高值)
            │
        低业务价值
```

| 象限 | 策略 | 说明 |
|-----|------|------|
| 第一象限 高技高值 | **改造** | 功能增强 + 数据模型改造 |
| 第二象限 高技低值 | **集成** | 企业应用集成，消除孤岛 |
| 第三象限 低技低值 | **淘汰** | 全面重新开发；可借鉴旧系统降风险 |
| 第四象限 低技高值 | **继承** | 新系统兼容旧功能/数据模型；需并行运行 |
