- **一句话**：标准类型：是含国际标准、国家标准、行业标准、企业标准等。作用：用于合规与采标题。
- **考什么**：概念辨析、场景决策与案例回扣。
- **具体理解**：
  - 信息资源规划(IRP)：梳理业务流程→建立信息体系→建立数据库体系。
  - 标准类型：是含国际标准、国家标准、行业标准、企业标准等。作用：用于合规与采标题。
  - 标准生命周期：是预研→立项→起草→征求意见→审查→批准→出版→复审。作用：用于标准化流程选择题。
  - 软件知识产权：是含著作权、专利权、商业秘密与许可。作用：用于开源/外包/员工职务作品边界。
- **别搞混**：与同章相邻考点区分；题干锚词：**标准类型 / 生命周期 / 知识产权**。

## 定义

- **标准类型**：是含国际标准、国家标准、行业标准、企业标准等。**作用**：用于合规与采标题。
- **标准生命周期**：是预研→立项→起草→征求意见→审查→批准→出版→复审。**作用**：用于标准化流程选择题。
- **软件知识产权**：是含著作权、专利权、商业秘密与许可。**作用**：用于开源/外包/员工职务作品边界。
- **GB/T 8567 等国标**：是规定文档与工程制品要求。**作用**：用于交付物与验收对齐。

## 步骤与流程

### 标准制定生命周期（选择常考）

预研 → 立项 → 起草 → 征求意见 → 审查 → 批准 → 出版 → 复审。

### 信息资源规划 IRP（三步）

1. 梳理企业业务流程与信息需求。
2. 建立企业信息体系（功能/数据类结构）。
3. 建立数据库体系与应用分布。

### 软件知识产权处理要点（案例）

1. 区分职务作品、委托开发、开源许可边界。
2. 交付物对齐 **GB/T 8567** 等文档与验收要求。

## 要点

### 标准层级（选择）

| 类型 | 代号/示例 | 说明 |
|------|-----------|------|
| 国际标准 | ISO/IEC | 跨国采标 |
| 国家标准 | GB / GB/T | 强制 vs 推荐（/T） |
| 行业标准 | 如 JR/T、YD | 行业统一 |
| 地方标准 | DB + 省码 | 地域要求 |
| 企业标准 | Q/ | 企业内部 |

### 知识产权保护期限（常考口径）

| 对象 | 典型期限 | 备注 |
|------|----------|------|
| 软件著作权 | 自然人终生 + 死后 **50 年**；法人首次发表后 **50 年** | 与 [法律考点](/kb/kp-law-finance-org-hr-it-audit/) 对照 |
| 发明专利 | **20 年** | 自申请日起 |
| 实用新型 | **10 年** | 常作干扰项 |
| 商标 | **10 年**，可续展 | 续展制 |
| 商业秘密 | 无固定法定年限 | 依赖保密措施 |

### IRP 与数据标准

- **信息资源规划(IRP)**：梳理业务流程→建立信息体系→建立数据库体系。
- **标准**：数据元素标准、信息分类编码标准、用户视图标准。
