# 信息（文档）管理 GB/T 8567

> **大纲**：8.9 · **教程**：第8章 · **分组**：科目1 · 6. 项目管理 · **状态**：工坊精修 v1.2.9 · 审计通过

## 概述

**信息（文档）管理 GB/T 8567** 属本科目大纲考点，侧重概念辨析与案例/论文回扣。

## 定义

- **项目文档管理**是按 GB/T 8567 等标准对分析、设计、测试等文档进行标识、版本与配置管理的过程；**用于**保证可追溯与验收。
- 文档类型含可行性、需求、设计、测试计划/报告等；与配置管理配合控制基线，案例宜列文档编号与变更记录。

## 要点

### 文档管理

**GB/T 8567软件文档标准**：

| 阶段 | 文档 |
|------|------|
| 可行性 | 可行性研究报告 |
| 计划 | 项目开发计划 |
| 需求 | 软件需求规格说明(SRS) |
| 设计 | 概要/详细设计说明 |
| 实现 | 用户手册、操作手册 |
| 测试 | 测试计划/分析报告 |
| 维护 | 维护手册 |
