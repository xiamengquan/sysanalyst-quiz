# 速查 · 云原生架构设计（2026 考纲）

> **回链**：`kp-cloud-computing` · `kp-microservices` · `ch20` · [Web+Agent 四维度](./Web与AI智能体-架构选型四维度卡.md)

## 云原生四要素

| 要素 | 考点 | 案例/论文句 |
|------|------|-------------|
| **容器** | Docker 镜像、轻量隔离、不可变基础设施 | 环境一致、快速回滚 |
| **微服务** | 按业务能力拆分、独立库、轻量通信 | 见拆分策略 |
| **DevOps** | CI/CD、自动化测试、基础设施即代码 | 缩短交付周期 |
| **持续交付** | 小批量发布、金丝雀/蓝绿 | 降低发布风险 |

## 微服务拆分策略（选型题/案例）

- **按业务能力**（DDD 限界上下文）——首选表述  
- **按变更频率 / 团队拓扑**（康威定律）  
- **按非功能需求**（性能热点独立扩容）  
- **忌**：按技术层拆分（UI 服务/API 服务）导致跨层调用链过长  

## 服务治理

| 能力 | 典型组件/机制 |
|------|----------------|
| 注册发现 | Nacos/Eureka/Consul |
| 配置 | 配置中心、动态刷新 |
| 流量 | 网关、限流、熔断、重试 |
| **Service Mesh** | Sidecar（Envoy/Istio）：mTLS、可观测、策略与流量治理与业务解耦 |
| 追踪 | 分布式 traceId |

## 容器编排（Kubernetes 原理级）

- **Pod** 最小调度单元；**Deployment** 声明式副本与滚动更新  
- **Service** 集群内稳定访问；**Ingress** 七层入口  
- **HPA** 按 CPU/自定义指标弹性伸缩  
- 案例写「编排层负责调度与自愈，业务无感知节点故障」即可，勿堆 kubectl 命令  

## 与 SOA/单体对比

写 **权衡**：云原生换弹性与发布速度，代价是分布式复杂度、最终一致与运维体系投入。
