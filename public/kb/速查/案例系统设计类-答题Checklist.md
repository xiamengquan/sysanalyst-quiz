# 速查 · 案例系统设计类 · 答题 Checklist

> **docType**：howto · **权重**：案例分析选答题中「系统设计 / 架构 / 性能」类常见，与需求类互补  
> **关联**：[案例分析答题教程](../案例分析答题教程.md) · [UML 体系化学习指南](./UML-体系化学习指南.md) · [Web与AI智能体 · 架构选型四维度卡](./Web与AI智能体-架构选型四维度卡.md) · [案例预测第二套 · 练笔 Checklist](./案例预测第二套-练笔Checklist.md)

## 适用信号词

题干出现 **架构风格、质量属性、组件/接口、部署、性能、可用性、扩展、缓存、限流、数据库分库** 等，且要求 **方案对比 / 填空 / 简答**。

## 30 分钟答题骨架（Checklist）

### 1. 约束清单（3 min）

- [ ] 功能与非功能（性能 QPS、可用性、安全、成本、工期）
- [ ] 现有系统/遗留约束、团队技能、合规（等保、数据出境等）

### 2. 架构风格 / 模式选型（8 min）

- [ ] 给出 **2～3 种** 候选（如 C/S、分层、微服务、事件驱动、管道-过滤器）
- [ ] 用 **对比表**：粒度、耦合、扩展、运维复杂度
- [ ] 结论 **回扣题干约束**（勿空泛堆名词）

**回链**：`kp-10-1` · `kp-12-1` · [架构选型四维度](./Web与AI智能体-架构选型四维度卡.md)

### 3. 质量属性与战术（8 min）

- [ ] 写 **质量属性场景六要素**（刺激源→刺激→环境→制品→响应→响应度量）
- [ ] 对应 **战术**：限流/熔断/冗余/缓存/异步/分片 等
- [ ] 可选：**ATAM** 思路（识别敏感点、权衡、风险）

**回链**：`kp-10-5` · `kp-10-6`

### 4. 组件、接口与数据模型（8 min）

- [ ] **组件划分**：按业务边界/变更频率拆模块，标 **核心域 vs 支撑域**
- [ ] **接口契约**：操作名、入参/出参、错误码、幂等键、超时与重试
- [ ] **E-R / 表结构 / 分库分片键**（若题干偏数据）；写 **分片键选取理由**（均衡/业务相关性）
- [ ] **接口风格**（REST/消息）、同步 vs 异步、一致性（强一致/最终一致/Saga/TCC）

**回链**：`kp-10-2` · `kp-3-1` · `kp-3-2` · `kp-microservices` · `kp-app-service-integration`

### 5. 部署与性能（5 min）

- [ ] 负载均衡层次、缓存层次、MQ 削峰、读写分离
- [ ] 监控与容量（压测、瓶颈、扩容）

**回链**：试题四类高并发题 · `kp-cloud-computing`

## 易漏分点

- 只写「用微服务」不写 **为何**、**代价**、**一致性怎么保证**
- 性能题缺 **数字或量级**（可合理假设并声明）
- 未写 **与需求/用例的可追踪关系**
