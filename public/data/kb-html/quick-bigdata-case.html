分值

  • 综合 5–6 分；案例 7–10 分；与 AI/云常交叉（见 AI与数字化应用-考点速查）

特征：4V / 5V

V 含义 案例句
Volume 海量 分布式存储与计算
Velocity 高速 流 vs 批
Variety 多样 结构/半结构/非结构
Value 价值密度低 挖掘后才有业务价值
Veracity 真实性/质量 清洗、可信数据

六大设计原则（案例常答）

  1. 分而治之——分区、分片、并行
  2. 移动计算而非移动数据——MapReduce 思想
  3. 容错与副本——HDFS 多副本、任务重试
  4. 异构数据统一接入——Flume/Kafka 等采集
  5. 批流分工或一体——Lambda/Kappa 选型
  6. 安全与治理——脱敏、权限、审计、元数据

（教程 §2.1 另列：分布式、模块化、安全、性能、可靠、可运维——可与上表合并表述。）

分层架构

采集 → 存储（HDFS/对象存储/NoSQL）→ 计算（MapReduce/Spark/Flink）→ 服务（Hive/Presto）→ 应用（BI/风控）

Lambda · Kappa · IOTA（辨析）

架构 要点 适用
Lambda 批层（全量）+ 速度层（实时）+ 服务层（查询合并） 批流并存、逻辑可重复
Kappa 以流为主，日志重放补历史 简化双轨、流优先
IOTA（教程/案例语境） 面向 IoT/边缘海量接入：集成接入 → 组织存储 → 转换处理 → 分析应用；强调 即时查询、弱化传统 ETL、与 数据湖/边缘 SDK 衔接 物联网 + 大数据、近实时分析

处理流程：ETL / ELT

  • ETL：Extract → Transform → Load（传统仓库）
  • ELT：先入库再转换（数据湖/弹性计算）
  • 六步转换（教程）：发现 → 映射 → 提取 → 代码生成 → 执行 → 审查
  • 清洗：缺失、异常、重复、标准化

技术栈选型（简表）

层次 常见组件
采集 Flume、Kafka、Sqoop
批计算 Hadoop MapReduce、Spark
流计算 Storm、Flink、Spark Streaming
存储 HDFS、HBase、对象存储
查询/仓库 Hive、Presto、数据湖
检索 Elasticsearch

行存 vs 列存：OLTP 行存；OLAP/分析列存（HBase 列族等）——见 ch19 §2.3。

测试与安全

测试 要点
功能 分区、聚合、关联、清洗转换
性能 吞吐、延迟、扩展
可靠 副本、故障转移
安全 Kerberos/RBAC、加密、审计、分级 S1–S4

生命周期：存储 → 管理（元数据/血缘）→ 处理 → 分析 → 部署；生产/测试隔离。
