概述

开发环境与工具：集成开发环境（IDE） 是集编辑、编译/构建、调试、版本管理于一体的软件开发环境。

速懂

  • 一句话：集成开发环境（IDE）：是集编辑、编译/构建、调试、版本管理于一体的软件开发环境。作用：用于提高编码效率并与构建/测试流水线衔接。
  • 考什么：开发模型选型、UML、过程改进（教程第 7 章）。
  • 具体理解：
    • CASE 分类：按阶段分为需求（建模/原型）、设计（UML/CASE）、实现（代码生成）、测试（用例管理）、维护（逆向/再工程）工具。
    • CASE 工具：是在软件工程各阶段提供建模、分析、生成与管理的计算机辅助软件工程工具。作用：用于提高工程化、自动化与制品一致性。
    • 构建工具（Maven/Gradle）：是管理依赖、编译打包与生命周期阶段的自动化工具。作用：用于 repeatable build 与 CI/CD 集成。
  • 别搞混：与同章相邻考点区分；题干锚词：开发环境与工具。

定义

  • 集成开发环境（IDE）：是集编辑、编译/构建、调试、版本管理于一体的软件开发环境。作用：用于提高编码效率并与构建/测试流水线衔接。
  • CASE 工具：是在软件工程各阶段提供建模、分析、生成与管理的计算机辅助软件工程工具。作用：用于提高工程化、自动化与制品一致性。
  • 构建工具（Maven/Gradle）：是管理依赖、编译打包与生命周期阶段的自动化工具。作用：用于 repeatable build 与 CI/CD 集成。
  • 静态分析/代码规范插件：是在编码期发现缺陷与风格问题。作用：用于左移质量与团队编码标准统一。

要点

教程无独立 7.3 专节；以下为备考提纲。

集成开发环境（IDE） 是集编辑、编译/构建、调试、版本管理于一体的软件开发环境。

CASE 工具 是在软件工程各阶段提供建模、分析、生成与管理的计算机辅助软件工程工具。

  • 开发环境：语言/框架 SDK、构建工具（Maven/Gradle）、调试器、静态分析插件。
  • CASE 分类：按阶段分为需求（建模/原型）、设计（UML/CASE）、实现（代码生成）、测试（用例管理）、维护（逆向/再工程）工具。
  • 选型要点：与团队过程（瀑布/敏捷）、制品库、CI 是否集成；避免「工具堆叠、流程不配套」。
