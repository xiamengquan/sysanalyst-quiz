概述

开发环境（App/小程序/网页）：Spring MVC 请求流程（Web 移动后端常考）：DispatcherServlet → HandlerMapping → HandlerAdapter → Handler → ViewResolver → 渲染响应。

速懂

  • 一句话：移动开发环境是含 SDK、模拟器/真机调试、签名与打包工具链。
  • 考什么：移动开发方式、离线与安全（教程第 18 章）。
  • 别搞混：题干锚词：开发环境。

定义

  • 移动开发环境：是含 SDK、模拟器/真机调试、签名与打包工具链。作用：用于 iOS/Android/小程序发布流程题。
  • 小程序运行时：是宿主 App 内轻量 JS 引擎 + 原生能力桥接。作用：用于微信/支付宝小程序与 H5 差异辨析。
  • 混合开发框架：是如 React Native、Flutter 等跨端渲染方案。作用：用于一码多端与性能权衡。
  • 应用商店合规：是含隐私政策、权限说明与版本审核。作用：用于上线与安全管理。

要点

架构演进阶段

单体应用 → MVC → MVP → MVVM → 微服务
架构 核心思想 适用
MVC Model-View-Controller 分离 传统移动/Web
MVP Presenter 中转，View 被动 可测试性更好
MVVM ViewModel + 数据绑定（Vue/小程序/Angular） 响应式 UI
微服务 独立服务、独立部署（Netflix 案例） 大规模、高可用

Spring MVC 请求流程（Web 移动后端常考）：DispatcherServlet → HandlerMapping → HandlerAdapter → Handler → ViewResolver → 渲染响应

Netflix 微服务模块：用户管理、视频流、推荐、支付、配置管理；Eureka 注册发现、Ribbon 负载、Hystrix 熔断、Zuul 网关
