速懂

  • 一句话：移动应用是运行在移动终端、强调触控、弱网与多分辨率的应用形态。
  • 考什么：概念辨析、场景决策与案例回扣。
  • 具体理解：
    • 「请说明 Web 应用架构设计应遵循的核心原则（至少 2 个）」→ 直接誊写 §2.1 八大原则答卷句。
    • 「对比 MVC 与 MVP / 传统 Web 与 SPA / 整体式与微服务」→ 用 §五 易混对比表展开。
    • 「如何提升 Web 应用性能？」→ 负载均衡 + 连接池 + 缓存（含 CDN）三板斧，各写定义+作用。
    • 「多端（Web/小程序）如何统一业务规则？」→ 前后端分离 + BFF 或统一领域服务，避免双端两套逻辑。
  • 别搞混：题干锚词：移动 / Web。

定义

  • 移动应用：是运行在移动终端、强调触控、弱网与多分辨率的应用形态。作用：用于选型原生/混合/跨平台与离线策略。
  • Web 应用：是通过浏览器访问、业务逻辑集中在服务端的应用形态。作用：用于 B/S、快速迭代与统一升级。
  • 混合应用：是 WebView 壳 + 原生插件的折中形态。作用：用于一码多端与商店分发。
  • 响应式 Web：是同一套 UI 适配多屏宽度的前端技术。作用：用于降低移动端维护成本。
