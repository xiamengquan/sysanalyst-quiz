第1章 绪论

出自《系统分析师教程》知识点精炼 · 第一篇 · 基础知识（第1—9章）分章。

本章考什么

本章奠定系统分析师角色认知与方法论基础，常考信息/系统/信息系统概念、香农信息论、系统特性与系统论、霍尔三维结构与软系统方法论对比、信息系统生命周期与建设原则、系统分析师知识体系。选择题与案例背景题均可能出现。

核心知识点/概念

信息

  • 香农定义：信息是不确定性的减少；信息量是负熵，单位 bit。
  • 信息特征（11项）：客观性、普遍性、无限性、动态性、相对性、依附性、变换性、传递性、层次性、系统性、转化性。
  • 信息功能：认识依据、改造指导、有序保证、资源开发条件、知识生产材料。
  • 信息与数据：数据是信息的存在形式；信息 = 被解释/被理解的数据。
  • 信息与知识：知识 = 经过加工的信息。

系统

  • 定义：相互联系、依赖、作用的事物/过程组成的具有整体功能的统一体。
  • 系统特性：整体性、层次性、目的性、稳定性、突变性、自组织性、相似性、相关性、环境适应性。
  • 系统论任务：调整结构、协调元素、优化目标。
  • 系统理论8原理：整体性、整体突变(非加和)、层次性、开放性、目的性、环境互塑共生、秩序、生命周期(演化)。

信息系统

  • 定义：接受输入数据，加工产生信息的系统；以计算机为基础的信息系统 = 管理模型 + 信息处理模型 + 系统实现条件（技术/环境/人员）。
  • 生命周期5阶段：系统规划 → 系统分析 → 系统设计 → 系统实现 → 系统运行与维护。
  • 建设原则：高层管理人员介入、用户参与开发、自顶向下规划、工程化原则。

系统工程方法论

霍尔三维结构（硬系统方法论）

维度 内容
时间维 规划→制定方案→研制→生产→安装→运行→更新
逻辑维 问题确定→目标确定→系统综合→系统分析→方案选择→评价决策→实施计划
知识维 工程、管理、社会科学等专业知识

切克兰德软系统方法论（5步）：问题现状说明 → 理清关联因素 → 建立概念模型 → 比较 → 实施。

  • 核心差异：硬系统强调最优化；软系统强调可行/满意，通过磋商与反馈学习。

系统分析师

  • 角色：分析、设计、指导开发企业/组织计算机应用系统的高级复合型人才。
  • 任务：系统规划、系统分析、系统设计、系统实现指导、系统运行与维护。
  • 知识体系：信息化知识、信息系统工程、企业业务、软件工程、项目管理、法律法规等。
