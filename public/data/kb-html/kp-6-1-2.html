CPS 概述（IoT 关系）

大纲：21.1 · 教程：第21章 · 分组：科目2 · 6. 信息物理系统分析与设计 · 状态：结构式重写 v2.0 · 审计通过

概述

CPS 概述（IoT 关系）：定义：包含物理部件、计算部件、网络的交互系统，实现信息空间与物理空间的深度融合与闭环控制。

速懂

  • 一句话：CPS 与 IoT 关系是IoT 强调连接与数据采集；CPS 强调闭环控制与物理交互。
  • 考什么：CPS/IoT、边缘与信息物理融合（教程第 21 章）。
  • 具体理解：
    • 感知是基础（模拟→数字 ADC）
    • 网络：TSN、工业以太网、5G 切片
  • 别搞混：题干锚词：CPS / 概述。

定义

  • CPS 与 IoT 关系：是IoT 强调连接与数据采集；CPS 强调闭环控制与物理交互。作用：用于概念辨析与架构分层。
  • CPS 典型特征：是实时、可靠、安全、嵌入式、网络化。作用：用于与通用信息系统对比。
  • 数字孪生：是物理实体在数字空间的动态镜像。作用：用于仿真、预测性维护。
  • 信息物理融合：是计算、通信与控制与物理过程协同。作用：用于智能制造/交通等论文素材。

步骤与流程

CPS 闭环与分层（教程第 21 章）

感知-分析-决策-执行闭环：感知 → 传输 → 分析 → 执行 → 反馈。

三层逻辑架构：设备层（传感/执行接口）→ 控制层（实时计算）→ 应用层（监控/孪生/集成）。

与 IoT 辨析：IoT 偏连接与数据；CPS 偏物理交互与闭环控制。

要点

一、场景特征

定义：包含物理部件、计算部件、网络的交互系统，实现信息空间与物理空间的深度融合与闭环控制。

与物联网关系：IoT 侧重连接与感知；CPS 侧重感知-分析-决策-执行闭环与实时控制。CPS 范围更广、实时性与安全性要求更高。

典型应用：智能制造、智能交通、智能电网、工业互联网、自动驾驶、医疗监护

CPS 与 SCADA/嵌入式区别：CPS 强调全局虚拟-局部物理、深度嵌入、事件驱动、以数据为中心、异构 SoS

二、架构原则与模式

分层架构

三层逻辑：

  • 决策层：语义逻辑、用户-感知-控制耦合
  • 网络层：跨时空子系统互联
  • 物理层：传感器/执行器与物理实体接口

基本闭环：传感器 → 决策控制单元 → 执行器 → 物理对象 → 再感知

SoS 级 CPS：多 CPS 系统协同（如产业链、产品服务系统）

典型构成

功能单元：传感器(Sensor)、执行器(Actuator)、决策控制单元(DCU)

五大特点：

  1. 多为封闭系统，通信距离短
  2. 分布式、复杂度高、规模大
  3. 接入设备海量运算
  4. 感知是基础（模拟→数字 ADC）
  5. 应用广泛

十大特质（案例列举题）：

  1. 全局虚拟、局部物理
  2. 深度嵌入
  3. 事件驱动
  4. 以数据为中心
  5. 时间关键
  6. 安全关键（Safety + Security + Privacy）
  7. 异构（混合系统/SoS）
  8. 高可信赖
  9. 高度自主（自组织/自配置/自维护/自优化/自保护）
  10. 领域相关

技术框架

四大核心技术：

  1. 感知与自动控制：智能感知、虚实融合控制
  2. 工业软件：嵌入式软件、MBD、CAX/MES/ERP/PLM/CRM/SCM
  3. 工业网络：现场总线、工业以太网、无线、SDN
  4. 工业云与智能服务平台：边缘/雾/大数据分析

支撑技术：普适/嵌入式/分布式/云/移动/自律/可信计算；NGI/NGN/5G；WSN/WSAN

协议标准（选型对比）

层次 协议/技术
应用层 MQTT、CoAP、HTTP、DDS
网络/传输 IPv4/v6、TCP、LoWPAN
近距离 NFC/RFID、Bluetooth/BLE
远距离蜂窝 GSM/GPRS/LTE/5G、NB-IoT
远距离非蜂窝 ZigBee、Wi-Fi、LoRa/LoRaWAN、SigFox
有线 RS232/485、Ethernet、USB、M-Bus

ZigBee：802.15.4，Mesh，低功耗，250kb/s(2.4GHz)，适用工业控制

LoRa/LoRaWAN：LPWAN，Class A/B/C（功耗 vs 灵活性）

DDS：以数据为中心的中间件，发布-订阅

控制系统与通信

控制行为模式：嵌入控制、虚体控制、集控控制、目标控制

控制类型：开环、闭环、顺序、批量

事件类型：过程、诊断、维护

通信模式：

  • DPC：确定性周期通信
  • DAC：确定性非周期
  • NDC：非确定性

三、开发与测试要点

四类开发技术

  1. 感知控制：传感器、ADC、执行器、PLC
  2. 工业软件：SCADA、MES、数字孪生
  3. 网络：TSN、工业以太网、5G 切片
  4. 服务平台：边缘计算、工业云
