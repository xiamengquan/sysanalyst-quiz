分值与题型

  • 综合约 8–12 分；案例约 8–12 分
  • 高频：Native / Hybrid / Web App / 小程序 对比、MVP/MVVM、弱网与离线、性能与安全

架构模式

模式 适用
MVP 视图与逻辑分离，Presenter 驱动
MVVM 数据绑定，适合复杂 UI 状态
分层 UI → 领域 → 数据（本地缓存 + 同步）

三端对比（方案论证常用）

维度 Native Hybrid/跨端 Web App
体验/性能 优 中 依赖浏览器
发布 应用商店审核 热更新有限 即时
设备能力 全 插件/桥接 受限
成本 双端维护高 一套代码多端 低但体验折中

非功能清单

  • 弱网/离线：本地队列、冲突合并、幂等同步
  • 安全：本地存储加密、证书绑定、代码混淆
  • 性能：启动时间、内存、电量、包体积
