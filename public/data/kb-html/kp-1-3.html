概述

输入输出系统（程序控制/中断/DMA/通道/I/O 处理机、总线、I/O 接口）：1. 程序控制：无条件传送、程序查询（CPU效率低） 2. 程序中断：CPU与外设并行，5阶段（请求→判优→响应→处理→返回） 3. DMA：DMAC控制，CPU暂停/分时/周期窃取 4. 通道：字节多路/选择/数组多路 5. I/O处理机：功能最强，可独立运算。

速懂

  • 一句话：程序中断是 CPU 在执行程序过程中响应外设请求、暂停当前程序转去执行中断服务程序、处理完毕后再返回原程序的 I/O 控制方式。
  • 考什么：Cache/RAID/存储层次、OS 与指令对比（教程第 3 章）。
  • 具体理解：
    • 程序中断：CPU与外设并行，5阶段（请求→判优→响应→处理→返回）
    • DMA：DMAC控制，CPU暂停/分时/周期窃取
  • 别搞混：| 对比 | 区别 |

定义

  • 程序中断：程序中断是 CPU 在执行程序过程中响应外设请求、暂停当前程序转去执行中断服务程序、处理完毕后再返回原程序的 I/O 控制方式。作用：主要用于使 CPU 与外设并行工作，提高 I/O 效率；适用于中速设备，CPU 仅在请求到达与处理首尾阶段参与。
  • DMA：DMA（直接存储器访问）是由 DMA 控制器直接在内存与外设之间批量传送数据、无需 CPU 逐字节参与控制的 I/O 方式。作用：主要用于高速、大批量数据传输，减轻 CPU 负担并提高并行度；CPU 仅负责预处理与后处理（如启动传输、处理完成中断）。
  • 端口编址：独立编址(I/O指令) vs 统一编址(存储器映射)。

步骤与流程

O系统

  1. 程序控制：无条件传送、程序查询（CPU效率低）
  2. 程序中断：CPU与外设并行，5阶段（请求→判优→响应→处理→返回）
  3. DMA：DMAC控制，CPU暂停/分时/周期窃取
  4. 通道：字节多路/选择/数组多路
  5. I/O处理机：功能最强，可独立运算

要点

O系统

5种工作方式（由低到高）：

总线：地址总线、数据总线、控制总线；并行/串行。

总线带宽 = 总线宽度 × 总线频率（注意周期与猝发传输）。

端口编址：独立编址(I/O指令) vs 统一编址(存储器映射)。

易混辨析

对比项 程序查询 中断 DMA
CPU 介入 全程轮询等待 响应时介入处理 仅传送时让出总线
CPU 效率 最低 较高（部分并行） 高（批量传送）
数据路径 外设→CPU→主存 外设→CPU→主存 外设↔主存直接
适用场景 低速设备 中低速、偶发事件 高速块设备

应试

案例可能怎么问：Cache 命中率与平均周期计算；按 I/O 场景选查询/中断/DMA；死锁四条件识别与破坏策略；虚拟存储分页/分段与置换算法选型；局部性原理解释 Cache 或应用层缓存设计。

论文怎么用：性能优化可写「Cache/局部性→存储层次→I/O 方式选型→虚拟存储与并发」；可靠性场景可写 RAID 冗余；分布式系统可类比 DMA 减轻主节点负担、虚拟存储类比弹性资源池。

常考结论

  • Cache公式：t3 = tc×h + tm×(1-h)。

  • CISC 80/20：20%指令占80%时间。

  • RISC性能：P=I×CPI×T，快 3~5 倍。

  • RAID1利用率 50%。

  • USB最多 127 设备；1394最多 63 节点。

  • I/O方式递进：查询→中断→DMA→通道→I/O处理机。

  • 总线带宽 = 宽度 × 频率（注意单位换算）。
