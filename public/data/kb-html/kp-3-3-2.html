概述

移动架构（MVC/MVP/MVVM/微服务）：- 安全（认证、存储、传输） - 性能（启动、内存、网络） - 可维护性（模块化、组件化） - 测试（单元、UI 自动化、兼容性） - 发布与版本更新（灰度、热修复）。

速懂

  • 一句话：App是Xcode(Apple)、Android Studio；Cocoa Touch、CoreData、WebKit。
  • 考什么：移动开发方式、离线与安全（教程第 18 章）。
  • 具体理解：
    • 网页：DevExtreme 等 HTML5 工具
  • 别搞混：题干锚词：移动架构 / MVC / MVP。

定义

  • App：是Xcode(Apple)、Android Studio；Cocoa Touch、CoreData、WebKit。作用：用于按目标平台选型 IDE 与工具链。
  • 小程序：是各平台 IDE（FIDE 等）。
  • 网页：是DevExtreme 等 HTML5 工具。

要点

开发环境

  • App：Xcode(Apple)、Android Studio；Cocoa Touch、CoreData、WebKit
  • 小程序：各平台 IDE（FIDE 等）
  • 网页：DevExtreme 等 HTML5 工具

开发关注点

  • 安全（认证、存储、传输）
  • 性能（启动、内存、网络）
  • 可维护性（模块化、组件化）
  • 测试（单元、UI 自动化、兼容性）
  • 发布与版本更新（灰度、热修复）

测试要点

  • 多设备、多 OS 版本兼容
  • 弱网/断网场景
  • 触控手势、屏幕适配
  • 应用商店审核规则
  • 性能（启动时间、内存、电量）
  • 安全（本地存储、通信加密）
