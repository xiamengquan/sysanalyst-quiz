序 1 · P0 · 软件过程与 UML（教程第 7 章）

开发模型（[§1 软件开发模型](./高频对比速查表.md#1-软件开发模型对比)）

模型 关键词 选型
瀑布 顺序、文档、里程碑 需求明确、技术成熟
V 模型 开发与测试阶段对称 质量要求高
螺旋 风险驱动、原型+瀑布迭代 大型、高风险
喷泉 OO、阶段界限模糊、迭代 面向对象项目
RAD 原型+构件、快 工期紧、需求较清晰
RUP 用例驱动、架构中心、迭代增量 中大型
敏捷/Scrum 拥抱变更、短迭代 需求不确定

口诀：需求稳 → 瀑布/V；风险大 → 螺旋；要快 → RAD/敏捷；OO → 喷泉/RUP。
螺旋四步 计风实评 · RAD 业数过应测 · RUP 初细构移 · CMMI 初可已定优。

UML 深度：UML 体系化学习指南 · kp-面向对象技术

UML 坐标与六关系

  • 结构图 = 长什么样；行为图 = 怎么动。
  • 必考图顺序：用例 → 类 → 序列/通信 → 状态 → 活动。
关系 线型 记法
依赖 虚线开放箭头：客户端→供应者 较弱；供应者变更可能影响客户端
关联 实线 实例链接
泛化 实线空心三角在一般端 is-a
实现 虚线空心三角在规约端 类实现接口
聚合 实线空心菱在整体 弱拥有
组合 实线实心菱在整体 生命周期绑整体

菱形贴整体 · include 基→被含 · extend 扩展→基 · BCE 边界/控制/实体。

练手：第 7 章；案例「选图 / 填关系」。

序 2 · P0 · 需求与规划（教程第 11、10 章）

需求工程路径 · 需求获取五法

层次 记法
业务需求 组织为什么要做
用户需求 用户要达成什么
系统需求 系统必须做什么（可验证）

获取选型：要深 → 访谈/观察；要广 → 问卷；快共识、消冲突 → JRP/JAD；现成系统 → 文档/采样。

DFD 四要素：外部实体 · 加工 · 数据流 · 数据存储。

规划方法（§2）：BSP 过程+U/C · CSF 关键成功因素 · SST 战略转化 · SDP 主题数据 · VCA 价值链。

练手：第 10、11 章；案例 DFD/需求获取。

序 3 · P0 · 架构 · Web · 微服务（教程第 12 章）

§7 架构 · §13 Web · §16 微服务 · REST 卡

风格 记一句

仓库（黑板） 共享数据
4+1 视图 逻辑/开发/进程/物理 + 场景
