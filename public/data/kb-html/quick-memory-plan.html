0. 先诊断：不是记性差，是复习结构不对

记忆失败只有三种，各有对策：

失败类型 表现 对策
编码失败 当时就没真懂、靠死背 学时编口诀/画图（双编码），见 §1
检索失败 提示了才想起来 默写优先于重读：先写再看答案（提取练习）
间隔缺失 学完只复习一次 固定间隔日程 1-2-4-7-15（§2）

一句话：「能默写出来」才算记住；「看着眼熟」不算。

3. 每日 25 分钟记忆微循环

  • 早 10 min（提取）：昨天专题的「必背内核」遮盖默写 → 对答案 → 错条抄到错卡。
  • 午 5 min（编码）：今天新专题读「速懂」节，顺手编一个自己的口诀（哪怕很烂）。
  • 晚 10 min（间隔）：按 §2 日历做当天复习组的默写；错卡优先，清完才收工。

错卡规则：一张卡一行（问句 + 答案 ≤ 20 字）。连续 3 次默写全对才销卡。

4. 硬记忆点卡组（56 条 · 按专题分组 · ★=错卡高发）

各专题全部考点见知识点地图 · 按记忆专题。

T01 计算机系统

  1. Cache 均访：t3 = tc×h + tm×(1-h) ★
  2. RISC 性能：P=I×CPI×T（快 3~5 倍）；CISC 80/20
  3. RAID1 利用率 50% ★
  4. I/O 递进：查询→中断→DMA→通道→I/O 处理机
  5. 总线带宽 = 宽度 × 频率
  6. USB 最多 127；1394 最多 63

T02 网络

  1. 子网主机数 = 2^m − 2 ★
  2. IPv4 32 位 / IPv6 128 位；OSI 7 层 / TCP-IP 4 层
  3. 端口：HTTP 80 · HTTPS 443 · FTP 21 · DNS 53
  4. 以太网帧最小 64 字节

T03 数据库 ★★（错卡重灾区）

  1. ACID：原一隔持
  2. 范式递进：1→2→3→BCNF→4NF
  3. 授权粒度：库→表→行→列（4 级）
  4. 增量备份基于「上次任意备份」；差异基于「上次完全备份」★
  5. 分片设计原则：均衡、相关、可扩展
  6. 分片正确性准则：完备、重构、不相交 ★
  7. 审计=事后；标识鉴别=事前
  8. 备份口诀：物逻分，冷热全增异

T04 企业信息化

  1. SCM 五环节：计采制配退
  2. BI 三组件：仓库 + OLAP + 挖掘
  3. ERP 三阶段：准备→试运行→交付
  4. 电商 B2B/B2C/C2C/B2G/O2O；政务 G2G/G2B/G2C/G2E

T05 软件工程 · UML

  1. CMMI 五级：初可已定优 ★
  2. RUP 四阶段：初细构移 + 三特点（用例驱动/架构中心/迭代增量）
  3. 螺旋每轮四步：计风实评
  4. RAD 五阶段：业数过应测
  5. 模型选型：需求稳→瀑布/V；风险大→螺旋；要快→RAD/敏捷；OO→喷泉/RUP

T06 项目管理

  1. 沟通渠道 n(n−1)/2
  2. PERT 期望 (O+4M+P)/6 ★
  3. 挣值：CV=EV−AC、SV=EV−PV、CPI=EV/AC、SPI=EV/PV ★
  4. CPI/SPI >1 好 <1 差；EAC=BAC/CPI
  5. WBS 100% 规则；网络图单起止单终止无回路无双向

T07 信息安全 ★★（BLP/Biba 曾在库内写反，以本卡为准）

  1. BLP 下读上写（不上读、不下写·保密）；Biba 上读下写（不下读、不上写·完整）★
  2. 可用性 = MTTF/MTBF×100%；R(t)=e^(−λt)、MTTF=1/λ ★
  3. 串联 R=∏Ri；并联 R=1−∏(1−Ri) ★
  4. 模冗余 2n+1 容忍 n 个故障
  5. 等保五级：自审标结验
  6. N 版本=前向恢复/静态；恢复块=后向恢复/动态 ★
  7. 口令极不安全；动态口令一次一密

T09 需求工程

  1. 需求三层：业务/用户/系统（§23a）
  2. 获取五法选型一句话（访谈深/问卷广/观察真/原型快/JRP 共识）
  3. DFD 父子图平衡 ★
  4. include 必选复用 / extend 可选附加 ★

T10 架构

  1. 4+1：场景 + 逻辑/开发/进程/物理
  2. 五大风格族锚词：管道过滤·批处理｜分层·C/S 三层｜仓库·黑板｜解释器·规则｜事件·进程通信 ★
  3. 质量属性六元 + ATAM 敏感点/权衡点

T11 设计

  1. 耦合低→高七级；内聚高→低七级（功能内聚最优）★
  2. SOLID 五原则；ECB 三层
  3. 设计模式三类速记：创建 5 / 结构 7 / 行为 11

T12 测试

  1. V 模型对应：单元↔详细设计、集成↔概要、系统↔需求、验收↔用户 ★
  2. 冒烟=主流程可跑；回归=改后未坏

T13 运维

  1. MTBF = MTTF + MTTR ★
  2. 维护四类：改正/适应/完善/预防（完善占比最大）
  3. 转换四策略：直接/并行/分段/试点（风险↔成本）
  4. 遗留系统四象限：淘汰/继承/改造/集成

T14 案例五域

  1. 微服务四保护：限流/熔断/降级/灰度；CPS-IoT 四层：感知/网络/平台/应用

5. 自测问句化（把结论变问题，检索才有效）

拿卡组任一条自测时，问句化示例：

  1. CPI 公式？大于 1 意味着什么？
  2. 增量备份和差异备份各基于哪次备份？
  3. BLP 模型允许怎么读、怎么写？Biba 呢？
  4. RUP 四阶段口诀？三特点？
  5. 模冗余 2n+1 能容忍几个故障？
  6. 子网主机数公式？为什么要减 2？
  7. PERT 三点估算期望值公式？
  8. 内聚从高到低第七级是什么？最优是哪级？
  9. N 版本和恢复块，谁是前向恢复？
  10. DFD 父子图要满足什么才合格？

6. 与站点的联动

  • 错题→错卡：章练习/真题卷做错后，把解析里的结论抄成一行错卡加入次日复习。
  • 案例日：案例强化计划 D2–D9 的「当天默写骨架」本身就是检索练习，别跳过。
