**看完这一集你能做到**：按六条原则找出数据流图里的错误，并照「错在哪、违反什么、怎么改」三句模板写出踩得到分的答案。

**本讲核心定性**：图是题目给的，分在错误里——这一专题**考的不是画图，是挑错**。题目给你一张数据流图，让你指出错在哪、为什么错、怎么改。图不用你画，你要有的是一套检查清单：会画的人凭感觉找、找到一两处就停；会挑的人按六条原则逐条过、一处都漏不掉。这份清单教材第十一章已经给好了。

1. 四种基本符号（挑错的坐标系）

## 一、只有四种基本符号，多一个就是错（01:25）

| 符号 | 含义 | 表示 | 挑错点 |
| --- | --- | --- | --- |
| **数据流** | 有名字、有流向的数据 | 箭头 | 必须连到**加工**上 |
| **加工** | 对数据流的变换 | 圆圈 | 至少**一进一出**，且要用**动词短语**命名 |
| **数据存储** | 可访问的存储信息 | 直线段 | 整套图里既要**读**也要**写** |
| **外部实体** | 系统之外的人、设备或其他系统 | 方框 | 实体之间**不能有直接数据流** |

**考试怎么考**：第一眼先**数符号**——除了这四种以外出现的东西，基本就是得分点。

---

## 二、检查修改六原则（02:13）——本集最值钱的一页

教材第十一章给出的检查修改六原则：

1. **符号限定**：图上所有图形符号只限于那四种，且**每个元素都必须有名字**——没名字的元素本身就是错。
2. **数据守恒（一进一出）**：每个加工至少有一个输入数据流和一个输出数据流；**输出不与输入同名**，保持数据守恒。
3. **按层编号**：给加工编号，编号要能体现**父图和子图的对应关系**。
4. **父图与子图平衡**：任何一个子图必须与它上一层的一个加工对应，**输入输出数据流必须一致**。
5. **读写俱全**：整套图里每个数据存储必须既有读的数据流，又有写的数据流。
6. **不加控制流**：可以加**物质流**帮助理解，但**不可加控制流**。

> 拿到一张图，就按这六条从第一条问到第六条。

## 三、三层图与编号规则（03:10）

数据流图是**自顶向下逐层分解**的：

| 层 | 内容 | 编号 |
| --- | --- | --- |
| **顶层图** | 整个系统就是一个加工，只画外部实体和进出系统的数据流，作用是把**系统范围**勾出来 | — |
| **0 层图** | 对顶层那个加工做第一次分解，引入新的加工和数据存储 | 1、2、3 依次往下排 |
| **1 层图** | 对 0 层图的加工再分解，一直分到说清楚为止 | 1.1、1.2、2.1 这样排 |

**考试怎么考**：编号本身就是考点——看到编号乱跳，就知道父/子图的对应关系错了。

## 四、数据守恒：黑洞、奇迹与平衡（04:31）

### 父图与子图平衡（原则四，最容易出也最容易漏）

- **不平衡的例子**：父图里加工只有「订单」这一条输入，子图里却多出一条「库存查询」——凭空多出来的数据流就是题目埋的错，数量对不上，一定不平衡。
- **一种情况要小心**：父图一条「订单」，子图拆成了「订单头」和「订单明细」两条，合起来正好是原来那条。教材原话说得很清楚：**数据项的全体正好是父图里那一条，仍然算平衡**，别误判。

### 数据守恒（原则二）

每个加工至少一进一出：

- **只有输入没有输出** → 叫**黑洞**，是错。
- **只有输出没有输入** → 叫**奇迹**，也是错。
- **输出与输入同名**：即使组成完全相同也要换个名字——**同进同出等于这加工什么都没做**。
- **最关键的一句**：一个加工的**所有输出数据流，必须能从它的输入流里直接获得，或由这个加工产生**——凭空冒出来的数据就是错误点。

### 挑错顺序建议

1. 先扫**外部实体之间的直连**
2. 再扫**黑洞与奇迹**
3. 最后**核对父/子图平衡**

## 五、数据字典六类条目（05:17）

图说不清的细节靠**数据字典**补——它是对图上**所有命名元素**给出确切解释。一般有六类条目：

| 条目 | 含义 |
| --- | --- |
| **1. 数据元素**（数据项） | 数据的最小组成单位，如课程号、课程名 |
| **2. 数据结构** | 描述数据元素之间的关系；有**任选项、必选项、重复项**三种特殊情况 |
| **3. 数据流** | 由一个或一组数据元素组成，要写清**来源和去处** |
| **4. 数据存储** | 描述与存储结构有关的数据流和**查询要求** |
| **5. 加工逻辑** | 描述编号、名称、功能、输入、输出、详细逻辑；要借助**判定树、判定表和结构化语言** |
| **6. 外部实体** | 数据的来源和去向，还要写清**实体的数量** |

### 每类条目要写的属性（这张表就是考点）

| 条目 | 属性 |
| --- | --- |
| 数据元素 | 名称、编号、别名、类型、长度、取值范围、取值的含义 |
| 数据结构 | 元素之间的组合关系，标明任选项、必选项、重复项 |
| 数据流 | 名称、编号、简要说明、来源、去处、组成、流通量 |
| 数据存储 | 存储结构、有关的数据流、查询要求——**只列结构，不列内部构成** |
| 加工逻辑 | 编号、名称、功能说明、输入数据流、输出数据流 |
| 外部实体 | 名称、编号、简要说明、产生的数据流、接收的数据流、数量 |

**附加考点**：数据字典由**数据管理员专人维护**，任何人要修改都得经过它——这一点本身也常出题。

**考试怎么考**：让你补写某个条目的描述属性，缺哪几项就是得分点。

## 六、四类典型错误，先扫这四处（07:11）

| # | 错误 | 改法 |
| --- | --- | --- |
| 1 | **实体直连**：两个外部实体之间画了直接数据流 | 中间必须**经过加工** |
| 2 | **黑洞**：加工有输入没有输出（或反过来，即「奇迹」） | 补上缺失的那一侧 |
| 3 | **只写不读**：某个数据存储只有写没有读 | 整套图里必须**读写都有** |
| 4 | **夹带控制流**：图里混进了判断、控制信号 | **控制流不能出现在数据流图上** |

扫完这四处，再回头用六原则逐条过一遍。

## 七、仿真题走一遍（07:52）

> 说明：按教材考点自造的仿真题，非真题。

**题目背景**：某在线教育平台的数据流图里——学员与辅导老师之间画了一条「课程安排」数据流；加工「生成报表」只有输入没有输出；数据存储「选课记录」在整套图里只被写入。

**答案**：

1. **错误一**：学员与辅导老师都是外部实体，它们之间不能有直接数据流。
2. **错误二**：生成报表只有输入没有输出，违反**数据守恒**（黑洞）。
3. **错误三**：选课记录只被写入、没有被读出，数据存储不完整。

三个错误正好对应三类典型错误。真实题目会更绕，但挑错的路径是一样的。

## 八、答题模板：三句话（08:41）

知道错在哪还得写对，答题模板是三句话：

1. **第一句：错在哪**——指出位置。例如「学员与辅导老师之间存在直接数据流」。别绕弯。
2. **第二句：违反什么**——说出规则名称。例如「外部实体之间不应有直接数据流，必须经过加工」。
3. **第三句：怎么改**——给出可执行的改法。例如「去掉这条数据流，改为经『安排课程』加工中转」。

**注意事项**：

- 一处错写三句，三处错就是九句，这就是这一问的完整答案。
- **分条写**，每条一个编号，不要合并成一段。
- 如果题目还要你补数据字典，就按前面那张属性清单逐项检查，缺了哪几项补哪几项。

---

## 九、五个失分点（09:29）

1. **只说错不说规则**：写了「这里不对」，没写违反什么——等于只拿一半分。
2. **漏了父子图平衡**：只盯着一张图看，没跟上一层对照。
3. **把控制流当数据流**：判断条件、触发信号混进图里，是很典型的错。
4. **字典条目写不全**：来源、去处、取值范围这些属性最容易漏。
5. **开始画新图**：题目要求挑错，你却重画一张——时间花了，分却没拿到。

结构化分析是老派方法，讲的是**数据怎么流动**；下一集换到面向对象：用例图、类图、状态图、活动图，以及它们各自的判定规则——很多人卡在分不清**包含关系**和**扩展关系**上。还是同一套结构：教材抓手 → 错误清单 → 仿真题 → 答题模板。
