# 速查 · 分布式一致性与 BPMN

> **docType**：reference

## 分布式一致性（案例/选择）

| 概念 | 一句话 | 场景 |
|------|--------|------|
| **CAP** | 分区容忍 P 下，C 与 A 不可兼得 | 分区时选 CP 还是 AP |
| **强一致** | 读始终最新（如 2PC） | 金融扣款、库存 |
| **最终一致** | 允许短暂不一致，异步收敛 | 微服务、缓存、MQ |
| **Saga** | 本地事务链 + **补偿** | 跨服务长事务 |
| **TCC** | Try-Confirm-Cancel | 需预留资源的高一致业务 |

**答题链**：业务能否接受延迟 → 选一致级别 → 写 **幂等 / 重试 / 对账**

## BPMN vs DFD（业务建模）

| 维度 | DFD | BPMN |
|------|-----|------|
| **侧重** | 数据流、加工、存储 | 业务流程、事件、网关、泳道 |
| **软考** | 系统分析 **结构化** 高频 | 企业信息化、BPR、工作流 |
| **网关** | 无 | 排他/并行/包容网关 |
| **案例** | 0 层/1 层 DFD、平衡 | 流程重组前后对比 |
