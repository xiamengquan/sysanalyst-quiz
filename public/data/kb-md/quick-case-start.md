# 案例作答启动手册 · 告别头脑空白

> **docType**：howto
> **对症**：「知识点其实知道，但案例一看题就头脑空白、写不出第一句」。
> **根因**：知识停留在**定义态**（能背 BLP 是什么），没有转成**答题态**（能写出「该模型不满足 XX，因为材料中 YY」），加上考场是第一次组织语言。
> **解法**：固定启动句式 + 骨架先行 + 每日 30 分钟微训练闭环。两周 ≥10 题，空白自然消失。
> **配套**：[案例四类题型导航](./案例四类题型导航.md) · [考前 14 天冲刺计划](./考前14天冲刺计划.md) · [案例强化 14 天训练计划](./案例强化-14天训练计划.md)

---

## 1. 考场启动流程（每题前 3 分钟，固定动作）

1. **先读问题再读材料**：带着问题读，材料是有目的的检索，不是通读。
2. **材料标号**：把材料中每个技术决策 / 管理动作标 ①②③——案例答案 **90% 藏在材料里**，你缺的不是知识，是「检索钩子」。
3. **小问归类**（考场 30 秒判定，对齐[四类题型导航](./案例四类题型导航.md)）：
   - 「对比 / 选型 / 王工李工」→ **技术方案论证**
   - 「补图 / 填空 / 分层 / DFD / 类图」→ **建模与设计**
   - 「存在问题 / 如何改进 / 优化」→ **问题诊断与改进**
   - 「获取方法 / 干系人 / 需求确认」→ **需求识别与确认**

## 2. 信号词 → 启动句式（空白时先写第一句）

| 题干信号 | 第一句（抄上卷面） | 后续框架 |
|---------|-------------------|----------|
| 存在哪些问题 / 有何不足 | 「该项目/系统存在以下 X 方面问题：」 | 按**管理→技术→过程→人员**四维扫材料，一处标号对应一个问题 |
| 是否恰当 / 可行，说明理由 | 「不恰当（或恰当）。理由如下：」 | **判断先行**，再给 2–3 条依据，每条回扣材料 |
| 请提出改进措施 / 建议 | 「针对上述问题，建议采取以下措施：」 | 问题与措施**一一对应**：几个问题几条措施 |
| 请说明 XX 的作用 / 特点 | 「XX 的作用是……」 | 直接调用总册 M 卡定义态知识（你已有的） |
| 请对比两方案 / 选型 | 「建议采用 X 方案。对比如下：」 | 维度表（性能/成本/演进/风险）+ 结论回扣 |
| 补全 DFD / 类图 / 数据字典 | 先写已知结构 | 从父图-子图平衡、实体-加工对应关系推导缺项 |

> 头脑空白的本质是**启动成本**：第一句永远可以照上表抄，写完第一句就进入检索状态。

## 3. 骨架先行（考场与练笔通用）

每问作答分两步：**先落骨架，再展开成句**。

- **骨架三件套**：①结论句（照 §2 抄）②要点关键词（每条 2–4 字，按分值估点数：2 分一点，宁多勿缺）③材料回扣定位（「如材料中……」）。
- **展开句式**：`要点词 + 一句说明 + 材料证据`。例：「需求确认缺失——未组织评审与用户确认，材料①中需求说明书直接进入开发」。
- 骨架写完即使没时间展开，也有步骤分；**空白是「没启动」，不是「没知识」**。

## 4. 每日 30 分钟案例微训练（两周 ≥10 题）

| 步骤 | 时长 | 动作 |
|------|------|------|
| ① 读题标注 | 5 分钟 | 按 §1：先读问 → 材料标号 → 小问归类 |
| ② 计时骨架 | 10 分钟 | 白纸写骨架 + 展开每问（掐表，营造考场压力） |
| ③ 对照答案 | 10 分钟 | 逐点比对：漏点、框架错位、没回扣材料的点 |
| ④ 一问一卡 | 3 分钟 | 把「我漏的点」写成一张微卡：`题干信号 + 框架 + 我漏的 X` |
| ⑤ 复述重写 | 2 分钟 | 不看答案，把要点口述一遍（输出闭环） |

- 每日选题与主题见[考前 14 天冲刺计划](./考前14天冲刺计划.md) §「案例并行线」；真题入口 `/case`（可按年份/领域筛选，`?bank=real&domain=Web` 深链）。
- 微卡累积进纸面错题本：**每天早上先复述昨天所有微卡**，再开始新题。连续两天都漏的点写进[考前 7 天背诵清单](./考前7天背诵清单.md)。

## 5. 知识点不停：快进法（有底子的省时策略）

- **已掌握模块不重读**：只刷 `/recall` 到期卡（间隔排程自动只给你快忘的）+ 错题回炉。背诵时间省下来的全部投入 §4 案例微训练。
- **案例漏点回灌知识点**：微训练漏的点本质是某个 M/K 卡没记牢（如漏「需求确认」→ 回总册 D2）。当天回对应日次卡片用 `/audio` 洗脑式再循环。
- **建模与设计类**例外：DFD/类图补全是「练出来的肌肉记忆」，不是背出来的——每天 1 小题，两周手熟。

## 6. 头脑空白急救（考场上真的空了）

1. 抄第一句（§2 表，任何小问都有对应启动句）。
2. 扫材料标号 ①②③，把能对上号的标号内容**复述**成要点（复述也有分）。
3. 想不起术语就用白话 + 材料证据：判卷按点给分，**点对就行，词不苛求**。
4. 全部小问先写骨架再回头展开，**任何一问不交白卷**。

---

**一句话**：案例作答 = 启动句式（第一句照抄）+ 材料检索（标号钩子）+ 骨架先行（按分估点）。两周每天 30 分钟，空白从第 5 天开始消失。
