## 核心知识点/概念

### 企业信息化概述

**企业信息化（答卷·定义）**  
企业信息化是企业在生产、经营、管理等活动中**全面应用信息技术**，开发信息资源、培养信息人才，以提升管理与决策水平的过程。  
**作用**：用于提高企业竞争力、优化业务流程、辅助科学决策，实现以信息驱动的高效运营。

- **内涵**：信息技术应用、信息资源开发、信息人才建设。
- **目标**：提高竞争力、优化流程、辅助决策。

### 信息资源管理(IRM)

- **内容**：规划、组织、控制、技术、经济。
- **信息资源规划(IRP)**：梳理业务流程→建立信息体系→建立数据库体系。
- **标准**：数据元素标准、信息分类编码标准、用户视图标准。

### 信息化规划

**与战略规划关系**：信息化战略服从/支撑企业战略；BITA(业务与IT整合)、EITA(企业IT架构)。

**信息系统战略规划方法（答卷·定义）**：

**BSP（答卷·定义）**  
BSP（企业系统规划法）是从企业业务过程出发，通过 U/C 矩阵分析业务与数据类关系，进而导出信息系统总体结构的规划方法。  
**作用**：用于系统性地由业务需求推导出 IS 架构与实施优先级，保证 IT 建设与企业业务一致。

**CSF（答卷·定义）**  
CSF（关键成功因素法）是识别企业实现战略目标所必须把握的关键成功因素，并据此确定信息系统支持重点的规划方法。  
**作用**：用于在资源有限时聚焦最关键的业务环节，使 IS 投资优先支撑核心成功要素。

**SST（答卷·定义）**  
SST（战略集转化法）是将组织战略目标转化为信息系统战略，使 IS 规划与企业战略保持一致的规划方法。  
**作用**：用于确保信息系统建设方向直接承接企业战略意图，避免 IT 与业务战略脱节。

| 方法 | 特点 |
|------|------|
| **BSP** | 企业系统规划，U/C矩阵，由业务到IS |
| **CSF** | 关键成功因素，识别CSF→确定IS需求 |
| **SST** | 战略集转化，将组织战略转为IS战略 |

**ERP（答卷·定义）**  
ERP（企业资源计划）是建立于信息技术之上、以系统化集成管理思想为核心，整合企业内外部资源并提供决策与运营支持的管理平台。  
**作用**：用于打通财务、生产、供应链、人力资源等内部业务模块，实现企业全局资源的统一计划与优化配置。

- **三个角度**：管理思想(MRP II扩展)、软件产品(模块化→集成化)、管理系统(六大功能目标)。
- **主要模块**：生产、财务、供应链、人力资源、销售等。
- **实施阶段**：前期准备→试运行→交付收尾。
- **开发模式**：套装二次开发 / 定制开发。

**CRM（答卷·定义）**  
CRM（客户关系管理）是以客户为中心、整合销售、营销与服务流程，实现客户关怀与价值提升的管理系统。  
**作用**：用于管理客户全生命周期、提升客户满意度与忠诚度，并通过与 ERP 集成实现前后端业务协同。

- 组成：触发中心 + 挖掘中心；须与ERP集成。

**SCM（答卷·定义）**  
SCM（供应链管理）是贯穿计划、采购、制造、配送、退货等环节，对供应链上下游进行集成协同的管理系统。  
**作用**：用于优化供需匹配、降低库存与物流成本，实现供应商、制造商与分销商的高效协同。

- 关键：需求预测、库存优化、供应商协同。

**PDM/PLM**：

- **PDM**：产品数据管理，管理研发过程数据。
- **PLM**：产品生命周期管理，覆盖概念→报废全过程。

**KM(知识管理)**：知识获取、存储、共享、应用。

**BI（答卷·定义）**  
BI（商业智能）是对企业内外部数据进行采集、清洗、存储、分析与展现，以支持管理决策的信息系统。  
**作用**：用于从海量历史数据中发现规律与趋势，为管理层提供可视化分析与决策依据。

- 四阶段：数据预处理→数据仓库→数据分析→数据展现。
- 三大组件：**数据仓库 + OLAP + 数据挖掘**。

**企业门户(EIP)**：信息聚合、个性化、单点访问。

**DSS(决策支持系统)**：模型库+知识库+数据库，辅助半结构化决策。

### 电子商务

| 类型 | 说明 |
|------|------|
| B2B | 企业对企业 |
| B2C | 企业对消费者 |
| C2C | 消费者对消费者 |

- **技术**：Web、EDI、支付、安全(加密/认证/CA)。

### 业务流程重组(BPR)

- **定义**：对企业业务流程根本性再思考、彻底性再设计，以实现成本/质量/服务/速度改善。
- **原则**：以流程为中心、以客户为导向、IT使能。
- **与BPI区别**：BPR=根本性/彻底性；BPI=渐进式改进。

### 企业应用集成(EAI)

**EAI（答卷·定义）**  
EAI（企业应用集成）是通过技术手段将异构应用系统、数据与业务流程连接贯通，使企业 IT 资源协同工作的集成方案。  
**作用**：用于消除信息孤岛、实现跨系统数据共享与流程联动，支撑 ERP/CRM/SCM 等系统的协同运行。

| 层次 | 定义（答卷） | 作用（答卷） |
|------|-------------|-------------|
| **数据集成** | 数据集成是在不同应用系统之间实现数据的共享、复制或同步 | 用于保证各系统访问一致的数据副本，解决数据不一致问题 |
| **应用集成** | 应用集成是通过 API、中间件等技术实现应用系统之间的功能调用与互操作 | 用于使异构应用能够协同完成跨系统业务操作 |
| **界面集成** | 界面集成是将多个应用系统的用户界面聚合到统一入口（如企业门户） | 用于为用户提供单点访问体验，无需切换多个系统界面 |
| **过程集成** | 过程集成是通过工作流/BPM 引擎编排跨系统的业务流程 | 用于实现端到端业务流程自动化，使多个系统按业务规则协同流转 |

- **事件驱动EAI**：基于消息/事件的松耦合集成。

## 易混对比

| 对比项 | BSP | CSF | SST |
|--------|-----|-----|-----|
| 定义 | BSP 是从业务过程出发导出 IS 结构的规划方法 | CSF 是识别关键成功因素并确定 IS 重点的规划方法 | SST 是将组织战略转化为 IS 战略的规划方法 |
| 出发点 | 业务过程 | 关键成功因素 | 组织战略 |
| 工具 | U/C矩阵 | CSF分析 | 战略映射 |
| 特点 | 系统性 | 重点突出 | 战略导向 |

| 对比项 | ERP | CRM | SCM |
|--------|-----|-----|-----|
| 定义 | ERP 是整合企业内部资源的全局管理平台 | CRM 是以客户为中心的前端关系管理系统 | SCM 是贯穿上下游的供应链协同管理系统 |
| 核心 | ERP 的核心是内部资源（人财物产供销）的集成管理 | CRM 的核心是客户关系与前端营销服务流程 | SCM 的核心是供应链上下游的计划与物流协同 |
| 目标 | ERP 的目标是优化企业内部资源配置与运营效率 | CRM 的目标是提升客户价值与客户满意度 | SCM 的目标是降低库存成本并实现供需高效匹配 |
| 范围 | ERP 覆盖企业全局内部业务 | CRM 聚焦前端客户接触点（销售/营销/服务） | SCM 聚焦上下游供应商、制造与分销环节 |

| 对比项 | PDM | PLM |
|--------|-----|-----|
| 范围 | 产品数据 | 全生命周期 |
| 重点 | 研发数据管理 | 概念到报废 |

| 对比项 | BPR | BPI |
|--------|-----|-----|
| 变革程度 | 根本性/彻底性 | 渐进式 |
| 风险 | 高 | 低 |
| 适用 | 流程严重落后 | 局部优化 |

| 对比项 | BI | DSS |
|--------|-----|-----|
| 数据 | 历史海量 | 模型+数据 |
| 功能 | 分析展现 | 辅助决策 |
| 用户 | 管理层 | 决策者 |

| 对比项 | BITA | EITA |
|--------|------|------|
| 侧重 | 业务与IT对齐 | 企业IT架构 |
| 适用 | IS不能满足业务 | 架构规划 |

## 常考数字/结论/口诀

- 电商类型：**B2B/B2C/C2C/B2G/O2O**。

## 应试钩子

**案例可能怎么问**：按业务场景选 ERP/CRM/SCM/BI；BSP/CSF/SST 规划方法选型；EAI 集成层次（数据/应用/界面/过程）与 CRM-ERP 集成关系。

**论文怎么用**：企业数字化转型类可写「以 ERP 为核心、CRM 管前端、SCM 连上下游、EAI 打通孤岛」的集成架构；信息化规划段引用 BSP/CSF 方法论证 IS 与战略对齐。
