# 知识点精炼 · 答卷写法准则 v1.1

> **状态**：编制委员会强制规范 · 2026-09-13 起  
> **适用范围**：`content/kb/` 全部分章精炼、速查路径、高频对比表中的「定义 / 作用」条目  
> **依据**：结构化与 OO 分析路径 §0.1；近期案例真题答卷口径（需求三层、RTSAD、分片原则等）

---

## 1. 强制句式

| 类型 | 必须写成 | 禁止 |
|------|----------|------|
| **定义** | 「**X 是……**」完整句（含对象 + 本质特征） | 仅关键词、电报体、「X：……碎片」 |
| **作用** | 「**用于……**」或「**主要作用是……**」 | 仅「隔离」「扩展」等二字标签 |
| **原则 / 方法名** | 写全名 + 一句展开（如「数据均衡性原则是指……」） | 只列「均衡、相关、可扩展」三个词交差 |

口诀、前端类比、助记表：**允许**，但**不得替代**答卷句；文中宜标注「助记，不当答卷正文」。

## 2. 版式约定

1. 核心概念标题旁可加 `（答卷）` / `（答卷·定义）` / `（答卷·必背）`  
2. 同章易混概念用对比表；表内「区别」列尽量是完整短句  
3. 章末保留「易混对比」「应试钩子」（案例可能怎么问 / 论文怎么用）  
4. 禁止大段粘贴教程/真题原文；举例用自拟场景或公开题意概括  

## 3. 自检（编制乙/丙交稿前）

- [ ] 合上材料后，能否用完整句回答「什么是 X？X 的作用是什么？」  
- [ ] 案例若问「核心原则至少 2 个」，文中是否有可直接誊写的全名+展开  
- [ ] 与相邻章术语是否统一（如 BCE / 分片键 / 业务·用户·系统需求）  

## 4. 发布门禁衔接

- 新写/大改章节须按本准则自检后再入 `编制委员会/草稿/` 送审  
- 审计乙核对口径；审计丙核对「可背、可誊」  
- 全员通过后方可升正式版号（v1.1+）并 `sync:kb` 挂站  

## 5. 与 v1.0 关系

v1.0（2026-09-10）已全员通过结构与覆盖。**v1.1 为答卷化增强修订**：不推翻篇章节目录，按缺口盘点分批把高频考点改为可答卷表述。
