# 知识点 · 结构式重写模板 v2（编制委员会 · 结构统稿）

> 适用范围：`content/kb/points/kp-*.md` 全部 174 篇。
> 目标：每篇考点统一为同一骨架，标题层级可导航、无占位话术、无重复内容块。

## 1. 统一骨架（8 节，顺序固定）

```markdown
# 考点标题
> **大纲**：N.N · **教程**：第N章 · **分组**：… · **状态**：结构式重写 v2.0 · 审计通过

## 概述          ← 一句话定位 + 本章考什么（禁止出现两处）
## 速懂          ← 一句话 / 考什么 / 具体理解 / 别搞混（只留实义内容）
## 定义          ← 答卷·定义句式，一条一概念（禁止万能占位「作用」句）
## 步骤与流程    ← 有实义步骤/流程才保留；无则整节删除（不留占位）
## 要点          ← 正文主体；旧章内容平铺至此，子节用 ### （禁旧编号）
## 易混辨析      ← 统一节名；对比表挂此节（禁止「易混对比」变体）
## 应试          ← 案例怎么问 / 论文怎么用 / 常考结论 / 练题入口
## 相关考点      ← 内链 + 归档通章
```

## 2. 禁止项（审计即判违规）

1. **多个一级标题**：正文只允许文件首一个 `# `；旧整章头 `# 第N章 …` 一律删除。
2. **占位话术**：
   - 「本节在教程中未单独列出固定步骤名」引导的空壳「步骤与流程」节；
   - 「与同章相邻考点区分」（速懂·别搞混）；
   - 「（本节与相邻考点易混点见归档篇章…）」「（检索关键词：**X**。）」；
   - 万能作用句「**作用**：用于题干场景下的概念识别、对比选型与案例/论文回扣。」。
3. **节名变体**：「易混对比」「核心知识点/概念」「本章考什么」不得作为节名出现。
4. **旧编号残留**：`### 一、` `### 2.1 ` 等教程章内编号一律去除，仅保留标题文字。
5. **重复内容块**：同文 ≥20 字符行第二次出现即删；「流程要点」等小节标题不得重复。
6. **残缺表格**：表头列数与数据行列数不一致即违规（需内容级修复）。

## 3. 处理规则（归一脚本 `scripts/python/rewrite_kb_structure.py`）

| 乱象 | 处理 |
|------|------|
| 嵌入旧整章 H1 | 删 H1 行 + 紧随 `> 出自…` 行与 `---` |
| `## 本章考什么`（含「一、」变体） | 与概述重复则删节；否则并入 `## 概述` |
| `## 核心知识点/概念`、`## 二、…要点` 等旧壳 H2 | 删壳行，子节内容挂到 `## 要点` 下 |
| `## 易混对比` / `## 三/四、…易混对比` | 改名 `## 易混辨析`；原占位辨析节删除 |
| `## 常考数字/结论/口诀` | 整块移动为 `## 应试` 下的 `### 常考数字/结论/口诀` |
| 空壳步骤节 | 整节删除 |
| 万能占位句 | 按第 2 条逐句删除 |
| 重复行/重复小节标题 | 第二次出现删除 |
| 状态行 | `工坊精修 vX.Y.Z · 审计通过` → `结构式重写 v2.0 · 审计通过` |

## 4. 发布门禁

1. `python3 scripts/python/rewrite_kb_structure.py`（归一）+ `audit_kb_structure.py`（复检 0 问题）
2. 残缺表格等少数内容级问题手工修复后复检
3. `npm run sync:kb` → `check:release` → 升版发日志（知识点变更必记）
