# 知识点内容架构 v3 · 四层七日模型（架构规格）

> 版本：v3（2026-10-10）· 状态：正式 · 取代：v2 结构式八节模板（作为学习路径主文档地位）
> 落地物：`content/kb/速查/四层七日背诵总册.md`（学习主文档）

## 1. 为什么要重构

v2 架构（174 篇 × 八节模板）解决了「结构乱、占位多、易混表残缺」的问题，但它是**按考点组织的字典**，不是**按学习行动组织的教材**：考生仍然要自己回答「今天学什么、背哪些、放哪些、怎么复习」。v3 把组织维度从「考点」翻转为「背诵行动」：

- **四层结构**回答「背到什么深度」；
- **七日模型**回答「什么时间背什么」；
- **强化记忆块**把间隔重复（1-2-4-7-15）、默写提取、错卡回收内嵌到每天文档里。

## 2. 四层结构定义与判定

| 层 | 代号 | 深度 | 判定标准 | 呈现形态 |
|----|------|------|----------|----------|
| 必会 | M | 默写级 | 近 12 年真题反复出现；考场可直接誊写 | 一张卡 = 名称 + 一句话/公式/口诀（≤2 行） |
| 重点 | K | 理解会做 | 高频但需理解运用：对比、计算、辨析 | 对比表要点 + 题型流程；遮列默写 |
| 补充 | S | 眼熟即可 | 大纲内低频；做对选择题即可 | 一行一条，速览；抽屉点开即查 |
| 可放弃 | D | 止损 | 出现即主动放弃：性价比极低的深水区 | 对象 + 判定信号 + 替代动作（写结构分/换题） |

判定依据（可复核）：真题题型分布（论证 23/建模 23/诊断 9/需求识别 4）、章热力（需求 177>数据库 84>架构 81>安全 78>计组 69…）、题库 stop_loss 标记（22 道）、考点 slug 的 outlineRef 分布。

## 4. 日册文档模型（每天固定六块）

```
## Dn · 主题（教程章 · 梯队）
### 必会 · 默写卡（M）      ← 逐卡默写，写不出=错卡
### 重点 · 辨析与题型（K）  ← 遮右列默写 + 会算
### 补充 · 速览（S）        ← 眼熟即可，抽屉即查
### 可放弃 · 止损（D）      ← 判定信号 + 替代动作
### 强化记忆块
  - 回收：D-1 / D-3 / D-7 卡组默写（1-2-4-7-15 节奏）
  - 自测问句 5 条（检索练习）
  - 错卡规则：连续 3 次全对销卡
### 练题收口
  - 章练习链接 + 真题卷日安排
```

## 5. 迁移策略（旧内容处置）

- **旧 174 篇 v2 考点文档：降级为「字典层」保留**。理由：真题/案例/地图/抽屉/考试链接全部依赖其 id 与标题，物理删除将大面积断链；其内容已过 8 轮审计与结构式重写，作为四层内容的「详情源」仍有价值。
- 学习路径主文档地位移交《四层七日背诵总册》；旧文档不再作为背诵入口，仅通过 `《》` 抽屉引用在 S 层/M 层详情时进入。
- 《考前 7 天背诵清单》《记忆强化卡组》《知识点地图》保留，作为总册的配套（卡组=总册 M 层的数字版，地图=全量索引）。
- 后续新增考点内容一律按 v3 日册模型撰写；v2 模板仅用于新增「字典层」条目。
