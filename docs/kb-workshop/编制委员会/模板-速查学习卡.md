# 模板 · 速查 / 体系化学习卡

复制到 `content/kb/速查/<文件名>.md` 后替换占位。须同步登记 `content/kb-index.json`。

```markdown
# <标题>

> **docType**：reference | tutorial | howto  
> **对齐大纲**：<大纲 § 或 教程第 N 章>  
> **对齐真题**：<卷次·题号，无则写「综合知识/案例通用」>  
> **用途**：<选择 / 案例 / 论文 / 填表>  
> **关联章节**：<正文章路径或章名>

---

## 一、<核心概念>（答卷·定义）

**<术语>（答卷·定义）**：<术语>是……；**用于**……

（助记：…… —— 助记，不当答卷正文）

---

## 二、<对比 / 约束 / 步骤表>

| … | … |
|---|-----|

---

## 三、<案例或真题口径>

（可选：官方表题判题摘要）

---

## 四、自测清单

1. …

**站内练习**：<相关 point 或章节刷题路径>
```

## 登记 `kb-index.json` 示例

```json
{
  "id": "quick-<slug>",
  "title": "<侧栏标题>",
  "path": "速查/<文件名>.md",
  "status": "正式",
  "kind": "quick",
  "docType": "reference",
  "note": "<一句话>"
}
```

`docType` 为 `tutorial` 时，`note` 建议含「L0→L4」或「由简入深」。
