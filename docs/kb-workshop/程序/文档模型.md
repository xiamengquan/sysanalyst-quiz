# 知识点 · Dev Docs 文档模型

> 借鉴开发者文档常见分层（Diátaxis）：**Tutorial / How-to / Reference / Explanation**，与本站 `content/kb/` 目录、`kb-index.json` 的 `kind` 对齐。  
> 编制、审计、挂站均按本模型归类，避免「速查堆里混教程、正文章缺入口」。

## 1. 四类文档与站点映射

| Dev Docs 类型 | 读者目标 | 本站载体 | `kind`（索引） | 典型路径 |
|---------------|----------|----------|----------------|----------|
| **Explanation** 解释 | 理解概念与权衡 | 分章精炼 | `chapter` | `第一篇…/第NN章-*.md` |
| **Reference** 参考 | 查表、对口径、背定义句 | 速查表、缩写卡、对比卡 | `quick` | `速查/高频对比速查表.md`、`速查/*卡.md` |
| **Tutorial** 教程 | 按关卡由浅入深 | 体系化学习路径/指南 | `quick` + `docType: tutorial` | `速查/*-体系化学习路径.md` |
| **How-to** 操作 | 完成一类题/填一类表 | 案例方法、必答卡 | `entry` / `quick` + `docType: howto` | `案例分析答题教程.md`、`速查/案例必答-*.md` |

**导航类**（非 Diátaxis 正文，但索引必需）：`kind: entry`（知识地图）、`kind: index`（篇索引）、`kind: appendix`（附录/范文）。

## 2. 权威源与镜像

| 角色 | 路径 | 说明 |
|------|------|------|
| **唯一权威源** | `content/kb/` | 仅改此处；须符合《答卷写法准则 v1.1》 |
| **目录注册表** | `content/kb-index.json` | 每篇一条：`id`、`path`、`kind`、可选 `docType` / `chapter` / `note` |
| **站点镜像** | `public/kb/` | `npm run sync:kb` 全量复制，不手改 |
| **搜索索引** | `public/data/kb-search-index.json` | sync 时由 `scripts/build-kb-search.mjs` 生成 |

## 3. 新增/修订一篇的决策树

```text
要新增内容？
├─ 讲清一章考点体系 → chapter（Explanation）→ 挂对应篇 index + 知识地图 §2.2
├─ 对比/定义/口诀可查 → quick + docType: reference → 高频对比表加锚点或独立卡
├─ L0→L4 闯关学习 → quick + docType: tutorial → 知识地图「按基础」链入
├─ 案例怎么写/怎么填表 → howto → 答题教程或案例必答卡
└─ 仅工坊流程/审计 → docs/kb-workshop/（不进 content/kb）
```

## 4. 文首元数据（速查/教程/How-to 强制）

速查目录下新建 Markdown，文首 blockquote 须包含：

| 字段 | 必填 | 示例 |
|------|------|------|
| `docType` | 是 | `reference` / `tutorial` / `howto` |
| `对齐大纲` | 是 | 大纲 § / 教程章号 |
| `对齐真题` | 选填 | 卷面定位 |
| `用途` | 是 | 选择/案例/论文 |
| `关联章节` | 选填 | 正文章跳转 |

模板见 `编制委员会/模板-速查学习卡.md`。

**Explanation（chapter）**：章首保留「出自…分章」；核心概念用「答卷·定义/作用」句式，见答卷写法准则。

## 5. 交叉引用约定

- 正文章 → 速查：`` `速查/xxx.md` `` 或站点内 `/kb/` 等价路径（sync 后一致）
- 速查 → 正文章：写「完整展开见第 N 章 …」
- **禁止**：仅在 `public/kb` 改文；禁止未入 `kb-index` 的 orphan 文件（搜索与侧栏不可见）

## 6. 发布门禁（与总章程一致）

1. 草稿 → 三席审计 → `审计委员会/正式发布/` 升版  
2. 合并 `content/kb/` + 更新 `content/kb-index.json`  
3. `npm run sync:kb`  
4. 站点 `package.json` 升 patch + `release-notes.json`（知识点变更必记）
