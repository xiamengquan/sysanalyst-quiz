# 知识点工坊 · 总章程

面向「系统分析师知识点精炼」内容生产与发布，与「出题工坊 · 细则审计委员会」平行运作。

## 双委员会

| 委员会 | 职责 | 产出 |
|--------|------|------|
| **编制委员会**（3 人） | 起草/修订知识点精炼 | `编制委员会/草稿/` |
| **审计委员会**（3 人） | 独立审计草稿 | `审计委员会/意见/` |
| **主席（编排）** | 计票；仅全员通过才发布 | `审计委员会/正式发布/` |

**正式发布 ⇔ 审计甲 ∧ 乙 ∧ 丙 均为「通过」。**  
有条件通过 / 驳回 → **发回编制委员会重编**，不得发布。

## 流水线

```text
编制甲∥乙∥丙 分工起草/统稿
    → 草稿入 编制委员会/草稿/
    → 审计甲∥乙∥丙 并行独立审计
    → 主席汇总
         ├─ 未全员通过 → 修订任务单 → 编制重编 → 再审
         └─ 全员通过 → 正式发布/ + 同步覆盖精炼正文目录
```
