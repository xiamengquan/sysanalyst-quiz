### 3.2 第14章子标题序号错位 — 阻塞

第14章 v1.1 大改后仍保留教程遗留编号：

```
## 二、软件实现与测试要点
  ### 4.1 …
  ### 4.2 …
## 三、测试类型与阶段（重点）
  ### 5.1 …
  ### 5.2 …
  ### 5.3 …
```

上级为「二/三」，下级为「4.x/5.x」，大纲 TOC 与文内交叉引用（如「见 §4.2」）均不可可靠解析。本轮对该章答卷块改动最大，应同步重编号为 **2.1/2.2、3.1/3.2/3.3**（或补全缺失的「一、…四、…」结构）。

### 3.3 第10章易混对比表 — 版式观察（不阻塞）

`## 七、第10章易混对比表` 使用「对比项 | A | B」三列，与同章前文及他章「对比 | 区别」两列风格不同；首行「TFD vs DFD」仍为短语，与同表「逻辑 DFD vs 物理 DFD」长句混排。不影响节存在性，建议统稿时对齐表头模板。
