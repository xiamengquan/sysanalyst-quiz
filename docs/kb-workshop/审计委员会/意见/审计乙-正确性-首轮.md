### 5. 高频对比速查表

| 位置 | 问题类型 | 说明 |
|------|----------|------|
| **§23 范式对比 · BCNF 行** | **事实错误（张冠李戴）** | 写「消除：主属性对码的依赖」——**错误**。BCNF 消除的是**决定因素不是候选码（超键）的函数依赖**；「主属性对码的依赖」语义含混，且与第5章易混表及 3NF「消除传递依赖」混淆。 |
| §5 vs 第5章 | 术语不一致 | 速查用「差分备份」，第5章用「差异备份」——同义，建议统一以免考生搜不到。 |

| §24 Redis CAP | 边界模糊 | 标「CP/AP」过宽；Redis 主从/集群模式下 C/A 取舍不同，非硬错误，宜加「视部署与配置而定」。 |
| §20 MD5 | 正确 | 已注「MD5 已不安全」，符合当前安全共识。 |

## 必须修改（阻塞）

### B-1 · 速查表 BCNF 条目张冠李戴

**文件**：`速查/高频对比速查表.md` §23  

**现状**：
```markdown
| **BCNF** | 主属性对码的依赖 |
```

**修改为**：
```markdown
| **BCNF** | 决定因素不是候选码（超键）的函数依赖 |
```

**理由**：与第5章正文及软考标准定义一致；现行表述会误导考生把 BCNF 与 3NF 的「传递依赖」混为一谈。

---

### B-2 · 知识地图复习路径章节编号错误

**文件**：`00-使用说明与知识地图.md` §3.2  

**现状**：
```markdown
周3—4：第一篇 5—8章 + 第二篇 9—11章
```

**修改为**：
```markdown
周3—4：第一篇 5—9章 + 第二篇 10—11章
```
（或等价表述：「第一篇 5—8章 + 第9章 + 第二篇 10—11章」）

**理由**：第9章属第一篇「信息安全」，不可划入第二篇；否则与 §2.2 知识地图及教程三篇结构矛盾。
