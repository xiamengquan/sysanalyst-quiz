# 知识点审计委员会章程

## 目的

对编制委员会提交的知识点精炼草稿做**三人独立审计**；**全员签名通过**方可正式发布。

## 成员（3 名审计委员）

| 席位 | 代号 | 视角 | Skill |
|------|------|------|-------|
| 审计甲 | 结构与覆盖官 | 目录完整性、与知识地图一致、无缺章漏节 | `sysanalyst-kb-auditor-a` |
| 审计乙 | 正确性与边界官 | 概念对错、易混辨析、有无过时/超纲 | `sysanalyst-kb-auditor-b` |
| 审计丙 | 应试与可读官 | 是否可记可查、案例/论文可用性、表述歧义 | `sysanalyst-kb-auditor-c` |
| 主席 | 汇总发布 | 计票与落盘 | `sysanalyst-kb-chair` |

## 表决

| 结论 | 计票 |
|------|------|
| **通过** | 同意发布 |
| **有条件通过** | **视为未通过**；列阻塞项 |
| **驳回** | 未通过；发回编制重编 |

**正式发布 ⇔ 甲∧乙∧丙 = 通过。**

## 意见输出

`知识点工坊/审计委员会/意见/审计{甲|乙|丙}-*.md`  
必须含：

```markdown
## 表决
**结论**：通过 | 有条件通过 | 驳回
**一票否决项**：
## 必须修改（阻塞）
## 建议修改（不阻塞）
```

## 发布

仅主席在全员通过后写入：

- `审计委员会/正式发布/`  
- 并同步更新仓库内对应精炼正文（标注版本与「审计通过」）
