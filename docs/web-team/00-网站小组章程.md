# 题库网站小组章程

## 目的

负责系统分析师**本地/可部署题库站点**的产品设计与程序实现，将正式题库与（审计通过后的）知识点精炼接入可刷题、可导航的 Web 界面。

## 成员（3 名）

| 席位 | 代号 | 职责 | Skill（工程内 `.cursor/skills/`） |
|------|------|------|-------|
| 设计 | UX/信息架构 | 信息架构、页面线框、视觉与交互规范 | `sysanalyst-web-design` |
| 程序 | 全栈实现 | 前端页面、题库加载、筛选/连续作答/进度、构建脚本 | `sysanalyst-web-dev` |
| 协调 | 站点经理 | 需求优先级、与出题/知识点工坊对齐、发布检查 | `sysanalyst-web-pm` |

## 输入（只读权威源）

| 源 | 路径 | 说明 |
|----|------|------|
| 练习题 | `content/banks/practice/all.jsonl` | 须为评审通过版本 |
| 真题解析 | `content/banks/real/上午真题.jsonl` | 个人学习用 |
| 工坊新题 | `content/workshop/new/*-passed.jsonl` 等 | `npm run sync:data` |
| 正式细则 | `docs/question-workshop/委员会/正式发布/` | 展示策略可参考双轨 |
| 知识点正式稿 | `docs/kb-workshop/审计委员会/正式发布/` | **未发布不得当正式内容挂站** |
| 站点实现 | `src/` | Next.js 静态导出基线 |

## 产出目录

```text
docs/web-team/
  00-网站小组章程.md          # 本文件
  设计/                      # IA、线框、视觉说明 + ROLE.md
  程序/                      # 实现说明、supabase/portal 等 + ROLE.md
  发布/                      # 需求看板、版本说明 + ROLE.md
src/                         # ★ 站点源码
public/data/ · public/kb/    # 同步产物
```

## 工作原则

1. **内容与程序分离**：小组不直接改知识点对错、不擅自出题；发现内容问题提工单给对应委员会  
2. **本地优先**：默认 `npm run dev` 或静态导出托管即可运行；不强制后端账号体系  
3. **隐私**：进度可存 localStorage；不上传用户答题数据到公网  
4. **发布门禁**：挂载「正式知识点」前须存在审计委员会发布记录  

## 当前优先级（v1 站点）

1. 信息架构：刷题 / 真题 / 工坊 / 知识点导航 / 关于与合规说明  
2. 在现有 `src/` 站点上升级导航与知识点只读浏览  
3. 设计规范一页纸 + 程序实现清单
