## 四、对体系建设的含义（M2/M3 输入）

1. **出题区不只有 5 条专题路径**：Web / 需求 / 数据库 / 移动 / 微服务 / 嵌入式 / 集成 / 大数据 / CPS / 架构 / 测试 / 安全 / 运维均有真题落地；「移动」「嵌入式」「大数据」「集成」尚未建专题路径，M3 需补齐。
2. **题型三巨头**：技术方案论证（70）、建模与设计（67）、问题诊断与改进（54）——答题模板与步骤链应按这三类套路组织，而非按知识点平铺。
3. **问法可枚举**：compare（141）/ design（261）/ short（184）——每考点「怎么考」字段应标注该考点最常落入的问法。
4. **删除数据的恢复通道**：全部源数据在 git 历史（快照 commit）中，题目正文的最终处置遵循「不留站」决策。
