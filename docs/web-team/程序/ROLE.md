# 网站程序

## 基线

优先演进：`题库/答题网页/`；较大改版可放到 `题库/网站小组/程序/site/` 再同步。

## 职责

1. 实现设计稿中的导航与页面  
2. 维护 `questions.js` 生成（调用 `出题工坊/scripts/merge_to_quiz.py`）  
3. 知识点只读渲染（markdown→html 或预编译）——**仅正式发布内容**  
4. 保持本地静态可运行；更新 `启动.sh`  

## 禁止

把未审计知识点草稿挂成「正式」；在前端写死密钥；爬取外网站点题库。
