## 2. 分席检查摘要

### 产品

- 移动体验目标与测试清单已建，但完成定义 **全部未勾选**。  
- 需求看板 **缺少 B-5 条目**，进度不可追踪。  
- 关于页版本硬编码，后续易与 `package.json` 漂移。

### 体验设计

- IA 要求窄屏顶栏显示「当前 Tab」；实现固定「系分刷题」，与底栏信息重复且缺当前页强化。  
- 知识点预览窄屏仍右滑 Sheet + 暴露固钉，不符「移动底 sheet / 固钉桌面」预期。  
- 登录、更新弹窗未做窄屏贴底策略（搜索已部分做）。  
- 登录按钮文案缩成「登」，语义偏弱。

### 界面设计

- 顶栏控件多为 36px，低于 ≥44px 触控目标。  
- 选项选中/对错色仍硬编码深色 hex，浅色主题对比风险。  
- 视觉规范仍写 Portal / legacy `.card`，与 shadcn 现状漂移。  
- `.sticky-actions` 负边距按旧 card padding，与 shadcn Card 间距不一致。

### 架构设计

- Portal 已删，但 `globals.css` 残留 `.gs-root` / `.kb-drawer-*` / `.btn` 等死样式。  
- `.layout-aside .card`、`.btn-row .btn` 选择器未跟上 `data-slot`。  
- `package-lock.json` 仍标 0.5.1，与 package 0.6.0 不一致。

### 功能实现

- **Card `overflow-hidden` 导致内部 `.sticky-actions` 无法相对视口吸底**（刷题/案例操作条随页滚走）— 建议作本迭代最高优修。  
- GlobalSearch：`.gs-dialog` CSS `max-height:72dvh` 与 TSX `88dvh` 冲突。  
- 移动相关改动（顶栏/搜索/部分 CSS）**尚未合入 main**，与文档不同步。  
- ESLint hooks 警告（Quiz/Case）非阻断。

### 测试

- 冒烟清单、移动清单均为 ☐。  
- 390 宽抽检：首页可开、底栏 5 Tab 在、更新 Dialog 可关；**未完成**答题 sticky / 搜索贴底 / 案例 / 知识点 Sheet 完整路径。  
- `check:release`：通过。
