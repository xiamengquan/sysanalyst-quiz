# 移动体验目标

> 产品席位 · 2026-09-19 · 对齐站点 v0.6+ · 看板 **B-5**

## 原则

1. **主路径不换手**：手机单手可完成「开刷 → 选题 → 看解析 → 下一题」  
2. **底栏神圣**：固定 Tab 与 Home 指示条区域内，不放置不可达主按钮  
3. **顶栏克制**：窄屏只保留必要控件；当前页状态以底栏为准，避免顶栏再堆标签  
4. **触控达标**：可点控件短边 ≥ 44px；选项行 ≥ 48px  
5. **浮层可关**：搜索 / 登录 / 知识点预览在移动端须有明确关闭与 Esc/遮罩  

## 视口基线

| 档 | 宽 | 用途 |
|----|-----|------|
| 手机 | 390×844 | 默认验收 |
| 小屏 | 360×640 | 防溢出抽检 |
| 平板 | 768 | 底栏隐藏、顶栏导航出现 |
