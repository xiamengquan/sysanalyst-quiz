# B-6 · 样式正确性走查

> **组织**：产品 · 2026-09-19  
> **触发**：知识点抽屉「整页打开」与同页其他按钮不一致  
> **席位**：界面审计 → 实现落地 → 测试抽检  

## 用户感知目标

同一面板内主 CTA / 次要 / 工具钮分工清晰；light/dark 可读；触控高度统一。

## 根因（界面审计）

1. `a { color: inherit }` 盖掉 `Button asChild` + `Link` 的 variant 字色  
2. `.kb-drawer-foot` 未接入 sticky-actions 触控高度  
3. 抽屉脚未全宽；若干 light 弱反馈 / 硬编码色 / Dialog 层级低于顶栏  

## 本轮已落地（实现）

- 锚点按钮色、抽屉脚高度+全宽  
- outline 浅色底、选项 hover、进度条/案例要点 token 色  
- Dialog/Sheet 默认 z-80；知识点抽屉保顶栏可见（z-60/65 + 顶偏移）  
- 规范 §4.1 / §6.6 与看板 B-6 条目
