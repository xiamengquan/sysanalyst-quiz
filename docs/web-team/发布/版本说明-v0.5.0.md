# 版本说明 · v0.5.0

> 发布：网站程序 · 2026-09-19

- 案例分析：五选三模拟与真题增加「七步法」选项卡
- 可选云同步：Magic Link + 显式开启后同步刷题/案例进度
- 数字等宽：IBM Plex Sans + `tabular-nums`
- 版本更新通知：新部署首次打开提示本版要点

## 发版时

1. 改 `public/data/release-notes.json` 的 `version` 与 `highlights`
2. （建议）同步 bump `package.json` version
3. 部署后用户浏览器会弹一次「知道了」；`localStorage.sysanalyst_release_seen` 记住已读版本
