# 版本说明 · v0.6.5

> 发布：网站程序 · 2026-09-22  
> 依据：站点更新必记日志规范 · 移动端样式深度调试与体验闭环修复

## 本版变更

### 移动端交互与视觉优化（体验 / UI）

- **重塑移动端底部导航栏（Tabbar）**：
  - **问题**：原底栏仅有 5 个中文短词与横线指示器，无图标支撑，在移动端呈现出简陋且不符合原生 WebApp 体验的空旷感。
  - **修复**：在 `SiteHeader.tsx` 底栏引入与 Cursor 风格统一的线性图标（`ListChecks` 刷题、`FileText` 案例、`BookOpen` 知识、`Sparkles` 更新、`Info` 关于），配合当前选中项微放大（scale-105）与精细顶线指示条，形成高质感的移动端 Tabbar。

- **窄屏顶栏操作区高低与圆角统一**：
  - **问题**：此前顶栏在窄屏下，搜索按钮与登录按钮高为 44px（`h-11`）圆胶囊，而主题切换按钮仅 32px（`size-8`）方圆角矩形，三者垂直中线错位、高低不一、风格突兀；且搜索按钮在触摸屏上硬性展示 `⌘K` 键盘角标，与触控习惯违和。
  - **修复**：将顶栏三者（全局搜索、主题切换、登录）统一规格为 36px（`size-9` / `h-9`）精密药丸/圆钮，微边框与垂直中心线绝对对齐，窄屏下隐藏桌面端 `⌘K` 快捷键，提供干脆利落的移动端图标触控入口。

- **根除 iOS Safari 输入聚焦自动放大（Auto-Zoom）缺陷**：
  - **问题**：iOS WebKit / Safari 内核规定：若表单元素（`input` / `textarea` / `select`）的 `font-size` 小于 16px，点击聚焦时浏览器会强制将整页缩放放大，导致布局变形、需要手动双指缩小。
  - **修复**：统一将移动端输入框（`input.tsx`）、多行文本域（`textarea.tsx`）及筛选下拉框（`globals.css .field`）在窄屏下的字号设为 `16px`（桌面端响应式回到 `14px`），彻底解决苹果设备聚焦跑焦问题。

- **答题吸底操作栏（Sticky Actions）紧凑化与令牌对齐**：
  - **问题**：移动端答题操作栏因按钮高度被强制拉大为 44px 且内边距偏大，双行布局高达 128px，占满屏幕底部近 25% 的垂直面积，严重遮挡题干与选项；且缺失 `--card-spacing` 变量定义。
  - **修复**：在 CSS 根节点精准补齐 `--card-spacing`（移动 1rem / 桌面 1.25rem）；压缩移动端吸底操作栏的内边距与按钮尺寸（缩减至 37.6px / `2.35rem`），整体高度压降 20%（128px → 103px），释放更多答题可视区域。

- **弹层安全区与长表格触控优化**：
  - 登录/更新底部抽屉增加 `max-sm:pb-[calc(1rem+var(--safe-b))]`，避开全面屏底部的 Home 虚拟横条。
  - 知识点正文 `.table-wrap` 增加轻微自适应边框与平滑触控滑动提示，防止表格在窄屏生硬截断。
  - 移除知识点移动抽屉底部的重复安全区内边距。
