# 版本说明 v0.10.15（2026-10-11）

## 主题

修复 UML 指南内嵌 SVG 图示在浅色 / 护眼主题下文字不可见的问题。

## 用户上报与根因

- **现象**：`/kb/quick-uml-learn/` §2.2「六种关系 · 图形速查」中，「1 关联 Association」等图题文字在页面上几乎不可见（用户截图反馈）。
- **根因**：指南内 4 幅内嵌 SVG（六种关系 / 用例图 / 类图 / 状态图）的配色按**深色主题硬编码**——文字 `#d7e0ea`（近白）、盒子 `#1a2330`（深底）、连线 `#c5d0dc`。浅色/护眼主题下页面背景为浅色，近白文字直接「隐形」。

## 修复（`src/app/globals.css`）

在样式层按主题变量覆盖，文档源不动，所有内嵌图示统一受益：

- `text.t` → `var(--foreground)`；`text.s` → `var(--muted-foreground)`
- `rect.box/bound/uc/st` → `fill: var(--card)`，强调盒 `stroke: var(--primary)`，普通盒 `stroke: var(--border)`
- `.line` → `var(--muted-foreground)`；`.div` → `var(--border)`
- 内联硬编码形状：`[fill="#c5d0dc"]` → `var(--foreground)`（实心箭头/菱形）、`[stroke="#c5d0dc"]` → `var(--muted-foreground)`、`[fill="#0f141c"]` → `var(--surface)`（挖空）、`[fill="#7eb8da"]` → `var(--primary)`

亮色 / 暗色 / 护眼三主题下文字、图形均清晰。
