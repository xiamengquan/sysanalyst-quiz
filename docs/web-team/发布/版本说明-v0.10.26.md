# 版本说明 v0.10.26（2026-10-12）

## 背景

冲刺 D2，用户按新排程在 /recall 用「范围选 D1 + D2」清卡时发现：总册日次筛选为单选，无法复选。同时 D1 晚模考后 /recall 到期卡显示 141（136 张从未学习的新卡 + 5 张桶1到期），「新卡永远视为到期」的设计导致数字虚高造成焦虑。

## 变更要点

### 1. 范围筛选支持多选

- `dayFilter: string` → `daySet: string[]`：D1–D7 日次 chip 可任意组合勾选，「全部」一键清空（daySet 为空即视为全部）
- 选中态按 chip 独立高亮；标题更新为「范围（总册日次 · 可多选）」

### 2. 到期统计拆分

- 到期待复习卡片下新增副行「复习 N · 新卡 M」：复习到期 = 有学习进度且到期；新卡 = 无进度（视为到期属既有设计）
- 明示数字构成，避免「141 从哪来」的误读

### 3. 抽卡顺序：复习优先

- `start()` 中到期队列改为「有进度的到期卡洗牌在前 + 新卡洗牌在后」拼接，复习债优先清偿，新卡不再挤占本轮配额

## 同步范围

- `src/components/RecallApp.tsx`（筛选状态、filtered/dueList 计算、统计卡片、范围 chips、start 抽卡顺序）
