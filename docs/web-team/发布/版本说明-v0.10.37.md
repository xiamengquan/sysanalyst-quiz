# 版本说明 v0.10.37

> 日期：2026-10-15 · 分支：main · 主题：/audio 新增「39 点讲透文章」池——没时间看就用听的

## 背景与需求

用户要求「将 39 个知识点制作成可以音频阅读的文章，我在没时间看时可以通过音频听」。

现有 /audio 是问答/洗脑卡模式（闪卡 M/K + 演练卡组），缺「连贯朗读文章」形态。方案：复用 AudioApp 成熟的 TTS 播放器（SpeechSynthesis 队列 / gen 失效 / 定时 / 循环），新增第三种卡池「文章」。

## 变更清单

### 数据：audio-articles.json（新增生成链路）

- 新脚本 `scripts/build-audio-articles.mjs`：解析合并版《四层七日背诵总册》的「逐点讲透 · 一通到底」节，按 pid 前缀分 4 篇域文章（req/web/mic/db），每点生成一段 TTS 友好文本：`第N点，标题。第一性拆解：…费曼讲法：…一通到底：…考场回扣：…`
- 内建校验：39 点整（req10+web10+mic9+db10）、未知域、空段——脚本已接入 `check:release` 门禁首环（生成即校验，幂等）
- 输出 `public/data/audio-articles.json`

### 功能：AudioApp 文章池（src/components/AudioApp.tsx）

- Pool 类型加 `article`；新增 ArticleDoc/ArticleParagraph 类型与 `/data/audio-articles.json` 拉取
- `articleToCards`：段→音频卡（问=「第N点 标题」播报，答=完整讲透文本）
- 设置界面：卡池按钮加「文章 · 39 点讲透（连贯朗读）」；文章池专属域筛选（全部/需求/Web/微服务/数据库）
- 复用播放能力：问答式/洗脑式、语速 0.7–1.6x、发音人、∞ 循环、定时停止、上/下一段
- 设置持久化加 articleFilter；播放 badge 显示「讲透文章 · 域」
- 页面 lead 文案更新

### 内容：总册入口

- 总册「读 · 练 · 背三环」的「读」条目加：没时间看 → /audio 文章池连贯收听

## 用法

- 通勤/散步：/audio → 卡池选「文章 · 39 点讲透」→ 按当日主块选域（今晚微服务）→ 问答式播放
- 没时间看总册时：睡前把整章 39 点连播（约 40–50 分钟，可 ∞ 循环）
- 锁屏注意：部分手机会暂停 Web Speech 合成，建议亮屏播放或连耳机
