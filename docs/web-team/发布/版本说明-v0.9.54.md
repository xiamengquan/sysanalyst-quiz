# 版本说明 v0.9.54

## 变更要点

- 外部 Agent 无法稳定读取 sitemap：改回 **Next.js 推荐** `src/app/sitemap.ts` + `src/app/robots.ts`。
- `npm run generate:seo` 生成 `public/data/sitemap-urls.json`（逻辑仍来自 `scripts/seo-utils.mjs`）。
- 删除 `public/sitemap.xml`、`public/robots.txt`，避免与 Metadata Route 产物冲突。

## 验收

- `npm run build && node scripts/check-sitemap.mjs --strict-out`
- 确认 `out/sitemap.xml`、`out/robots.txt` 存在
- 部署后 `npm run check:live-seo`
