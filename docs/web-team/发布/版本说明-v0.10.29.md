# 版本说明 v0.10.29（2026-10-13）

## 背景

用户要求：对全知识点按**需求工程 / Web / 数据库**三域重构为「答题知识点」体系（后追加**微服务**，四域正好对齐案例出题重心：试题一需求铁律 + Web 22 席 + 数据库 12 席 + D3 下微服务主背域）；按新知识点设计**辅助背诵的选择题 + 填空题（Duolingo 式）**；再**模仿真题设计案例题**，要求三（四）域知识点全覆盖。经确认三项机制：轻量游戏化（进度环 + 错题重入 + 即时反馈，不做 XP/红心）、案例双入口（/case 池 + 单元末深链）、错题知识点自动转卡进 /recall。

## 变更内容

1. **知识点重构（内容源 `content/tracks/*.json`）**：四门课程 12 单元 **39 个答题知识点**，每点含「核心答题句 + 易混辨析（vs）+ 案例钩子（hook）」——按答题口径重组（不是教程章节复述）：
   - 需求工程（10 点，映射 D2）：需求三层 / 获取五法 / DFD / 用例与 include-extend / SRS / 验证四法 / 评审六查 / 跟踪矩阵 / CCB / 状态与基线
   - Web（10 点，D3）：前后端分离 / MVC-MVP-MVVM / 负载均衡 / REST / 缓存三问题 / 会话与 JWT / XSS-CSRF / API 网关 / 同步异步 / 演进判据
   - 微服务（9 点，D3）：特征与 SOA / 拆分原则 / 注册发现 / 通信与事件三部件「源-管-理」/ 四保护 / 可观测三支柱 / 配置与 K8s / 每服务一库 / Saga-TCC
   - 数据库（10 点，D4）：ER 转化（M:N 单独建）/ 范式判定 / 反范式 / 视图索引 / ACID / 并发三读 / 2PL 与死锁 / 2PC-TCC / CAP-BASE / 分库分表
2. **Duolingo 式背诵**（`/track`，`TrackApp.tsx`）：每点 1 选择 + 1 填空共 **78 题**；逐题即时反馈（对错 + 解析）；**错题当课重入直到答对**；首过率进度环 + 连对计数；填空判分（归一化 + 别名组匹配，宽松包含）；进度入 IndexedDB（`sysanalyst_track_v1`）。
3. **错题自动转卡**：`RecallApp` 装卡时合并 `/track` 未首过知识点 → 合成 `TRK-*` 轨道错题卡（K 层 ★ 卡，挂对应 D 日次），无进度 = 永远到期，进入 1-2-4-7-15 间隔排程。
4. **四套仿真案例**（`content/banks/cases/案例131–134.md` → 自编池 130→134）：CA-131 需求·需求识别与确认（仿试题一）、CA-132 Web·技术方案论证、CA-133 微服务·技术方案论证、CA-134 数据库·建模与设计；各 3 问、rubric 要点齐备；双入口（/case 池 + 轨道单元收官深链）。
5. **覆盖矩阵进发版门禁**：`scripts/build-tracks.mjs` + `scripts/check-tracks.mjs`（每点 ≥1 选择 + ≥1 填空；qmap 100% 覆盖本域点；案例 md 存在且落库）；`check:release` 链新增 `check-tracks`；`sync:all` 链新增 `build:tracks`。
6. **接线**：导航新增「轨道」（顶栏 + 底栏 8→9 格，Route 图标）；sitemap 收录 `/track`（priority 0.9 daily）。
