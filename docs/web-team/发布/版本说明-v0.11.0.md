## 变更要点

### A1 · 风险项直达纠偏执行器（控制层闭环）

- **问题（G2）**：`/system` 风险登记册此前只有「⚡冲该域 / 📖重学」两个动作，控制指令没有执行器——看到风险还要人肉找题、找卡，纠偏回路在最后一米断开。
- **修复**：风险项动作升级为四个直达链接：
  - **练此点** → `/track/?point=<pid>`（点级精确练习，取代原「冲该域」的粗粒度跳转；域级入口仍保留在矩阵与课程页）；
  - **背此卡** → `/recall/?day=<course.day>`（新增深链：RecallApp 读取 `?day=` 参数预选总册日次筛选）；
  - **做此题** → 课程配套案例整题（`tracks.json` `caseSet.href`，数据既有、此前未接线）；
  - **重学** → 总册锚点（保留）。
- **涉及文件**：`src/lib/se-system.ts`（RiskItem 增 `day` / `caseHref`）、`src/components/SystemApp.tsx`、`src/components/RecallApp.tsx`。

### A2 · 连错自动入池（反馈回路去人工化）

- **问题（G3）**：错题二刷靠当日计划里的人工标注步骤，回路存在人工瓶颈。
- **修复**：`wrong ≥ 2` 的考点自动合成一条「连错回炉（自动入池）」任务注入**当天**午休重刷块，直达第一个连错点的轨道练习；总控台基线层执行率/连续天数同步计入。
- **关键设计**：
  - 新增 `src/lib/today-compose.ts`：纯函数 `injectRetryTasks` 由 `TodayApp` 与 `se-system` 共用，两侧基线一致；`loadComposedTasks` 为 TodayApp 异步入口；
  - **仅对「今天」注入**，历史日次基线保持稳定（last7 / streak 不被追溯性污染）；
  - `today-compose` 不反向 import `se-system`（避免循环依赖），轨道存储键字符串按 RecallApp 同例本地维护。

### A3 · 掌握度保鲜衰减（状态机时变化）

- **问题（G4）**：`risky/mastered` 判定只看 right/wrong 比率，`lastAt` 未参与——记忆是时变系统，模型却按静态系统建，「曾掌握」高估当前状态。
- **修复**：`se-system.ts` `statusOf()` 增加 7 天保鲜期（`MASTERED_TTL_MS = 7d`）：首过掌握但超 7 天未触碰 → 自动降级「巩固中」，等待间隔重复复验；纠偏后答对追平自动解除风险的行为不变。
- **涉及文件**：`src/lib/se-system.ts`。
