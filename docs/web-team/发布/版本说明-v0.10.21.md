## 背景

用户刷到练习题 177（第7章 CMMI 等级）质疑：「这看着好像不对啊」「不应该是初始、可重复、已定义、已管理、优化吗」。经查：

1. **题干确有笔误**：「连续式表示法」问「五个成熟度等级」是概念混搭——连续式用「过程域能力等级」（无「初始级」）；「成熟度等级 + 初始级…优化级」是**阶段式**的口径。答案 A（初始、已管理、已定义、量化管理、优化）为 CMMI 阶段式正确序列，答案不变。
2. **用户口诀是老 CMM**：初始→可重复→已定义→已管理→优化（初重定管优）为 CMM 五级；CMMI 阶段式为初始→已管理→已定义→量化管理→优化（**初管定量优**，用户提出，采纳）。
3. **真题证据**（本站真题库检索）：近年实际考 **CMM 五级特征映射**——2019上39/2023上39（可重复级=基本项目管理）、2025下10（优化级=定量分析+持续优化）、2026上44/45（初始级/已管理级特征）；无真题直接考 CMMI 阶段式序列。故 CMM 口诀不可删，CMMI 序列作辨析与干扰项防御。
4. **本站知识点自己混写了**：「CMMI 5级：初重定管优」模板化地散布在 13 篇考点页及总册/清单/卡组/对比表——把 CMM 的序列标成了 CMMI。
