## 变更要点

### 分解层新增「建模语法链（SA / OOA）」

- **背景**：39 个考点配置项只覆盖案例四大域（需求/Web/微服务/数据库），建模知识（SA / OOA / UML / 数据库设计链）散在 `/drill` 步骤链与速查文档里，未清单化——「词汇」有了，「语法」没有户口。
- **修复**：`/system` 分解层（39 点矩阵与控制层之间）新增「建模语法链」区块：
  - **24 个建模知识点**按三组芯片列出：结构化分析 SA（DFD 四要素/命名分层/数据字典/加工逻辑/STD/父子图平衡/三模型/RTSAD）、面向对象分析 OOA（定义作用/用例三要素/业务 vs 系统用例/规约/BCE/CRC/分析产物）、通识与对比迁移（范式坐标系/题干信号/填空四步法/UML 六图链/数据库设计链/需求链/对比表）；
  - **每芯片 hover 显高频易错点**（title 提示），点击直达 `/drill/?deck=` 步骤链卡组或已审计速查（`/kb/quick-sao-learn/` L0→L4、`/kb/quick-uml-learn/`、`/kb/quick-compare/`）；
  - 区块头链至语法层总纲「结构化与面向对象分析体系化学习路径」。
- **设计边界（架构评审意见）**：建模知识属链/网层，暂不升格为 39 点配置项状态机（其掌握状态随案例题实践联动）；本区块为纯展示层索引，**全部条目指向既有已审计内容，零新增知识点**——不触碰内容门禁。
