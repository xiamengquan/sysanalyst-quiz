# 版本说明 · v0.6.8

> 发布：网站程序 · 2026-09-23  
> 依据：站点更新必记日志规范 · 移动端知识点抽屉丝滑动画、零收缩切换与弹窗层级穿透修复

## 本版变更

### 缺陷修复与体验深度优化

- **移动端知识点抽屉滑入与退出动效重构（`Sheet` / `KbPreviewDrawer`）**：
  - **问题根因**：原抽屉动画规则依赖于已被重构废弃的旧选择器 `.kb-drawer-root:not(.is-docked) .kb-drawer-panel`，在采用 Radix UI 的 `SheetContent` 后样式未命中；且父级组件在关闭时通过条件判断直接卸载组件，导致移动端打开时生硬硬弹、关闭时瞬间消失无动画，产生明显卡顿感。
  - **修复实现**：
    - 在 `globals.css` 中为 Radix `[data-slot="sheet-content"][data-side="bottom"]` 专门声明标准的 `kb-sheet-in` 与 `kb-sheet-out` 动效，使用 iOS 原生级别的阻尼缓动函数（`cubic-bezier(0.16, 1, 0.3, 1)`）。
    - 遮罩层同步接入淡入淡出（`kb-fade-in` / `kb-fade-out`）。
    - 父级组件 `QuizApp`、`CaseApp`、`KbApp` 调整为常驻挂载 `open={kbOpen}`，让 Radix 状态机完整托管入场与退场生命周期，滑入滑出如丝般顺滑。

- **多知识点选项切换「剧烈收缩与弹跳」根治**：
  - **问题根因**：移动端抽屉原本仅声明 `max-h-[min(88dvh,720px)]` 而未固定高度；在用户点击相关知识点 chip 时，`status` 立即变更为 `"loading"`，导致原本由长文撑开的大面积内容瞬间被卸载、退化成一行加载文字，抽屉骤缩至 100 多像素，几百毫秒后新内容加载完成又突然弹开，严重抖动。
  - **修复实现**：
    - **尺寸稳定**：移动端抽屉尺寸固定为 `h-[min(85dvh,720px)] max-h-[min(85dvh,720px)]`，主体 `.kb-drawer-body` 作为弹性滚动区，外框轮廓永远稳定，杜绝任何物理尺寸抖动。
    - **内存缓存与预热**：引入全局模块级知识点缓存 `kbMarkdownCache`，并在抽屉打开时对题目的多个关联知识点执行轻量静默预热。用户在 2 个或多个考点标签间切换时实现 0ms 瞬间秒切。
    - **平滑渐显过渡**：网络初次加载时保留当前内容并降为 60% 透明度展示顶部纤细加载条，新内容就绪后瞬间置顶替换，告别内容塌陷。

- **全站弹窗与底部悬浮按钮（FAB）层级穿透遮挡修复**：
  - **问题根因**：全局 `Dialog`（如更新说明 `UpdateNotice`、登录弹窗等）原 `z-index` 为 `z-[80]`，而知识库悬浮按钮 `.kb-nav-fab` 和 `.kb-toc-fab` 为 `z-index: 85`。当更新弹窗在窄屏贴底弹出时，悬浮按钮因层级更高直接穿透遮罩盖在弹窗正文上方，遮挡住下方选项和文字。
  - **修复实现**：
    - 将全站 `DialogOverlay` 和 `DialogContent` 统一提升至最高模态优先级 `z-[100]`。
    - 将 `.kb-nav-fab` 和 `.kb-toc-fab` 规范下调至页面悬浮层级 `z-index: 50`。
    - 抽屉 `Sheet` 规范为 `z-[90]`。
    - 彻底消灭任何弹窗被悬浮按钮遮挡穿透的问题。
