# 版本说明 · v0.6.7

> 发布：网站程序 · 2026-09-23  
> 依据：站点更新必记日志规范 · 知识库深色模式悬浮光晕与引用块纯白大方块修复

## 本版变更

### 缺陷修复与视觉体验重构

- **知识库悬浮操作条（「返回目录」与「索引」）白光扩散晕染（White Glow）修复**：
  - **问题根因**：原样式在 `.kb-fab-btn` 和 `.kb-toc-trigger` 中使用了 `box-shadow: 0 10px 28px color-mix(in srgb, var(--foreground) 16%, transparent);`。在暗黑模式下，前景色 `--foreground` 为高亮白，导致深黑背景上出现一个巨大的刺眼白色扩散柔光圈，破坏暗色主题的一致性并干扰正文视线。
  - **修复实现**：
    - 彻底移除以 `--foreground` 计算的投影。
    - 浅色模式下采用自然纯净的微黑沉降投影（`0 4px 14px -2px rgba(0, 0, 0, 0.12)`）。
    - 深色模式下采用 Cursor 风格深色重投影与精细顶线内微光（`0 8px 24px -4px rgba(0, 0, 0, 0.75), inset 0 1px 0 rgba(255, 255, 255, 0.08)`），视觉纯粹沉稳，彻底告别刺眼白晕。
    - 同步优化 `.kb-toc-panel` 索引弹层、侧边抽屉面板与 `.kb-toast` 悬浮提示，消除全站残留的所有白光投影。

- **知识库 Markdown 引用块（`blockquote`）纯白实心大方块修复**：
  - **问题根因**：原样式中定义了 `background: color-mix(in srgb, var(--primary) 12%, var(--card));`。由于构建链路的 PostCSS / LightningCSS 编译器对 `color-mix` 采取了静态兼容回退策略，自动生成了 `background: var(--primary)`。在 Cursor 现代黑白调中，`--primary` 被定义为纯白色 `oklch(0.98 0 0)`，当移动端浏览器（Safari / 微信内嵌 WebView）匹配到 fallback 时，直接将引用块强制渲染为一个刺眼的纯白实心方块，文字对比度严重失衡。
  - **修复实现**：
    - 彻底重构 `.md-body blockquote`，弃用脆弱的 `color-mix`。
    - 浅色模式采用浅灰底 `var(--surface)` 与沉稳边框。
    - 深色模式精确设定为轻薄暗底 `rgba(255, 255, 255, 0.035)`、清晰边线 `rgba(255, 255, 255, 0.25)` 与柔和文字 `oklch(0.85 0 0)`，段落加粗字保持 `var(--foreground)`，阅读体验极其舒适清爽。

- **全站 `color-mix` 降级风险排查与收敛**：
  - 检查并清理 `KbApp` 与 `CaseApp` 页面中残留的 `border-[color-mix(...)]` 与 `bg-[color-mix(...)]` 临时类，统一收敛为自研语义令牌类（`border-border bg-surface/60` 等）。
  - 全站阴影规范化收敛，杜绝任何因浏览器 CSS 降级带来的“夜间模式大白块”与“发光白圈”次生问题。
