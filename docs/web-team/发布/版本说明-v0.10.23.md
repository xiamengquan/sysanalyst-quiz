# 版本说明 v0.10.23

- **版本**：0.10.23（package.json / release-notes.json latest / releases[0] 三处一致）
- **日期**：2026-10-11
- **类型**：功能增强（今日任务 · 日期切换与总览）

## 背景

用户提出「今日任务应该每天生成一份当天计划」。现状：`/today` 本就按日期出 15 天各自独立的当天计划（10/11–10/25 硬编码于 `today-plan.ts`），但页面只能看今天，无法预览明天、回补漏掉的日子或总览全排程。确认需求为：**日期切换器 + 全排程总览**。

## 变更清单

### today-plan.ts

- 新增 `shiftDate(dateKey, delta)`：本地日历日平移。
- 新增 `planRoster()`：冲刺窗口 15 天（含考试日）计划清单（date/weekday/tag/sprintDay），供总览渲染。

### TodayApp.tsx（重写组件）

- **日期导航卡**：‹ 前一天 / 日期+星期+冲刺日次+阶段标签 / 后一天 ›；「今天」徽标；`?date=YYYY-MM-DD` 深链支持（进入页面读取、切换时 replaceState 同步 URL）。
- **冲刺 15 天总览**：一屏列出全部 15 天，每天显示主线首任务预览、勾选进度 x/y 与迷你进度条、今天高亮；点任意一天直达该日任务。总览与当日任务用同一状态位切换（「返回当日任务」按钮）。
- **回到今天**：非今天浏览时显示一键返回。
- **进度按日期分档**：勾选存储 `sysanalyst_today_checks_v1` 本就按日期 key 分档，重构后所有读写均走 `viewDate`（原来写死 `today`），浏览历史日期时勾选/重置均作用于该日；总览的每日进度直接读分档数据。
- 「🎉 全部完成」文案改为通用表述（该日任务全部完成）。
- 修复 hooks 规则：`roster` 的 useMemo 移至提前 return 之前。

## 影响面

- 仅 `/today` 页面；不涉及 KB 内容与题库数据；勾选存储 key 与数据格式不变（老进度无损迁移）。
- 日期导航不设边界（自由 ±1 天），窗口外日期自动落 `buildFallbackTasks` 通用模板并显示对应标签。

## 流程与验证
