# 版本说明 v0.10.6（2026-10-11）

> **主题**：新增《考前 14 天冲刺计划》速查文档 + 知识点主页置顶入口——两周加速两轮制，数据支撑的模块分级与战略放弃清单。

## 内容改动

- 新增 `content/kb/速查/考前14天冲刺计划.md`：
  - **两轮制**：第 1–7 天总册 D1–D7 铺底 + 七日巩固当日配题；第 8–14 天综合真题 5–8 场 + 案例专攻 4–6 场 + 论文限时 2 篇 + 收口。

  - **战略放弃清单**：案例非专攻领域（嵌入式/移动/大数据/CPS 中未选者）、形式化方法/Petri 网/IDEF、TOGAF/Zachman 细节、经管与英语刷题、低频计算、第二轮起不学新知识。
