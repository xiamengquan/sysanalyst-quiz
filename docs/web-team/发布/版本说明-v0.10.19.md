# 版本说明 v0.10.19（2026-10-11）

## 主题

洗脑音频接入演练卡组 + ∞ 无限循环——UML 六图的定义与作用可直接无限播放。

## 用户需求

「UML 中图的定义与作用还有步骤制作成洗脑音频，我要无限播放给自己听，太难背诵了。」

## 实现（`src/components/AudioApp.tsx`）

1. **卡池扩展**：fetch `public/data/drills.json`，演练步骤 → 音频卡（17 张：UML 建模 6 / 数据库设计 6 / 需求工程 5）
   - 洗脑式朗读文本 = `图名。范例句。一句话作用`（图名高频重复即洗脑点；「一句话——」前缀清洗后朗读）
   - 问答式 = 读格子提问 → 停顿 → 范例句 + 作用句
2. **∞ 无限循环**：新增 `loopAll` 开关（默认关，本机记忆）——整组播完自动回到第一张继续，配合「定时停止 = 不限」实现通勤无限听
3. **卡池选择 UI**：闪卡库（原 D1-D7/M/K 筛选不变）/ 演练卡组（按链筛选）；偏好与设置一并持久化到 `sysanalyst_audio_settings_v1`
4. **播放页**：badge 显示「演练 · 链名」；进度行显示 ∞ 循环状态
