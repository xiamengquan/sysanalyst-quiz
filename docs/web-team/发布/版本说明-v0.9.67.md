# 版本说明 v0.9.67（2026-10-08）

## 主题

模拟卷上线：参照真题 75 题出题顺序与结构重新整理自编选择题，按「基础 / 进阶 / 困难」三套成卷。

## 背景

用户反馈：自编选择题题量 730 道但组织松散，希望参照真题 15 套（2014上—2026上）每套 75 题的出题顺序与结构重新整理，按套组织、覆盖多方面模块、难度分三档，题目内容可参考真题设计。

## 实现

### 1. 真题结构模板（75 槽位）

- 数据源：`content/banks/real/综合知识/all.jsonl`（15 套真题 1040 题）。
- 通过题干+解析关键词正则将每题归入 16 个模块（与自编章 ch0—15 对齐：法规/英语/数学/系统/网络/数据库/信息化/软工/项目/安全/规划/需求/架构/设计/测试/维护）。
- 对每个题号 1—75 取 15 套真题的众数模块 → 75 槽位模板；平均众数吻合率 44.9%（真题各套顺序本身波动较大，众数模板仍能代表主流题序）。

### 2. 组卷引擎 `scripts/python/build_mock_sets.py`

- 池：`content/banks/practice/all.jsonl` 730 题（basic 307 / medium 72 / deep 351；scenario 584 / short 146）。
- 选题策略：
  - 基础卷、困难卷「难度优先」：本模块首选难度 → 相邻模块（±1、±2）首选难度 → 全池首选难度 → 才允许难度降级；情景题优先。
  - 进阶卷「模块优先 + want-major」：medium 全库仅 72 题且 53 题集中 ch11，若纯难度优先会导致 53/75 全是需求题；改为在本模块+相邻内按难度优先（medium→deep→basic），保证模块覆盖面。
- 输出 `public/data/mock-sets.json`：`meta` + `template[75]` + `sets[3]`（每套 `items[{qnum,id,ch,module,diff,style}]`）。
- 内置自检：3×75、套内无重复、引用 id 全部存在、跨套复用计数；异常即 exit 1。

### 3. 产物验证

- mock-basic：75 题，难度 basic×75；模块覆盖 0/1/3/4/5/6/7/8/9/11/13 共 11 个；情景题 64。
- mock-medium：75 题，medium×26 + deep×49（medium 全库仅 72 题已最大化使用）；模块覆盖 10 个；情景题 75。
- mock-advanced：75 题，deep×75；模块覆盖 10 个；情景题 73。
- 跨套复用 0；三套合计 225 题，互不重复。

### 4. 前端接入（`src/components/QuizApp.tsx`）

- 初始加载并行 fetch `/data/mock-sets.json`（失败降级 null，不影响主流程）。
- 新增 `startMockSet(setId, preferredMode?)`：按 qnum 排序、按 id 映射题目成池；缺失题报错拦截。
- 刷题页 setup 区新增「模拟卷 · 对齐真题 75 题结构」卡片：三套一键开始按钮（含难度构成徽标），作答模式跟随「模式」选择；75 题卷自动复用既有模考结果/及格判定 UI。
