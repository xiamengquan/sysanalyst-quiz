## 变更要点

### A6 · 记忆引擎升级：莱特纳 → FSRS 式自适应 + 掌握度预测

- **问题（原 P2 定位）**：莱特纳盒对所有人用同一张时刻表，盒级跳变粒度粗，无法区分「记得牢的」与「勉强记住的」；掌握度是静态计数，不预测未来。
- **修复**：`src/lib/flashcards.ts` 引擎升级 v2，三层结构不变（基线阶梯 / 状态字段 / 到期判定），新增：
  - **每卡自适应系数 `ease`（0.6–1.6，缺省 1）**：记住 ×1.05、模糊 ×0.9、忘了 ×0.8；实际间隔 = 基线间隔（1-2-4-7-15）× ease——连对越多间隔拉得越长，反复忘的卡自动缩密；
  - **连对计数 `streak`**：记住 +1、忘了清零，为后续按 streak 加成留口；
  - **保持率预测 `predictedRetention()`**：半衰曲线 R = 2^(-已过天数/半衰期)，半衰期 = 排程间隔——到期日即预测保持率降至 50% 之时；
  - **聚合健康仪表 `retentionStats()`**：平均预测保持率 + 风险卡数（R < 0.7）。
- **呈现**：
  - `/recall` 答题卡新增「预测保持率 N%」徽章（<70% 标黄）；准备页新增保持率统计行；
  - `/system` 反馈层背诵闭环卡新增「保持率 N% · 风险卡 N」；案例微卡（CASE-*）与轨道错题卡（TRK-*）的在册进度一并纳入统计。
- **兼容性（零迁移）**：`ease`/`streak` 为可选字段，旧 IDB/云同步进度缺省即默认值，原样接入新引擎；到期判定行为对旧数据不变（ease=1 时与 v1 完全一致）。
- **涉及文件**：`src/lib/flashcards.ts`、`src/components/RecallApp.tsx`、`src/lib/se-system.ts`、`src/components/SystemApp.tsx`。
