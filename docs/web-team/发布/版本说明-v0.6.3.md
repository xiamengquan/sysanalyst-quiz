# 版本说明 · v0.6.3

> 发布：网站程序 · 2026-09-22  
> 依据：站点更新必记日志规范 · 移除 shadcn 与 Cursor.com 视觉重构 · 2026 案例 Web+AI 智能体四维度知识点

## 本版变更

### 规则与发版规范（新增）

- 制定全站规则：**「变更必登日志（更新全记录）」**，并在 `.cursor/rules/changelog-always-recorded.mdc`、`docs/web-team/00-网站小组章程.md` 等文件中固化。
- **核心约束**：任何一点的更新（含 UI/交互微调、功能增强、知识点增补/修正、题库维护、架构重构、依赖变动），都必须被明确记录并写入更新日志（`public/data/release-notes.json` 与版本说明），杜绝“静默更新”。

### 架构与依赖重构（程序）

- 彻底移除 `package.json` 中的 `shadcn` 依赖包，清理 257 个间接 npm 包。
- 移除根目录的 `components.json` 配置文件。
- 移除 `src/app/globals.css` 中的 `@import "shadcn/tailwind.css"`。
- 将 `src/components/ui/*` 基础组件全面重构为**纯粹、轻量、自包含**的自研 UI 原语（基于 Radix 基础能力与 CVA，无黑盒 CLI 绑定）。

### 视觉与交互风格（Cursor-inspired UI）

- **色彩体系**：参考 Cursor.com 现代开发者工具设计风格，重塑 Dark 模式纯粹冷黑底色（`oklch(0.12 0 0)`）、卡片层级（`oklch(0.155 0 0)`）、极度细腻的 8.5% 白透明边框与微弱内边缘高光；Light 模式采用温润冷白与纯黑反差高对比度设计。
- **环境微光**：优化背景 Ambient Glow，呈现深空星云般的放射状层次微光。
- **顶栏导航**：引入 Cursor 风格几何多边形线框 Icon，主导航重构为悬浮胶囊药丸（Pill）容器，激活态具备浮岛微阴影。
- **全局搜索**：全局搜索弹窗与触发按钮重构为 Raycast / Cursor 风格微型键帽 `kbd` 与极简输入框。
- **卡片与答题选项**：统一卡片圆角至 14px，选择题 `.opt-btn` 支持高亮边框微光与 Emerald / Rose 精致判题状态。
- **UI 缺陷修复（走查落地）**：
  - 修复案例知识点关联抽屉底部「整页打开」按钮因 `a[data-slot="button"]` 选择器继承黑色文本导致与纯黑背景同色隐形的问题，彻底修正继承与特异度，保证 Light/Dark 模式下均清晰醒目、黑白分明。
  - 修复顶栏主题切换下拉菜单（`DropdownMenuContent`）因微透明（`bg-popover/95`）导致穿透底层正文的问题，重构为 100% Solid 实心纯色遮光面板，提升层级至 `z-[90]`，优化多层柔和阴影，未选文字改为高对比度并加入当前项 `Check` 状态勾选。

### 知识点（文档）

- 新增 `content/kb/速查/Web与AI智能体-架构选型四维度卡.md`，完整对齐 2026 上案例试题五考查口径：
  - 四维度：并发/实时、智能体调度、安全权限、扩展分布式
  - 轻量栈（FastAPI+Node）vs 微服务栈（Spring Cloud）填空与辨析
  - 负载均衡（四层/七层/网关/客户端）与常用中间件（K8s 等）
- 同步更新 `第16章-Web应用系统分析与设计.md`、`速查/高频对比速查表.md` 与知识点检索索引。
