# 版本说明 v0.9.24

**日期**：2026-09-26

## 变更要点

- `KbReader`：API 考点（`kind: point`）阅读页增加左侧「考点索引」，按 `group` + `outlineRef` 与目录页一致分组。
- 当前考点 `aria-current="page"` 高亮；切换后索引列表自动滚到可见区域。
- `<960px` 隐藏侧栏，改正文顶部的考点下拉跳转。
