# 版本说明 · v0.6.9

> 发布：网站程序 · 2026-09-23  
> 依据：站点更新必记日志规范 · 综合知识题目选项暗黑模式全白悬停修复与样式稳健性清障

## 本版变更

### 缺陷修复与视觉体验重构

- **题目选项（`.opt-btn`）暗黑模式悬停全白缺陷修复**：
  - **问题根因**：原样式中定义了：
    ```css
    .opt-btn:hover {
      border-color: color-mix(in srgb, var(--foreground) 25%, var(--border));
      background: color-mix(in srgb, var(--foreground) 4%, var(--surface));
    }
    ```
    构建流程中的 PostCSS / LightningCSS 兼容插件在处理包含多个动态 CSS 变量的 `color-mix` 时，自动生成了回退属性：
    ```css
    .opt-btn:hover { background: var(--foreground); }
    @supports (color: color-mix(in lab, red, red)) { ... }
    ```
    在暗黑主题下，`--foreground` 被定义为高亮白。当移动端 Safari、微信内置 WebView 或不支持 `in lab` 评估的环境运行该回退时，鼠标悬停或触碰选项直接导致背景变为刺眼的**全白实心方块**，白底白字完全破坏阅读。
  - **修复实现**：
    - 彻底移除对 `color-mix` 的依赖。
    - 浅色模式规范为：`background: rgba(0, 0, 0, 0.03); border-color: rgba(0, 0, 0, 0.22);`。
    - 暗黑模式规范为：`background: rgba(255, 255, 255, 0.05); border-color: rgba(255, 255, 255, 0.22);`。
    - 呈现细腻高级的微亮浮层质感，绝对不可能再出现任何全白方块。

- **选中、正确与错误状态（`is-chosen` / `is-ok` / `is-bad`）安全收敛**：
  - 同样剥离了选中态与正误判定态中残留的 `color-mix` 属性，改为稳健的 RGBA 标准半透明色相。
  - 选中态：暗黑模式下呈现 `rgba(255, 255, 255, 0.08)` 高亮底与前景色边框，对比清晰层次分明。
  - 正确态：柔和绿底（`rgba(34, 197, 94, 0.14)`）与高对比边框。
  - 错误态：柔和红底（`rgba(239, 68, 68, 0.14)`）与高对比边框。

- **全站 `color-mix` 语法彻底清零**：
  - 深度检索全站 `src` 代码库，将普通按钮 hover、输入框聚焦、抽屉头尾底色、案例分析要点卡片、关于页合规卡片等处残留的所有 `color-mix` 彻底替换为安全稳健的标准实现，达成全站 0 处 `color-mix`。
  - 杜绝今后任何页面在暗黑模式下发生意外编译降级白块的可能。
