# 版本说明 v0.9.49

## 变更要点

- `src/app/sitemap.ts`：静态导出时生成 `sitemap.xml`（主路由 + kb-index 全部可读条目）。
- `src/app/robots.ts`：生成 `robots.txt`，指向 sitemap；`Disallow: /knowledge/`。
- `src/lib/site-url.ts` + `NEXT_PUBLIC_SITE_URL`（默认 `https://maintruly.top`）。
- `layout` 增加 `metadataBase`。

## 验收

- `npm run build` 后存在 `out/sitemap.xml`、`out/robots.txt`。
- `npm run check:release`
