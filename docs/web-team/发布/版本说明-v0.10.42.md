# 版本说明 v0.10.42

- 发布日期：2026-10-16
- 性质：缺陷修复（用户实测发现：排序题答对仍判错）

## 一、缺陷：排序题判定恒错

- **现象**：用户把「需求工程主线」5 步按正确顺序（获取→建模→成文→验货→封版）排列提交，仍被判「再记一遍」。
- **根因**：`TrackApp.tsx` 中排序题判定 `orderSeq.map((i) => orderPool[i]).join("|")` 得到的是**原始下标**（如 `2|0|1|4|3`），却与 `current.steps.join("|")` 的**标签文本**比较——类型不一致，恒不等，所有排序题无论对错一律判错。
- **修复**：两处（`submitOrder` 与 `genericOk`）改为 `orderSeq.map((i) => current.steps[orderPool[i]])` 先映射回步骤文本再比较。

## 二、连带修复：风险状态机终身红标

- **现象**：`se-system.ts` 中 `statusOf` 以 `wrong > 0` 判风险，一旦答错即使后续纠偏答对也永远显示「风险」。
- **修复**：风险改为 `wrong > right`（错比对多 = 缺陷未清）；纠偏答对追平/反超后自动降级回「巩固中/已掌握」。
- 同步更新总控台图例文案与 release-notes 对应表述。
