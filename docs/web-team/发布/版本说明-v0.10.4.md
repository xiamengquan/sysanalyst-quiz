## 保留的正确口径（防止误改）

- include 箭头：基用例→被包含用例；extend 箭头：扩展用例→基用例。
- 序列图元素口径：选择三大（对象/生命线/消息）vs 案例四大（+参与者）双口径并存。
- 菱形恒画在整体端；泛化=实线空心三角、实现=虚线空心三角。
- 通信图 = 协作图等价表述（UML 2.x 更名）。
