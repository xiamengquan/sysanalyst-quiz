# 版本说明 v0.10.13（2026-10-11）

## 主题

新增「运用演练场 `/drill`」：Tutorial 式步骤链训练，专治「知识点记住了，但案例里写步骤的作用与差异时下不了手」。

## 设计

从「记」到「用」缺的是**输出训练层**。本功能把高频案例步骤链拆成一格一格的演练格，每格五件套：

1. **问**：这一步做什么、作用与产出是什么（先自己写）
2. **判定**：`judgeAnswer` 比对关键点（复用随机问答自动判定引擎），命中/未中 chips 可视化
3. **范例句**：可直接改写上卷的答题句
4. **一句话作用 + 差异辨析**：与相邻步骤/易混概念的抠点辨析（小问「XX 与 XX 区别」的得分点）
5. **易错点 + 溯源深链**：回对应知识点重读

收尾小结给出薄弱格清单，可「只练薄弱格」；本机 localStorage 记录每链练次/最近成绩/薄弱格。
