## 变更要点

### 建模知识点升格：「语法」获得与「词汇」同规格的练习模式

- **背景**：建模知识此前只以「建模语法链」芯片索引（/system 展示）与 /drill 步骤链存在，未纳入点级状态机——没有风险登记、没有四阶题组、没有案例覆盖。
- **升级**：新增第五课程 `mod`「系统分析与建模」，与既有四域完全同规格进入闭环系统：
  - **12 点 3 单元**：SA（DFD 四要素 / 分层与父子图平衡 / 数据字典与加工逻辑 / 三模型与 STD）+ OOA（用例三要素与关系 / 用例规约与边界 / BCE / CRC 与分析产物）+ 图族与迁移（UML 六图 / 类图六关系 / ER 与范式 / 需求五步链与选图元技能）；
  - **四阶题组**：每点选择（判据驱动、4 选项带解析）+ 填空（blanks 对照）+ 简答（采分点 reference）+ 判断，全域 2 道配对（加工逻辑选型、BCE 归类）+ 2 道排序（DFD 建模顺序、数据库设计六阶段）；
  - **配套案例 CA-136**《智慧园区访客管理平台》：3 道综合问 qmap 覆盖全部 12 点（问题1=SA / 问题2=OOA / 问题3=图族与迁移），案例三部曲「做批卡」直接可用；
  - **闭环接入**：总控台 39→51 点状态矩阵自动纳入（硬编码 39 改为动态 totalPoints）；风险登记册「练此点/背此卡/做此题/重学」四动作对建模点生效（重学锚点=总册 D1 软工·UML·OO）；连错（wrong≥2）自动入午休重刷池；莱特纳/FSRS 排程自动覆盖新点。
- **门禁同步**：`build-tracks` ORDER 收录「建模」；KB_ANCHOR 三处副本（se-system / TrackApp / check-traceability）统一补 `mod` 映射；追溯矩阵门禁自动覆盖（d1 卡组 6 M + 7 K，达标）。
- **范围说明**：24 项建模知识中 12 个核心点升格为配置项，其余（如 IDEF/Petri、论文专题组）保留在「建模语法链」芯片索引作速查入口；考后按掌握数据决定是否扩点。
- **涉及文件**：`content/tracks/建模.json`（新增）、`content/banks/cases/案例136.md`（新增）、`scripts/build-tracks.mjs`、`scripts/check-traceability.mjs`、`src/lib/se-system.ts`、`src/components/TrackApp.tsx`、`src/components/SystemApp.tsx`。
