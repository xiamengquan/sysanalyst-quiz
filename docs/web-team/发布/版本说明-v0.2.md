## 启动

```bash
cd 题库/答题网页
./启动.sh          # 默认 8765
# 浏览器 http://127.0.0.1:8765/  →  顶栏「知识点」
```

修改 `index.html` 或 `kb-index.json` 后，刷新浏览器即可；若服务未运行，先执行 `./启动.sh`。
