# 版本说明 v0.10.24

- **版本**：0.10.24（package.json / release-notes.json latest / releases[0] 三处一致）
- **日期**：2026-10-11
- **类型**：功能增强（案例深链）+ 今日任务链接落定

## 背景

用户问：「微训练第 1 题是哪一题，能否直接通过链接索引到」。现状：冲刺计划/今日任务里「微训练第 1 题（需求识别类）」只给了 `?bank=real&domain=需求` 的**筛选**链接，落到案例列表而非具体题目；且「第 1 题」未落定为具体案例。

## 落定：微训练第 1 题

- **ZT-2025下-案例01**（2025下·案例一 · 需求 · 需求识别与确认）：题面为需求获取方法选型（访谈/JRP/问卷/文档分析/实地观察五法匹配获取目标），与 D1「需求获取五法对比卡」、D2 需求链预习直接衔接；含七步骨架数据。
- 选择依据：需求识别与确认类共 3 道（2020上01 / 2025下01 / 2026上01）；取「先老后新」——2026 上最新的停车场题留作考前全真模拟。

## 变更清单

### CaseApp.tsx

- 新增 `?id=案例ID` 直达单题：自动套该题的 bank/domain/year 筛选并直接进入作答页（pool=[该题]，phase=quiz）；id 无效或大小写不匹配时回退原有筛选参数行为。
- 兼容双重百分号编码（decodeURIComponent 回退匹配）。

### 链接更新（三处）

- `today-plan.ts`：新增 `LINKS.caseById(id)`；D1 主线任务与午休主题均改为「案例微训练第 1 题：2025下·案例一·需求识别与确认（需求获取方法选型，五步完整闭环）」直达该题。
- `考前14天冲刺计划.md` 时刻表 14:00–15:30 行：链接改为直达该题并在文字中写明题号。
- `案例作答启动手册.md` §4：补充 `?id=案例ID` 直达单题用法及示例链接。

## 影响面

- 老式筛选深链（`?bank=&year=&domain=&type=`）行为不变；今日任务其余日期的案例链接仍为筛选链接（后续可逐日落定具体题号）。
- 案例数据、题库数据无变更；kb 镜像随 sync:kb 重建（261 篇 missing 0）。
