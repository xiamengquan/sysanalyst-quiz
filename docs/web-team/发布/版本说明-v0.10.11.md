# 版本说明 v0.10.11（2026-10-11）

> **主题**：导航栏新增「今日任务」（`/today`）——每日时刻表结构化为可勾选清单，对照执行当日冲刺任务。

## 背景

用户要求「每日时刻表在导航栏上挂载一个快速任务确认入口，方便对照任务执行」。将《考前 14 天冲刺计划》§4/§5 的日程结构化为每日任务数据，按「时段分组 + 勾选确认 + 深链直达」呈现。

## 实现

### 新增 `src/lib/today-plan.ts`（任务数据层）

- **14 天计划数据**（2026-10-11 ~ 10-25）：每天 `DayPlan`（日期/星期/日次标签/主块任务）；与冲刺计划文档 §4/§5 手工对齐。
- **每日固定三件套生成**：地铁早 `/audio` 问答式（检验昨晚）→ 工位 8:30–9:00 `/recall` 到期卡 → 午休 30' 案例骨架（**每天主题不同**：需求获取/架构/微服务/数据库/问题诊断四类轮训，带 `?bank=real&domain=…` 深链）→ 地铁晚 `/audio` 洗脑式 ×3。
- **主线任务**：总册背诵/七日巩固配题/真题成卷/案例全真/论文限时等，全部带站内深链。
- **范围外兜底**：`buildFallbackTasks` 按星期轮转 D1–D7 的通用模板。
- 工具函数：`sprintDayNumber`（冲刺第 N 天）、`daysUntilExam`（距 10/25 倒计时）。

### 新增 `src/components/TodayApp.tsx` + `src/app/today/page.tsx`

- 五时段分组渲染任务行：自绘 checkbox（勾选→绿底+划线）+ 任务文本 + 深链按钮。
- 进度条（完成 x/y + 百分比）+ 全部完成庆祝提示 + 一键重置。
- 勾选状态按日期存 localStorage（`sysanalyst_today_checks_v1`），跨天自动归零。

### 导航（`SiteHeader.tsx`）

- `tabs` 首位插入 `{ href: "/today/", label: "今日", short: "今日", icon: CalendarCheck }`；移动底部栏 `grid-cols-6` → `grid-cols-7`。

### SEO

- `seo-utils.mjs` staticRoutes 加 `/today`（changefreq daily，priority 0.9）；sitemap 258→**259**。

## 数据一致性说明

`today-plan.ts` 为手工结构化数据，与 `content/kb/速查/考前14天冲刺计划.md` 保持人工同步（文件头注释已标注）；后续若冲刺计划大改需同步两处。
