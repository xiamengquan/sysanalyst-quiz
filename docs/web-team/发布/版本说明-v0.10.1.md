# 版本说明 v0.10.1

- **版本号**：0.10.0 → 0.10.1
- **日期**：2026-10-11
- **背景**：用户决策——基于四层七日知识点系统，新增「必会与重点知识随机问答」功能辅助强化记忆。三项决策：①卡库程序化提取（~150 张）②莱特纳盒 + 1-2-4-7-15 间隔持久化 ③入口在学习主页复习区（不加导航 tab）。

## 变更要点

### 1. 闪卡库（程序化提取）

- 新增 `scripts/build-flashcards.mjs`（`npm run build:flashcards`）→ `public/data/flashcards.json`
- **153 张卡**：
  - M 层 97 张：总册 D1–D7「必会 · 默写卡」编号项，`**术语**：内容` → 问句化 front（口诀/辨析/默认三规则）+ 默写 back
  - K 层 56 张：记忆卡组 §4 硬记忆点，冒号行 → 问句；无冒号含数字行 → 填空式（数字打码）；无冒号无数字陈述行 → 14 条人工问句覆盖（`FRONT_OVERRIDES`）
  - ★ 错卡高发标记 → `hard: true`（30 张，前端标红徽章）
- 卡组专题 T01–T18 → 总册日次映射（T01/T02→D6、T03→D4、T05→D1 等），与七日主线对齐
- 清洗：back/front 剥离 `★` `**` 残留；断言校验通过

### 2. 随机问答应用（`/recall`）

- 新增 `src/lib/flashcards.ts`：莱特纳盒逻辑——box 0 新卡 / box 1–5 间隔 1/2/4/7/15 天；自评 忘了→回 1 盒、模糊→原地、记住→升盒（封顶毕业，15 天循环保温）；到期判定 `isCardDue`
- 新增 `src/components/RecallApp.tsx` + `src/app/recall/page.tsx`：
  - setup：到期待复习/今日已复习/卡库总量/毕业卡四统计 + D1–D7 日次筛选 + M/K 层级筛选 + 本轮题量（10/20/全部到期）+ 盒级分布
  - quiz：先显示问句（默写提示）→「显示答案」→ 三键自评；卡片徽章（层级/日次/★错卡/盒级/新卡）+ 出处链接（总册锚点/记忆卡组）
  - done：本轮 忘了/模糊/记住 三色小结 + 明日到期预告
- 进度持久化：IndexedDB 键 `sysanalyst_recall_v1`（storage.ts 通用 kv）

### 3. 入口联动

- 知识点学习主页复习区置顶「随机问答」卡（卡数动态读取 flashcards.json meta）
- 总册配套行新增 `[随机问答](/recall/)`（同步镜像）
- sitemap 新增 `/recall`（254 → 255）
