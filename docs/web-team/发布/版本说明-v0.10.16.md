# 版本说明 v0.10.16（2026-10-11）

## 主题

修复 UML 指南「六种关系」内嵌图只显示第一行（关联），其余五组图形消失的问题。

## 用户上报与根因

- **现象**：`/kb/quick-uml-learn/` §2.2 图中只显示 A—B 实线连接一行；「2 依赖」「3 泛化」等以纯文本形式散落在页面下方，无图形。
- **根因**：该 SVG 内部存在多个**含空格的伪空行**。CommonMark 规定 HTML block 遇 blank line（strip 后为空的行）即结束——marked 把 `<figure>` 内从第一个伪空行起的内容当作独立片段解析，`<!-- 依赖 -->` 之后变成 `<p>  <text…>`，SVG 上下文被打断：图形元素（rect/line/polygon）成为不渲染的未知元素，text 内容散落为流式文本。
- **暴露过程**：该问题自图示加入起就存在；v0.10.15 修复主题配色后文字显形，问题随之可见（此前文字与图形同时隐形）。

## 修复

1. **渲染器加固（`src/lib/kb-md.ts`，全站受益）**：`renderKbMarkdown` 解析前把 `<figure>/<svg>/<pre>` 原始 HTML 块整体提取为占位符，marked 解析后原样还原——今后任何内部含空行的内嵌图示 / ASCII 图都不会再被打断。
2. **产物验证**：重建 kb-html 后 svg1 完整包含六种关系（关联/依赖/泛化/实现/聚合/组合），`<p>` 截断消失；同批修复用例图、类图、状态图与 2 幅 ASCII 图的同类隐患。
