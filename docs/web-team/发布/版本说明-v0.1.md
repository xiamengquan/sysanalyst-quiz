## 基线范围

- **刷题**：综合知识单选，`综合知识/all.jsonl`（正式细则 v1.0 终审通过题）
- **运行**：`./启动.sh` 或 `python -m http.server`，无后端、无账号
- **进度**：可选 localStorage，数据不出本机
- **不含**：正式知识点正文、案例分析模块、公网部署
