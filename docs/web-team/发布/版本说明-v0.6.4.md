# 版本说明 · v0.6.4

> 发布：网站程序 · 2026-09-22  
> 依据：站点更新必记日志规范 · 页面二次刷新异常修复 · 知识点抽屉底栏与主题切换菜单视觉修复

## 本版变更

### 交互与体验修复（程序）

- **修复刷新网页被二次重载（自动刷新两次）的严重交互缺陷**：
  - **根因**：顶栏 `AuthButton` 在用户登录且开启云同步时，页面首次挂载会执行 `applyPull(true)`，如果本地时间与云端存在偏差或判定云端较新，会直接触发 `window.location.reload()`，导致浏览器刚完成初次刷新又立即强制执行第二次重载。
  - **修复**：页面初次加载改为 `applyPull(false)` 静默拉取，直接平滑写入本地 IndexedDB，彻底移除自动刷新。用户继续刷题或进入题库时直接使用最新数据，杜绝白屏重载抖动。

### 视觉与组件修复（UI）

- **修复知识点关联抽屉底部「整页打开」按钮黑字隐形问题**：
  - **根因**：抽屉底部按钮为 `Button asChild` 渲染的 `<a>` 链接标签，此前 `globals.css` 中的 `a[data-slot="button"]` 选择器导致其继承了深色字体（`#1c1c1c`），叠加深黑按钮背景形成“黑底黑字”，文字图标完全融于背景隐形。
  - **修复**：在 CSS 中精准剔除该恶性继承，保证默认按钮高反差（浅色纯黑底配高亮白字，深色纯白底配纯黑字），并优化图标对齐。
- **修复顶栏主题切换下拉菜单半透明透字问题**：
  - **根因**：`DropdownMenuContent` 使用了 95% 弱透明与模糊层，在浅色高对比页面下无法完全遮蔽下层文字，底层正文文字穿透菜单造成阅读干扰。
  - **修复**：全面调整为 100% Solid 实心纯色遮光面板，提升层级至 `z-[90]`（高于顶栏），优化立体微投影，所有选项保证高清晰度，并增加当前选中主题的 `Check` 勾选标记。
