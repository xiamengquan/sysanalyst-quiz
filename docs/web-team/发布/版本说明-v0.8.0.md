# 版本说明 · v0.8.0

> 发布：网站程序 · 2026-09-23  
> 依据：站点更新必记日志规范 · 新增全题库随机抽取 75 题功能与全真考场答题卡交互

## 本版变更

### 1. 全题库无偏随机抽取 75 题功能（全真模考冲刺）
- **对标真实考场标准规格**：严格遵循全国计算机技术与软件专业技术资格（水平）考试——系统分析师上午卷「综合知识」75 道单选题、150 分钟、满分 75 分、45 分合格的标准考场设定。
- **Fisher-Yates 高质量无偏抽样**：从全站 1935 道纯选择题（涵盖历年真题 1040 题、自编题 730 题、出题工坊新题 165 题）中无偏均匀洗牌抽取 75 道互不重复的试卷，彻底规避传统伪随机的分布偏差与题目重复现象。
- **双入口快速启动**：
  - 在刷题首页（`phase === "setup"`）右侧主栏新增醒目的推荐入口卡片「全真模拟 · 随机抽取 75 题」，支持常规通关、严格模考（交卷看分）、即时解析三模式一键直启；
  - 在左侧侧栏「学习路径」下拉菜单中集成 `🎲 全库随机 75 题（模考冲刺）` 快捷预设。

### 2. 考场矩阵答题卡（Sheet / Dialog 交互）
- **全局题号状态矩阵**：在答题页面（`phase === "quiz"`）顶栏与底栏操作区新增「答题卡」入口。
- **状态一览与瞬时跳题**：弹出响应式题号面板，直观通过高对比度状态徽块展示当前题（双边框实心）、已作答（高亮实底）与未作答（浅灰线框）状态；支持随时点选任意题号直接跳转切题，解决长试卷翻题效率痛点。
- **移动端底部抽屉适配**：手机端无缝匹配 `dialogMobileSheetClassName` 规范，支持阻尼缓动滑入与安全区自适应。

### 3. 75 题专项考场分析与「再抽 75 题」一键再战
- **成绩与及格线判定**：结果页自动识别 75 题考卷，展示专业级考场评定卡片。
  - $\ge 45$ 分高亮提示合格并展示超分成绩；
  - $< 45$ 分提示距离及格线的差距分值并给予强化建议。
- **无缝换卷刷题**：结果页核心主操作提供 `[🎲 再抽 75 题]` 按钮，一键快速重置作答并抽选全新 75 题继续开练。

### 4. 进度存储与断点恢复增强
- 在本地持久化配置（IndexedDB）中接入 `isRandom75Session` 状态标识，考生在 75 题模考中途中断、刷新浏览器或离开页面后，随时可通过「从断点继续」无缝恢复当前这套 75 题及答题卡进度。
