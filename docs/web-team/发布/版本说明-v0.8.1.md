# 版本说明 · v0.8.1

> 发布：网站程序 · 2026-09-24  
> 依据：站点更新必记日志规范 · 知识点页全局搜索弹窗被遮罩模糊层盖住导致内容发糊修复

## 本版变更

### 缺陷修复

- **全局搜索（⌘K / Ctrl+K）弹窗内容发糊**：
  - **现象**：在知识点目录页点击「打开搜索」或使用快捷键时，搜索面板内文字、下拉与结果列表整体呈现被毛玻璃模糊的效果，难以阅读。
  - **根因**：`GlobalSearch` 的 `DialogContent` 额外指定了 `z-[90]`，而 `DialogOverlay` 为 `z-[100]` 且带 `backdrop-blur-sm`。合并 Tailwind 类后内容层低于遮罩层，模糊遮罩叠在弹窗之上。
  - **修复**：移除 `DialogContent` 上多余的 `z-[90]`，沿用组件默认 `z-[100]`，保证内容绘制在遮罩之上。

## 验收

- 执行 `npm run check:release`：版本 0.8.1 对齐通过。
- 执行 `npm run lint`：0 错误。
- 知识点页 `/kb/`：打开搜索后输入框、筛选与结果列表文字清晰，背景页正常虚化。
