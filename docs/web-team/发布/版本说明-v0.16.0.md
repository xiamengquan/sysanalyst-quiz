# 版本说明 v0.16.0 · 真题按章节分割刷

发布日期：2026-10-16 · 分支：main

## 需求背景

综合知识 1040 道真题此前 `ch=99`（无结构化章节归属），只能按场次成卷刷。考前 8 天，用户明确诉求：「把真题进行分割，我只做我关注的真题」——即按关注章节（如项管、需求、架构）筛选真题，聚焦薄弱考点。

## 变更内容

### 1. 真题章节打标（数据管线）

- 新增 `scripts/real-chapter-tags.mjs`：关键词判据库（每章一组判据，覆盖 23 章），对「题干+选项+解析」文本计分，命中最高者胜；同分取排序靠前章；零命中回退 99（未分类）。英语阅读题（长英文题干）归 0 杂项。
- `scripts/sync-data.mjs` 接入：real 行生成时调用 `tagRealChapter(q)` 替代硬编码 `ch: 99`——**打标是确定性推导**，每次 `sync:data` 重建不丢标；`question-meta.json` 新增 `real_chapters` 章节分布。
- 打标覆盖率：85%（883/1040 题命中真实章节）；未分类 157 题归「其他」组，仍可正常筛选刷题。
- 章节分布（Top）：ch3 计算机系统 148 · ch4 网络 121 · ch5 数据库 104 · ch0 法规杂项 97 · ch6 企业信息化 84 · ch11 需求工程 81 · ch9 信息安全 50 …

### 2. 真题目录「只刷我关注的」(`src/components/RealExamApp.tsx`)

- 新增「只刷我关注的真题 · 按章节分割」Card：章节 chips（章名 + 题数）点击勾选，关注项存 IndexedDB（键 `sysanalyst_focus_chapters_v1`），跨会话记住。
- 「只刷我关注的（N 章 · M 题）」按钮 → 深链 `/real-exams/?session=all&chapters=8,11,12`。

### 3. 真题作答页章节多选筛选 (`src/components/QuizApp.tsx`)

- 新增 prop `initialChapters?: number[]`（真题系统深链传入）。
- 新增 state `chapterSet`；`filtered` 在 `bank === "real"` 分支按 `chapterSet` 过滤（空 = 不限）。
- 真题模式筛选面板新增「章节（关注分割 · 可多选）」chips（动态统计各章题数，含「不限」与「其他」），与场次筛选自由组合。

## 验收记录

- `npx tsc --noEmit`：0 错误。
- `npm run lint`：0 errors（4 个既有 warning，未新增）。
- `npm run check:release`：门禁全绿（版本对齐 / 追溯矩阵 / 题量统计 1935 不变）。
- `npm run build`：静态导出成功。
- 手工验收：目录页勾选章节 → 按钮 N 章 M 题计数正确 → 深链进入作答页仅出该章真题 → 作答页 chips 可再次调整 → 刷新后勾选状态保持。

## 影响面

- 零迁移、零破坏：questions.json 题量与题号（no）不变，仅 real 题 `ch` 字段由 99 升级为真实章节；练习/工坊/论文/案例全不受影响。
- 追溯矩阵门禁不校验 real 题章节，`check:release` 无需改规则。
