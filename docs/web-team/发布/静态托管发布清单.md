# 静态托管发布清单

> 维护：网站程序 · 2026-09-19 · 对应需求 **B-1**  
> 运行时：Next.js `output: "export"` → 目录 `out/` · 常见托管：EdgeOne / 任意静态 CDN

## 一键命令

```bash
# 1. 同步内容 + 构建
npm run sync:all && npm run build

# 2. 发版检查（含 out/）
npm run check:release -- --strict-out
```

仅改代码、内容未动时：`npm run build`（`build` 脚本已内含 `sync:all`）。

本地预览导出产物：

```bash
npx serve out
# 或
python3 -m http.server 8080 -d out
```

## 上传前检查表

| # | 项 | 做法 |
|---|----|------|
| 1 | 版本号一致 | `package.json` · `public/data/release-notes.json` 的 `latest` 与 `releases[0].version` 相同 |
| 2 | 更新日志（全记录） | 严格执行「任何更新均须写入更新日志」规则：`releases[0].highlights` 详实记录本次所有细微与重大变更，并在 `docs/web-team/发布/版本说明-vX.Y.Z.md` 归档 |
| 3 | 题库 / 案例 / 知识点 | `public/data/questions.json`、`cases.json`、`kb-index.json`、`kb-search-index.json` 存在且为本次拟发布内容 |
| 4 | 环境变量 | 托管平台注入 `NEXT_PUBLIC_SUPABASE_URL` + `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`（或 ANON）；**禁止** `service_role` |
| 5 | Auth 回调域名 | Supabase Dashboard → Authentication → URL：站点域名（含 `https://`）已加入 |
| 6 | 构建产物 | `out/index.html`、`out/about/`、`out/case/`、`out/kb/`、`out/changelog/` 齐全 |
| 7 | trailingSlash | 本站 `next.config.ts` 已开；托管勿再错误重写去掉尾斜杠导致 404 |
| 8 | 合规 | 关于页声明仍在；勿把未审计知识点草稿当正式稿挂站 |

自动化：`node scripts/check-release.mjs`（或 `npm run check:release`）覆盖 1–3、部分 6；4–5、7–8 需人工确认。

## EdgeOne / 静态托管要点

1. 构建命令：`npm run build`  
2. 输出目录：`out`  
3. Node 版本：建议 20 LTS  
4. 安装：`npm ci`（或 `npm install`）  
5. 环境变量：构建期写入 `NEXT_PUBLIC_*`（静态导出打入前端包）  
6. push `main` 若已接 CI：确认流水线 env 与本地一致后再合并发版

## 回滚

保留上一版 `out/` 或托管平台「上一成功构建」一键回滚；内容回退则 revert 对应 commit 后重新 `build` 上传。
