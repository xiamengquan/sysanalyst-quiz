# 版本说明 v0.9.39

## 变更要点

- 刷题/案例设置页：≤959px 主内容置于筛选之上；筛选区默认折叠，一键展开。
- 答题 sticky 操作栏：移动端主操作三键 44px 高，次要操作独立一行。
- 顶栏 ≤420px 隐藏考期倒计时胶囊；知识点 API 节锚点加大触控面积。
- `body` 背景在窄屏改为 `scroll`，减轻 iOS 滚动卡顿。

## 验收

- `npm run lint`、`npm run build`、`npm run check:release` 通过
- 390px 宽：刷题首页首屏可见「随机 75 题/开始答题」；答题页底栏不遮挡 Tab
