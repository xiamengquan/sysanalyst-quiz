# 版本说明 v0.10.18（2026-10-11）

## 主题

演练场新增「故事线」记忆模式：三条步骤链化身「剧组拍电影 / 盖图书馆 / 委托装修」。

## 设计原则

用户痛点：知识点记住了，但案例里「步骤的作用与差异」下不了手——缺的是**因果直觉**。故事补直觉，术语层不动：

- 故事是钩子不是替代品：范例句、一句话作用、差异辨析、易错点保持考纲口径不变
- 故事模式开关（默认开，localStorage `sysanalyst_drill_story_v1` 记忆）：时间紧可切纯应试模式

## 实现

1. **内容**（`content/drills/*.md`）：每步新增 `- **故事**：` 字段；链头新增 `> **故事线**：` 总开场
   - UML 建模 = 剧组拍电影：剧本大纲（用例）→ 演员人设（类）→ 分镜（顺序）→ 主角心理线（状态）→ 片场调度（活动）→ 定档发行（部署）
   - 数据库设计 = 盖图书馆：蹲点问读者 → 建筑草图（ER，不管用什么砖）→ 施工规范图（关系模式+范式）→ 书架索引摆放 → 施工试运营 → 开馆养护（重组/重构 = 挪架/扩馆）
   - 需求工程 = 委托装修：听唠叨（五法=面谈/问卷/跟住/样板间/碰头会）→ 画图纸（加工不收集）→ 签合同（SRS 可验收）→ 开工前验图纸（一块橡皮 vs 砸墙）→ 变更单（控制+影响分析+台账）
2. **构建**（`scripts/build-drills.ts`）：解析故事线/故事字段 → drills.json（3 decks / 17 stories）
3. **UI**（`src/components/DrillApp.tsx`）：首格上方「🎭 故事线开场」卡；揭示卡中「🎭 记忆剧情」高亮段（紧跟一句话作用）；顶栏「🎭 故事 开/关」切换
