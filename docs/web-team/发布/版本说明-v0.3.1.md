# 版本说明 · v0.3.1

> 发布：网站协调 · 2026-09-10（晚）

## 本版变更

- **知识点站内阅读**：顶栏「知识点」点击条目后直接渲染 Markdown 正文，无需打开编辑器
- 启动时自动 `sync_kb_web.py`，将正式清单中的 `.md` 镜像到 `答题网页/kb/`
- 本地渲染依赖 `vendor/marked.min.js`（离线可用）
- 章节条目仍可「在本章刷题」

## 构建 / 启动

```bash
python3 题库/出题工坊/scripts/sync_kb_web.py   # 亦可由 ./启动.sh 自动执行
题库/答题网页/./启动.sh
# → http://127.0.0.1:8765/#/kb
```
