# 版本说明 v0.20.2（2026-10-24）

## 变更要点

1. **新增速查卡**：《需求分析工具 · 定义与用法速查》（`quick-req-tools`），注册于知识库「速查」区，紧随「需求工程 · 体系化学习路径」之后。
2. **内容结构**（12 类分析工具，均含「定义 + 用法 + 适用场景」）：
   - 加工逻辑三件套：结构化语言、判定表（含示例表）、判定树 + 选型口诀；
   - 功能建模：数据流图 DFD（绘制四步/分层/纠错四类/三作用）、数据字典 DD（六类条目/四作用）；
   - 数据建模：E-R 图、层次方框图、Warnier 图、IPO 图；
   - 行为建模：状态转换图 STD、Petri 网；
   - 面向对象建模：用例图、类图、顺序图、状态图、活动图（附 BCE/CRC 提示）；
   - 辅助：因果图（与判定表的推导关系）。
   - 收尾附「问什么 → 用什么」选型速记表与总口诀。
3. **交叉链接**：相关考点用站内约定书名号写法（需求分析 / 结构化分析 / 面向对象分析 / 三张速查卡），渲染为 kb-ref 预览锚点。
