# 版本说明 v0.10.7（2026-10-11）

> **主题**：新增「知识点洗脑音频」（`/audio`）——浏览器语音合成循环播放闪卡，零散时间磨耳朵强化记忆。

## 背景

用户距考试两周，希望在零散时间（通勤/散步/排队）通过音频循环强化知识点记忆。选择 **Web Speech API（speechSynthesis）** 方案：纯前端、零音频文件、零流量成本、无需构建产物，内容随闪卡库自动更新。

## 实现

### 新增 `src/components/AudioApp.tsx` + `src/app/audio/page.tsx`

- **数据源**：`/data/flashcards.json`（155 张 = 总册必会 M 97 + 卡组硬记忆点 K 58），内容更新即自动生效。
- **两种播放模式**：
  - 洗脑式：答案连读 ×2/3/5 遍（可调），适合纯磨耳朵；
  - 问答式：读题 → 停顿 1.2s → 读答案，适合「听题默答」。
- **控制**：总册 D1–D7 日次 + M/K 层级筛选、语速 0.7–1.6x、顺序/随机、定时停止（15/30/60 分钟）、发音人选择（设备 zh 语音）、上一张/下一张/暂停/停止、设置 localStorage 持久化。
- **TTS 读文本清理**（`speakText`）：`＞`→「大于」、`→`→「到」、`＝`→「等于」、`；`→句号、`★`→「重点」、`〔旧称构件〕`→逗号括注、中文间 `/`→「或」（公式卡不受影响）。
- **播放链竞态防护**：世代号（genRef）+ 停止标记，`cancel` 触发的 `onerror` 与手动跳转不会双跳。

### 入口与收录

- `scripts/seo-utils.mjs` staticRoutes 加 `/audio`（priority 0.7）；sitemap 256→**257**。

## 已知边界（页面内已提示）

- iOS 锁屏后 speechSynthesis 会暂停（无后台音频通道）；建议亮屏播放或连接耳机。此为浏览器平台限制，若后续需要真后台，可评估 edge-tts 预生成 MP3 方案。
- 不支持的浏览器（无 speechSynthesis）显示引导文案。
