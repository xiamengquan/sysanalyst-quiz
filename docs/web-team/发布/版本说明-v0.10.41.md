## 二、交付物

### 1. 数据层 `src/lib/se-system.ts`（新）
系统状态聚合器：统一读取 track / recall / today 勾选 / case 草稿四个存储 + tracks/flashcards 静态数据，产出 `SeSystemState`（mission / courses / points / recall / execution / cases / risks）。

### 2. 总控台 `/system`（新页面 + SystemApp.tsx）
- **使命层**：系统使命卡（倒计时环 + 39 点掌握度 + 三科里程碑按钮）
- **系统健康带**：今日执行（连续天数）、39 点掌握（风险数）、背诵闭环（到期卡 + 盒级分布条）、案例作答（草稿数 + 验证节点）
- **分解层 · 39 点状态矩阵**：4 域 × 每点格子（颜色=状态机），点击直达 `/track/?point=<pid>`
- **控制层 · 风险登记册**：错过的点按风险排行（wrong 降序 × 错误率），纠偏动作「⚡冲该域 / 📖重学总册锚点」直达
- **基线层 · 今日执行单**：`TodayApp embedded` 内嵌，勾选实时写回
- **反馈层**：/recall 到期卡 + /audio 洗脑音频入口

### 3. TodayApp `embedded` 模式
`/today` 页面组件支持 `embedded` 属性（只渲染执行单本体），总控台内嵌；`/today` URL 保留零破坏。

### 4. TrackApp 深链
`/track/?point=<pid>` / `/track/?course=<cid>`：解析后定位课程卡/单元按钮平滑滚动——总控矩阵与风险登记册的直达通道。

### 5. 导航重组
- SiteHeader tabs 首项「今日」→「总控」（Radar 图标，`/system/`）；`/today/` 归属总控组高亮
- 练习场页：池卡「今日计划」→「总控台」；轨道 stat 更新 406 题 + ⚡冲击；页脚加总控回链

### 6. SEO
