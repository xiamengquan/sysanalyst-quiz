# 版本说明 v0.20.0（2026-10-22）

## 定位

新功能模块（Minor）：上线「视频笔记」板块（`/notes`），将《系统分析师·案例分析通关》（UP 主：酒哥编程，B 站，全 8 讲）视频内容转写整理为可在线阅读的复习资料，与考点库/音频讲透并列为第四个学习入口。

## 背景

- 素材来源：B 站课程视频音频经 whisper（large-v3-turbo）本地转写，人工校正术语错字后成文；
- 8 份单讲笔记 + 1 份「总复习手册」汇编，共 9 篇，约 150KB 文本。

## 变更要点

### 1. 数据层

- `public/data/notes-md/`：9 篇 markdown（`00-handbook` + `01`~`08` 按讲次编号）
- `public/data/notes-index.json`：笔记元数据（标题/讲次/时长/发布日期/原视频链接/摘要）

### 2. 页面与组件

- `src/app/notes/page.tsx`：静态导出页（含 metadata）
- `src/components/NotesApp.tsx`（新）：客户端目录 + 阅读器
  - 桌面双栏（左目录右正文），移动端「目录 ⇄ 正文」切换 + 返回按钮
  - 正文经 `marked` 渲染复用全局 `.md-body` 样式；外链 `target=_blank`
  - 支持 `#hash` 直达某篇；正文按需拉取 `/data/notes-md/{id}.md`
- **不注入 kb-index**：视频笔记属整理资料而非审计考点，遵循「未审计内容不标正式」约束，独立于考点库体系

### 3. 导航与入口

- `SiteHeader`：tabs 新增「视频笔记 /notes」（NotebookPen 图标）；移动端底栏 grid-cols-4 → 5
- 首页：entries 新增「视频笔记」卡（三卡回四卡）

### 4. SEO

- `scripts/seo-utils.mjs`：staticRoutes 新增 `/notes`（weekly, 0.7）；`npm run sync:all` 重建 sitemap
