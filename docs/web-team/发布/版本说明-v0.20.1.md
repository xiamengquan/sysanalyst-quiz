# 版本说明 v0.20.1（2026-10-23）

## 定位

体验优化（Patch）：「音频讲透」连续播放两项增强——默认循环 + 屏幕常亮。

## 变更要点

### 1. 默认连续循环播放

- `AudioApp` 整组循环默认值 `false → true`：播完一组自动接下一轮，不用手动重开
- 设置存储键升级 `sysanalyst_audio_settings_v1 → v2`：老用户其余设置（模式/遍数/语速/顺序/定时/范围）原样迁移；v1 的 `loopAll` 不迁移（v1 默认「播完停止」，v2 起默认「连续循环」）
- 「整组循环」选项顺序调整：∞ 连续循环（默认）/ 播完一遍停止；播放中状态条文案同步改为「∞ 连续循环」
- 页面导语更新：说明默认连续循环与常亮行为

### 2. 屏幕常亮锁（Wake Lock）

- 播放中（`phase === "playing"` 且未暂停）申请 `navigator.wakeLock.request("screen")`，停止/暂停时释放
- `visibilitychange` 回到前台自动补申请，组件卸载时释放
- 不支持的浏览器静默降级（try/catch），不影响现有播放链路
