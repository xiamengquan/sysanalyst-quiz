# 版本说明 · v0.7.1

> 发布：网站程序 · 2026-09-23  
> 依据：站点更新必记日志规范 · 关于页合规声明卡片顶部多余留白与内边距失衡修复

## 本版变更

### 缺陷修复与体验优化

- **关于页合规声明卡片顶部多余留白修复**：
  - **问题根因**：全站早先从原生 shadcn 依赖重构为极简自研组件体系时，`Card` 容器自身内置了 `p-4 sm:p-5`（16px / 20px）的完整内边距。而在关于页（`src/app/about/page.tsx`）中，顶部的合规声明卡片由于无 `CardHeader`，子元素 `<CardContent>` 仍残留了旧版模板的 `pt-6`（padding-top: 24px）。两者叠加导致卡片上方留白高达 44px，而下方留白仅 20px，造成卡片“上面空了一大块”、文字偏在下方的视觉失衡。
  - **修复实现**：移除 `CardContent` 上的多余 `pt-6`，容器内部上下左右恢复由 `Card` 统一内边距管理，垂直间距恢复完美居中与对称，左右边距与下方的“本站是什么”、“功能一览”各卡片保持严格像素级对齐。
