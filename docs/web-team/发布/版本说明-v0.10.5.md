# 版本说明 v0.10.5（2026-10-11）

> **主题**：随机问答（`/recall`）升级——线上作答 + 系统自动比对判定对错，保留人工改判权。

## 需求

用户提出：随机问答系统支持线上回答，回答完毕后系统自动比对答案判定是否正确。原流程为「看答案 → 人工三键自评」，现升级为「作答 → 提交 → 自动判定 → 预选档位 → 可改判确认」。

## 实现

### 新增 `src/lib/answer-match.ts`（纯前端零依赖比对引擎）

- **关键点抽取**：标准答案按标点/分隔符切 token，剔除三类噪声——题面已含概念词（如「CMMI 五级」）、计数描述词（三特点/四阶段…）、旧称括注（〔旧称构件〕）与停用词。
- **判定规则**：
  - 答案规范化全等 → `correct`；
  - 关键点全命中（≥75%）→ `correct`；命中 ≥45% → `partial`；否则 `wrong`；
  - **顺序敏感**：含 `＞/→` 的关键点（排序型口诀、UML 关系强弱序）按词序列依序校验，乱序不命中；核心排序点命中但整体不足时保底 `partial`；
  - 弱符号（`/ + = -`）匹配前双方剔除（用户写「类型契约」可命中「类型/契约」）；
  - 无可判关键点（公式/图形卡，如沟通渠道 n(n−1)/2）→ `manual`，回退人工自评。
- **冒烟与自洽校验**：155 张卡全量「用标准答案本体作答必须判对」自洽通过；人工用例（口诀对/旧口诀错/乱序/漏项/照抄）行为符合预期。

### `RecallApp.tsx` 出题视图改造

- 题面下新增作答 textarea（自动聚焦、Enter 提交、Shift+Enter 换行、输入法 composing 防误触、移动端适配）；
- 提交后显示判定条（✅ 正确 / ⚠️ 部分 / ❌ 未通过，含 `关键点 n/m`）+ 命中（绿）/未命中（红）关键点 chips + 标准答案全文；
- 判定预选自评档位（对→记住 / 部分→模糊 / 错→忘了；跳过/无法判定→不预选），三键保留、可改判后确认；
- 「想不起来，直接看答案」入口预选「忘了」；
- 莱特纳盒 `applyGrade` 排程逻辑不变；会话统计口径不变。
