# 版本说明 · v0.8.2

> 发布：网站程序 · 2026-09-24  
> 依据：站点更新必记日志规范 · 对齐 2026 系统分析师机考上午连考安排

## 本版变更

### 产品与备考文案

- **2026 机考安排对齐**（以准考证与考场系统为准）：
  - **上午连考**：综合知识（75 题）与案例分析**同场连续机考**，08:30 起。
  - **提前交卷**：选择题答题上限 **150 分钟**，**满 120 分钟可交卷**（比上限早 30 分钟），交卷后**立即进入案例分析**。
  - **下午场**：论文写作（通常 15:30 起）说明保留。

### 落地文件

- `src/lib/exam-schedule.ts`：统一常量与说明文案。
- `ExamCountdown.tsx`：冲刺锦囊、横幅文案。
- `QuizApp.tsx`：随机 75 题模考卡片说明。
- `content/kb/00-使用说明与知识地图.md`、`案例分析答题教程.md`：知识库正文同步。

## 验收

- `npm run sync:kb` 后 `public/kb/` 含新段落。
- `npm run check:release` · `npm run lint` 通过。
