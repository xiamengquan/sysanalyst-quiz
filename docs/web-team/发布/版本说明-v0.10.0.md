# 版本说明 v0.10.0

- **版本号**：0.9.74 → 0.10.0（Minor：四大模块结构性重构）
- **日期**：2026-10-11
- **背景**：用户决策——知识点系统以「四层七日背诵总册」（v0.9.74 上线）为学习主线完全重编入口与联动；刷题、案例系统围绕知识点巩固重建；真题独立成系统。

## 变更要点

### 1. 知识点系统：四层七日学习主页（`src/components/KbApp.tsx`）

- `/kb` 落地页改为 **learn 视图（默认）**：总册主入口卡 + D1–D7 快捷卡（主题、主打考点、章节覆盖、「背总册 Dx」锚点跳转 +「刷当日配题」深链）+ 复习工具区（记忆强化卡组 / 知识点地图 / 考前 7 天清单 / 高频对比 / 案例 14 天 / 项管计算）
- 原 174 篇考点列表降级为 **dict 视图「字典检索」**，由 learn 页按钮进入，视图内可一键返回学习主页
- 总册 D1–D7 标题前注入显式锚点 `<a id="dN">`，学习主页「背总册 Dx」可直达当日章节

### 2. 刷题系统：七日巩固默认模式（`src/components/QuizApp.tsx` + `src/lib/kb-seven-day.ts`）

- 新增 `src/lib/kb-seven-day.ts`：D1–D7 与题库章节映射（D1 软工7 / D2 需求11+规划10 / D3 架构12+Web16+微服务20 / D4 数据库5+测试14 / D5 安全9+项管8 / D6 计组3+网络4+设计13+运维15 / D7 企信6+嵌入式17+移动18+大数据19+CPS21+论文22+杂项0/1/2）
- 学习路径新增「七日巩固（推荐）」并设为默认：按当日章节自动配题（自编 + 工坊；D7 含论文自测），筛选面板联动显示日次选择
- 设置页新增「七日巩固」置顶卡片：D1–D7 一键直接组卷作答（显示每日配题数）
- 深链协议扩展：`?path=seven_day&day=d1`（`quiz-deep-link.ts`），供知识点主页跳转

### 3. 真题独立系统：`/real-exams`（`src/components/RealExamApp.tsx`）

- 新增真题系统页：综合知识真题 15 场次（完整卷 75 题成卷，2024 上起部分卷标注残卷）+ 全部场次乱序综合 + 案例真题 13 场次分池入口
- 场次作答复用刷题引擎：QuizApp 新增 `realExamMode` / `initialYearHalf` props（题库锁定真题、隐藏学习路径与模拟卷、场次筛选启用）
- **练习池剔除真题**：自编/工坊路径（场景混淆、分值加练、稳练扫盲、前端友好、数学先易后难、全库随机 75）不再混入真题；`/quiz?bank=real` 旧深链自动 302 至 `/real-exams/`
- 导航新增「真题」tab（顶部 + 移动底栏 grid-cols-6）；sitemap 新增 `/real-exams`（253 → 254）

### 4. 案例系统：训练计划联动主页（`src/components/CaseApp.tsx`）

- setup 主区置顶「案例强化 · 14 天训练计划」联动卡（训练计划 / 四类题型导航 / 四层七日总册 / 记忆强化卡组入口）
- 整卷演练标注「真题卷分池」；自由练习区明确自编/真题分池 + 综合知识真题指向真题系统
- 支持 URL 参数：`?bank=real&year=2026上&domain=…&type=…`（真题系统按场次深链进入案例真题；页面包 Suspense）
