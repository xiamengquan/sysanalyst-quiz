# 版本说明 · v0.8.3

> 发布：网站程序 · 2026-09-24  
> 依据：站点更新必记日志规范 · 篇索引等正文内 .md 相对链接无法打开修复

## 本版变更

### 缺陷修复

- **篇索引 / 章节目录表格链接打不开**：
  - **现象**：打开「篇索引」（如 `p1-index`）后，表格中章节链接指向 `./第01章-绪论.md` 等相对路径，浏览器请求无效 URL，无法进入对应知识点页。
  - **修复**：在 `renderKbMarkdown` 中增加 Markdown 文件链接重写，结合 `kb-index` 将 `.md` 相对/文件名链接解析为 `/kb/{id}/`；阅读页点击兜底同样走 `resolveKbRef`。

## 验收

- 访问 `/kb/p1-index/`，点击「第01章」链接应进入 `/kb/ch01/`（或抽屉预览对应章节）。
- `npm run lint` · `npm run check:release` 通过。
