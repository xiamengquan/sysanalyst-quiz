# 信息架构

> 版本：v2 · 2026-09-19 · 设计产出 · 对齐站点 v0.6.0（Next.js App Router 静态导出）  
> 技术栈：Next.js 15 · `output: "export"` · `trailingSlash: true` · shadcn/ui  
> 配套：`页面说明.md` · `视觉与交互规范.md`

> **历史说明**：v1 基于 `题库/答题网页` 单页 hash 路由（`#/`、`#/kb` 等）与 localStorage 进度；v2 起为 App Router 多页静态站点，进度主存 IndexedDB，可选 Supabase 云同步。

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 第一屏即刷题 | 根路径 `/` 即刷题设置，主操作「开始答题」首屏可见，不做统计仪表盘 |
| 内容与程序分离 | 题目 / 案例 / 知识点来自 `content/` 权威源，经 sync 脚本写入 `public/`，前端只读 JSON / Markdown |
| 本地优先 | 刷题进度、案例草稿默认存 IndexedDB；不上传任何数据，除非用户登录且显式开启云同步 |
| 多模块一体 | 综合知识刷题、案例分析、知识点阅读、更新日志、关于说明共用壳层与导航 |
| 合规可见 | 「关于」页声明个人学习用途、真题勿外传 |

**设计范围外**：题目内容、解析、知识点正文的对错与完整性——由出题工坊 / 知识点工坊负责，网站只消费已发布产物。

## 2. 站点地图

```text
系统分析师 · 刷题站（静态导出 out/）
├── /                    刷题（默认首页）
│   ├── setup            筛选 + 模式 + 开始
│   ├── quiz             答题 + 关联知识点抽屉
│   └── result           统计 + 错题 / 断点
├── /case/               案例分析
│   ├── setup            筛选 + 模拟包 / 自由练习
│   ├── list             练习列表
│   └── quiz             作答 + 七步法 + 知识点抽屉
├── /kb/                 知识点目录
├── /kb/[id]/            知识点正文（SSG，id 来自 kb-index）
├── /changelog/          更新日志
└── /about/              合规 · 功能 · 部署
```

**不单独开顶栏页、但在刷题 / 案例筛选内区分的能力：**

- 自编练习、综合知识真题、出题工坊新题、论文自测——刷题页「题库」筛选
- 真题卷 / 五选三模拟包——案例页「模拟包」卡片
- 学习路径（P0/P1/P2、前端友好等）——刷题 / 案例「路径」筛选

## 3. 全局导航

### 3.1 顶栏（`SiteHeader`）

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 系统分析师 · 刷题站    [Auth] [主题] [⌘K]  刷题 案例 知识点 更新 关于 │
└──────────────────────────────────────────────────────────────────────┘
```

| 区域 | 组件 | 说明 |
|------|------|------|
| 品牌 | `Link → /` | 桌面「系统分析师 · 刷题站」；移动「系分刷题」 |
| 账户 | `AuthButton` | 未配置 Supabase 时隐藏；登录 / 注册 / Magic Link；云同步开关 |
| 主题 | `ThemeToggle` | 浅色 / 深色 / 跟随系统 |
| 搜索 | `GlobalSearch` | `Ctrl+K` / `⌘K`；站点导航 + 知识点全文检索 |
| 主导航 | 5 × `Button` + `Link` | 刷题 / 案例 / 知识点 / 更新 / 关于；当前页 `secondary` 高亮 |

- 顶栏 `sticky`，背景半透明 + 毛玻璃；适配 safe-area（`--safe-t`）
- 桌面（`sm+`）：5 项横排于顶栏右侧
- 移动（`< sm`）：顶栏仅显示当前页名 + 工具按钮；**底部 Tab 栏**承担主导航

### 3.2 移动端底栏

固定底部 5 列网格，与顶栏同路由：`/` · `/case/` · `/kb/` · `/changelog/` · `/about/`。当前项主色 + 顶指示条。高度 `--tabbar-h`，避让 safe-area（`--safe-b`）。主内容区需预留底栏占位。

### 3.3 页脚

桌面可见（`sm+`）：一行说明「个人学习用途 · EdgeOne / 本地均可部署 · 数据来自知识点精炼与出题工坊正式产物」。不含快捷键提示（答题快捷键见页面说明）。

## 4. 路由与状态

App Router 文件路由；构建时 `generateStaticParams` 为 `/kb/[id]/` 预生成全部知识点页。

| 路由 | 页面组件 | 客户端状态 | 持久化 |
|------|----------|------------|--------|
| `/` | `QuizApp` | `setup` / `quiz` / `result` | IndexedDB `sysanalyst_quiz_v4` |
| `/case/` | `CaseApp` | `setup` / `list` / `quiz` | IndexedDB `sysanalyst_case_v1` |
| `/kb/` | `KbCatalog` | 筛选 kind / section | — |
| `/kb/[id]/` | `KbReader` | 预览栈、固钉 | — |
| `/changelog/` | `ChangelogApp` | — | — |
| `/about/` | 静态 Card 布局 | — | — |

**深链示例：**

- `/kb/速查-uml-体系化学习指南/` — 直接打开知识点正文
- `/?chapter=12&bank=practice` — 刷题设置预填章节（KbReader「本章刷题」链出）

**跨页行为：** 答题中切换顶栏 / 底栏到其他页：Next.js 整页导航，进度已在 IndexedDB 自动保存，无需阻塞模态。

## 5. 内容源映射

| 用户可见能力 | 权威源 | 构建命令 | 站点消费 |
|--------------|--------|----------|----------|
| 自编练习 / 真题 / 工坊题 | `content/banks/` + `content/workshop/` | `npm run sync:data` | `public/data/questions.json`、`question-meta.json` |
| 论文自测 | 同上（paper 子集） | 同上 | `public/data/paper.json` |
| 案例分析 | `content/banks/` 案例 JSONL | 同上 | `public/data/cases.json`、`case-packs.json`、`case-meta.json` |
| 知识点目录 | `content/kb-index.json` | `npm run sync:kb` | `public/data/kb-index.json` |
| 知识点正文 | `content/kb/**` | 同上 | `public/kb/**`（Markdown 静态文件） |
| 知识点搜索 | sync:kb 内 rebuild | 同上 | `public/data/kb-search-index.json` |
| 更新日志 | 构建产物 | sync:data | `public/data/release-notes.json` |

完整构建：`npm run build` = `sync:all` + `next build` → 输出 `out/`。

## 6. 进度与同步

```text
写入路径：QuizApp / CaseApp → storageSet → IndexedDB (kv store)
                                    ↓（已登录 + 云同步开启）
                              cloud-sync → Supabase user_progress
```

| 层级 | 机制 | 说明 |
|------|------|------|
| 主存储 | IndexedDB `sysanalyst-quiz` / store `kv` | 刷题进度、案例草稿；key 含 `updatedAt` |
| 迁移 | 首次读取同名 localStorage key | 成功后删除 localStorage 副本（兼容旧版答题网页） |
| 云同步（可选） | Supabase + `AuthButton` 开关 | 需配置 `NEXT_PUBLIC_SUPABASE_*`；默认关闭；Last-Write-Wins |
| 主题 / 版本提示 | localStorage | `theme`、`sysanalyst_release_seen`（非答题数据） |

未配置 Supabase 或未登录时，站点行为与纯本地站一致。

## 7. 用户主路径

### 路径 A：快速开刷（默认）

```text
打开 / → 刷题设置 → （可选调筛选）→ 开始答题 → 答题 → 结果
```

### 路径 B：案例七步法

```text
/case/ → 选模拟包或列出练习 → 进入套题 → 「作答」写草稿 / 「七步法」看拆解 → 对照参考要点
```

### 路径 C：先读后练

```text
/kb/ → 选篇阅读 → 「本章刷题」或顶栏回 / → 章节筛选对齐 → 开始答题
```

### 路径 D：看更新日志

```text
首次打开新版本 → UpdateNotice 弹窗 → /changelog/ 查看全文
```

### 路径 E：登录同步（可选）

```text
AuthButton 登录 → 开启云同步 → 换设备 pull → 刷题 / 案例进度一致
```

## 8. 与其他模块关系

```text
content/banks + content/workshop ──sync:data──► public/data/*.json ──► 刷题 / 案例页
content/kb ──sync:kb──► public/kb/ + kb-index + search-index ──► 知识点 / 全局搜索
docs/web-team · src/ ──实现──► Next.js 静态站点（out/）
```

设计不修改题目与知识点内容；发现问题走工单至对应工坊 / 委员会。
