# 信息架构

> 版本：v1 · 2026-09-10 · 设计产出 · 对齐 `题库/答题网页/index.html` 基线  
> 站点形态：本地静态站点（`python -m http.server` / `./启动.sh`），无账号体系  
> 配套：`页面说明.md` · `视觉与交互规范.md`

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 第一屏即刷题 | 进入站点默认落在「刷题」页，首屏可见「开始答题」主操作，不做统计仪表盘 |
| 内容与程序分离 | 题目来自 JSONL merge 产物；知识点来自审计委员会正式发布稿（未发布则占位） |
| 本地优先 | 进度存 `localStorage`；不上传答题数据 |
| 合规可见 | 「关于」页声明个人学习用途、真题勿外传 |

## 2. 站点地图

```text
系统分析师 · 本地刷题（根 /）
├── 刷题                    ← 默认路由，第一屏
│   ├── 设置区（筛选 + 模式 + 开始）
│   ├── 答题区（题干 / 选项 / 进度）
│   └── 结果区（统计 + 错题回顾 + 断点继续）
├── 知识点                  ← 只读阅读
│   ├── 章节目录（00–22 章，对齐综合知识大纲）
│   └── 章节正文（Markdown 渲染）
└── 关于                    ← 合规与使用说明
    ├── 站点说明
    ├── 数据来源与版本
    └── 隐私与版权声明
```

**不在顶栏单独开页、但保留在刷题流内的能力：**

- **真题**：`bankFilter = real`，配合年份筛选（基线已有）
- **出题工坊**：`bankFilter = workshop`（基线已有）
- **自编练习**：`bankFilter = practice` + 章节筛选（基线已有）

顶栏仅三项，避免导航膨胀；真题 / 工坊 / 练习通过刷题页筛选器区分，符合「第一屏聚焦开始刷题」。

## 3. 全局导航

### 3.1 顶栏结构

```text
┌─────────────────────────────────────────────────────────────┐
│ 系统分析师 · 本地刷题          [ 刷题 ] [ 知识点 ] [ 关于 ] │
└─────────────────────────────────────────────────────────────┘
```

| 项 | 路由（建议） | 默认 | 说明 |
|----|--------------|------|------|
| 刷题 | `#/` 或 `#/quiz` | ✓ | 站点首页；含设置 / 答题 / 结果三态 |
| 知识点 | `#/kb` | | 章节目录 + 正文阅读 |
| 关于 | `#/about` | | 合规、启动方式、题库版本 |

- 当前页顶栏项高亮（accent 下划线或字色）
- 移动端：顶栏不换行；站点名可缩为「系分刷题」
- 刷题**答题中**切换顶栏到其他页：提示「进度已自动保存」，允许离开（不弹阻塞模态）

### 3.2 页脚（全站共用）

- 快捷键提示：`←` `→` 切题；`1–4` / `A–D` 选题（刷题答题态显示）
- 本地服务：`./启动.sh` → `http://127.0.0.1:8765/`
- 题量摘要：自编 · 真题 · 工坊 · 合计（来自 `meta.json` / `QUESTION_META`）

## 4. 路由与状态

建议单页应用（SPA）或轻量多 HTML，以 hash 路由为主，便于静态托管：

| 路由 | 视图 | 持久化 |
|------|------|--------|
| `#/` | 刷题 · 设置 | — |
| `#/quiz`（可选，或由 JS 态切换） | 刷题 · 答题 | `localStorage` key: `sysanalyst_quiz_v3` |
| `#/result`（内嵌于刷题流） | 刷题 · 结果 | 同上 |
| `#/kb` | 知识点 · 目录 | 上次阅读章节 → `sysanalyst_kb_last` |
| `#/kb/:chapter` | 知识点 · 正文 | 滚动位置可选存 localStorage |
| `#/about` | 关于 | — |

**深链：**

- `#/kb/12` → 直接打开第 12 章软件架构设计
- `#/?bank=real&year=2023` → 刷题设置预填（可选 v1.1）

## 5. 内容源映射

| 用户可见能力 | 权威源路径 | 站点消费方式 |
|--------------|------------|--------------|
| 自编练习 | `题库/综合知识/all.jsonl` | merge 进 `questions.js` |
| 真题选择题 | `题库/真题/上午真题.jsonl` | 同上 |
| 工坊新题 | `题库/出题工坊/新题/*-passed.jsonl` | merge 脚本 |
| 案例 / 论文真题 | `题库/真题/00-真题索引.md` | 关于页 + 知识点页外链说明 |
| 知识点正文 | `知识点工坊/审计委员会/正式发布/` | **发布门禁**：无正式发布则目录页显示「筹备中」 |

## 6. 用户主路径

### 路径 A：快速开刷（默认）

```text
打开站点 → 刷题（设置区）→ 选筛选（可不改默认）→ 「开始答题」→ 答题 → 结果
```

### 路径 B：连续通关

```text
刷题 → 「连续通关 · 当前筛选全部」→ 按序答完 → 本地自动存进度 → 下次「从断点继续」
```

### 路径 C：先读后练

```text
知识点 → 选章阅读 → 顶栏回刷题 → 章节筛选对齐该章 → 开始答题
```

### 路径 D：了解合规

```text
关于 → 阅读声明 → 刷题
```

## 7. 与其他模块关系

```text
出题工坊 ──merge──► questions.js ──► 刷题页
知识点编制 ──审计发布──► kb/*.md ──► 知识点页
网站小组·程序 ──实现──► 题库/网站小组/程序/ 或演进 答题网页/
```

设计不修改题目内容与知识点对错；发现问题走工单至对应委员会。
