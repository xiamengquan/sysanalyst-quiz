> **版本：v2 · 2026-09-19 · 对齐 v0.6.0 站点（shadcn/ui + next-themes）· 界面设计产出**  
> 原则：冷蓝主色 + slate 表面；支持浅色 / 深色 / 跟随系统；不套用常见 AI 紫白渐变模板  
> **实现基线：** `src/app/globals.css`、`src/app/layout.tsx`、`src/components/ui/*` · Skill：`sysanalyst-web-ui`

## 1. 主题模式（Theme Modes）

### 1.1 机制

| 项 | 规范 |
|----|------|
| 库 | [next-themes](https://github.com/pacocoursey/next-themes) |
| 挂载 | `ThemeProvider` 包裹根布局；`attribute="class"` 作用于 `<html>` |
| 可选值 | `light` · `dark` · `system` |
| 默认 | `defaultTheme="dark"`（首次访问无偏好时为深色） |
| 系统跟随 | `enableSystem`；`system` 时随 `prefers-color-scheme` 解析 |
| 持久化 | `localStorage` 键名 **`theme`** |
| 防 FOUC | `layout.tsx` 内联 boot script：在首屏渲染前读取 `theme` 并给 `<html>` 加 `light` / `dark`，同时设置 `colorScheme` |
| 切换入口 | 顶栏 `ThemeToggle`（`DropdownMenu`：浅色 / 深色 / 跟随系统） |
| 过渡 | `disableTransitionOnChange`，避免批量换肤时闪烁 |

**Boot script 逻辑摘要：**

```text
读取 localStorage.theme
→ 未设置或非 light 且（system 或未设置）且系统为 dark → dark
→ 否则 light
→ document.documentElement.classList + colorScheme
```

### 1.2 色板原则

- **主色：** 冷蓝 `--primary`（约 hue 245），用于 CTA、当前导航、链接  
- **表面：** slate 系 `--background` / `--card` / `--surface`，深浅模式各自独立 oklch 定义  
- **背景层次：** body 双层 `radial-gradient`（`--bg-glow-1` / `--bg-glow-2`）叠加于 `--background`  
- **禁止：** 高饱和紫罗兰渐变、白底卡片 + 紫 accent 的 AI 模板感  
- **语义色（模式无关）：** `--ok` / `--bad` / `--warn` 用于答题正误、深度题、合规提示

## 2. 设计令牌（Design Tokens）

### 2.1 语义色令牌

全站优先使用 **shadcn 语义变量**；Tailwind 通过 `@theme inline` 映射为 `bg-background`、`text-primary` 等。禁止在新代码中硬编码近似 hex。

| 令牌 | 用途 | 浅色意图 | 深色意图 |
|------|------|----------|----------|
| `--background` | 页面底色 | 近白、微冷 | 深 slate 底 |
| `--foreground` | 主文字 | 深灰蓝 | 近白 |
| `--card` | 卡片、面板、抽屉底 | 白 | 略亮于 background 的面板 |
| `--card-foreground` | 卡片内主文字 | 同 foreground | 同 foreground |
| `--popover` | 下拉、浮层底 | 白 | 同 card |
| `--popover-foreground` | 浮层文字 | 同 foreground | 同 foreground |
| `--primary` | 主操作、链接、当前态 | 中饱和冷蓝 | 较亮冷蓝 |
| `--primary-foreground` | primary 上的文字 | 近白 | 深底对比色 |
| `--secondary` | 次要按钮、徽章底 | 浅灰蓝 | 深灰面板 |
| `--secondary-foreground` | secondary 上文字 | 深灰 | 浅灰 |
| `--muted` | 禁用块、hover 底 | 浅灰 | 深灰 |
| `--muted-foreground` | 次要文字、标签、页脚 | 中灰 | 浅灰蓝 |
| `--accent` | 菜单选中、轻强调底 | 极浅蓝灰 | 深蓝灰块 |
| `--accent-foreground` | accent 上文字 | 深灰蓝 | 浅灰 |
| `--destructive` | 危险操作、校验错误 | 红 | 亮红 |
| `--border` | 边框、分隔线 | 浅灰线 | 半透白线 |
| `--input` | 输入框边框 | 同 border | 略亮于 border |
| `--ring` | 焦点环 | primary 色 | primary 色 |
| `--surface` | 嵌套输入区、选项底 | 略深于 background | 介于 background 与 card |
| `--sidebar-*` | 侧栏专用（预留） | 浅底 + primary 强调 | 深底 + primary 强调 |
| `--chart-1` … `--chart-5` | 图表序列色 | 蓝绿系 | 同系提亮 |

**模式无关语义色（`:root` 共用）：**

| 令牌 | 用途 |
|------|------|
| `--ok` | 正确、成功 |
| `--bad` | 错误、警示 |
| `--warn` | 深度题、合规提示 |
| `--bg-glow-1` / `--bg-glow-2` | body 背景 radial 光晕 |

### 2.2 布局令牌

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--content-max` | `1600px` | 顶栏、`.site-main`、页脚最大宽度 |
| `--tabbar-h` | `3.5rem` | 移动端底栏高度 |
| `--safe-t` / `--safe-b` | `env(safe-area-inset-*)` | 刘海 /  Home 指示条安全区 |

### 2.3 间距阶梯

| 令牌 | 值 | 典型用途 |
|------|-----|----------|
| `--space-1` | `0.35rem` | 紧凑内间距 |
| `--space-2` | `0.65rem` | 标题下距 `.page-title` |
| `--space-3` | `1rem` | 筛选栈间距 |
| `--space-4` | `1.35rem` | 卡片间距、`.stack` |
| `--space-5` | `1.85rem` | 副标题下距 `.page-lead`、`.stack-loose` |
| `--space-6` | `2.5rem` | 桌面主栏顶距 |

**常用组合（沿用 v1 节奏，已在 globals 落地）：**

| 场景 | 规则 |
|------|------|
| 主栏顶距 | 移动 `--space-5` → sm+ `--space-6` |
| 卡片内边距 | 移动约 `1.05–1.1rem` → sm+ `1.35–1.45rem` |
| 卡片间距 | `--space-4` / sm+ `--space-5` |

| 水平边距 | 移动 ≈1.15rem → sm 1.5rem → lg 2rem → xl 2.5rem |

### 2.4 圆角

| 令牌 / 类 | 值 | 用途 |
|-----------|-----|------|
| `--radius` | `0.65rem`（≈10px） | shadcn 默认控件圆角；衍生 `--radius-sm` … `--radius-4xl` |
| `--radius-card` | `16px` | 卡片 `.card`、大面板 |
| 选项 | `12px` | `.opt-btn` |
| 徽章 / FAB | `999px` | `.badge`、`.kb-fab-btn`、导航 pill |
| 进度条 | `99px` | `.progress` |

**约定：** 新 shadcn 组件用 `rounded-lg`（映射 `--radius`）；内容卡片可用 `rounded-2xl` 或 `--radius-card`。

### 2.5 行高

| 令牌 | 值 | 场景 |
|------|-----|------|
| `--leading-body` | `1.7` | 正文、题干 |
| `--leading-ui` | `1.5` | UI 说明、页脚 |

## 3. 字体与排版（Typography）

### 3.1 字体栈

```text
IBM Plex Sans（next/font，CSS 变量 --font-plex）
→ 系统 sans
→ PingFang SC / Hiragino Sans GB / Microsoft YaHei
→ sans-serif
```

- **加载：** `layout.tsx` 中 `IBM_Plex_Sans`，权重 400–700，`display: swap`  
- **数字：** `font-variant-numeric: tabular-nums` + `font-feature-settings: "tnum" 1`（题号、得分、统计对齐）  
- **字距：** 全站 `letter-spacing: 0.01em`

### 3.2 字号层级

| 层级 | 字号 | 字重 | 场景 |
|------|------|------|------|
| 站点标题 | `1rem`（sm+ 全名） | 600 | 顶栏 Logo |
| 页面标题 | `1.4rem` | 650 | `.page-title` |
| 区块 / 阅读 h1 | `1.35–1.5rem` | 650 | `.kb-reader-head h1` |
| 区块标题 | `1.15rem` | 600 | CardTitle、结果 h2 |
| 题干 | `1.05rem` | 400 | 刷题 stem |
| 正文 | `1rem` / `0.98rem` | 400 | `.md-body` |
| 辅助 | `0.92rem` | 400 | `.page-lead` |
| 标签 / meta | `0.82rem` | 400 | label、gs-trigger |
| 徽章 | `0.75rem` | 400 | Badge、`.badge` |

**页面标题约定：** 业务页 h1 用 `.page-title`，说明行用 `.page-lead`；多卡片竖排优先 `.stack` / `.stack-loose`。

## 4. 组件映射（shadcn/ui + 遗留样式）

组件库基于 **shadcn/ui（Radix 原语）**，位于 `src/components/ui/`。刷题等高频路径仍保留 `.btn` / `.card` / `.opt-btn` 遗留类，其颜色已映射到语义令牌。

### 4.1 Button 变体

| variant | 何时使用 |
|---------|----------|
| `default` | 主 CTA：开始答题、提交、确认 |
| `secondary` | 当前导航 Tab、次要强调块 |
| `outline` | 顶栏图标按钮（主题切换）、次要描边操作 |
| `ghost` | 工具栏、导航非当前项、低优先级操作 |
| `destructive` | 删除进度、不可逆操作 |
| `link` | 文内跳转、轻量「了解更多」 |

| size | 何时使用 |
|------|----------|
| `default` | 表单提交、对话框主按钮 |
| `sm` | 顶栏导航 Tab、紧凑工具栏 |
| `lg` | 首屏大 CTA（可选） |
| `icon` / `icon-sm` | 仅图标（ThemeToggle、关闭） |

**遗留 `.btn` 对照：** `.btn-primary` → `variant="default"`；默认 `.btn` → `secondary` / `outline`；`.btn-ghost` → `ghost`。

### 4.2 Card

- **shadcn `Card`：** 关于页分节、更新日志、设置面板等新页面  
- **遗留 `.card`：** 刷题设置/答题/结果、筛选侧栏；样式 `background: var(--card)`、`border: var(--border)`、`border-radius: var(--radius-card)`  
- 首屏设置卡片为刷题主视觉焦点：扁平、无发光阴影

### 4.3 Dialog vs Sheet

| 组件 | 形态 | 适用场景 |
|------|------|----------|
| **Dialog** | 居中模态 | 登录/注册（`AuthButton`）、版本更新提示（`UpdateNotice`）、需聚焦的短表单、确认框 |
| **Sheet** | 边滑 / 底升 | 移动端知识点预览（`KbPreviewDrawer`）、长内容侧栏、需保留上下文的预览 |
| **自定义 drawer** | `.kb-drawer-*` | 知识点关联预览；≥640px 右侧滑入，&lt;640px 底 sheet；可「固钉」为内容区侧栏 |

**原则：**

- 答题态 **禁止** 全屏 modal 锁死顶栏导航  
- 知识点关联用 drawer / sheet，不用阻断式全屏弹窗  
- 全局搜索（⌘K / Ctrl+K）用自定义 `.gs-dialog` 居中面板（类 Dialog 交互）

### 4.4 其他常用组件

| 组件 | 用途 |
|------|------|
| `Badge` | 考点标签、发布状态 pill |
| `Input` / `Textarea` / `Label` | 表单；遗留 `.field` 用于原生 select |
| `Switch` | 布尔设置（如连续模式开关） |
| `Tabs` | 同页多视图切换 |
| `DropdownMenu` | 主题切换、用户菜单 |
| `ScrollArea` | 长列表内滚动 |
| `Separator` | 区块分隔 |

**图标：** 全站 UI 图标使用 `lucide-react`（Sun / Moon / Monitor、BookOpen、Pin、X 等）。

### 4.5 刷题专用遗留组件

| 类名 | 说明 |
|------|------|
| `.opt-btn` | 选择题选项；态：默认 / `.is-chosen` / `.is-ok` / `.is-bad` |
| `.sticky-actions` | 答题底栏，sticky 于 tabbar 上方 |
| `.progress` | 进度条；填充用 `--primary` → `--ok` 渐变 |
| `.kb-toast` | 轻提示条（见 §6.3） |

## 5. 布局壳层（Layout Shell）

### 5.1 结构

```text
<html class="light|dark">
  <body>
    ThemeProvider
      SiteHeader          ← sticky 顶栏
      .site-main          ← 主内容（max --content-max）
      footer              ← sm+ 可见
      PortalHost          ← 全局 portal 挂载
      UpdateNotice
```

### 5.2 顶栏（SiteHeader）

| 属性 | 规范 |
|------|------|
| 定位 | `sticky top-0 z-50` |
| 背景 | `bg-background/90 backdrop-blur-md` + `border-b border-border/80` |
| 安全区 | `padding-top: var(--safe-t)` |
| 宽度 | `max-width: var(--content-max)` 居中 |
| 左 | Logo 链回首页；窄屏「系分刷题」 |
| 右 | AuthButton · ThemeToggle · GlobalSearch · 桌面 nav（5 Tab） |
| 窄屏 | 隐藏横向 nav，显示当前 Tab 名 |

**导航 Tab：** 刷题 / 案例 / 知识点 / 更新 / 关于  
**当前态：** `Button variant="secondary"` + `text-primary`；非当前 `ghost`。

### 5.3 移动端底栏（Tabbar）

| 属性 | 规范 |
|------|------|
| 可见 | `sm:hidden`（仅窄屏） |
| 定位 | `fixed bottom-0 inset-x-0 z-50` |
| 高度 | `var(--tabbar-h)` |
| 背景 | 同顶栏半透明 + blur |
| 安全区 | `padding-bottom: var(--safe-b)` |
| 项 | 5 列 grid；当前项 `text-primary` + 顶部 `bg-primary` 指示条 |

### 5.4 主内容区（`.site-main`）

| 属性 | 规范 |
|------|------|
| 宽度 | `min(100%, var(--content-max))` 居中 |
| 顶距 | `--space-5` / sm+ `--space-6` |
| 底距 | 含 tabbar + safe-area 留白（移动 `calc(tabbar + safe-b + 2rem)`） |
| 语义 | 对应 `<main>` 内容容器（layout 内层 div） |

### 5.5 分栏与阅读

| 模式 | 规则 |
|------|------|
| `.layout-split` | &lt;960px 上下堆叠；≥960px 且有 `.layout-aside` 时左筛选 sticky + 右主内容 |
| `.layout-full` | 无侧栏页占满壳层 |
| `.md-body.is-fluid` | 知识点阅读：无嵌套滚动盒，整页流式 |
| FAB | 左 `.kb-nav-fab`（返回目录 / 本章刷题）；右 `.kb-toc-fab`（本页索引） |

## 6. 交互规范

### 6.1 焦点（Focus Ring）

- **shadcn 默认：** `focus-visible:border-ring focus-visible:ring-3 focus-visible:ring-ring/50`  
- **遗留控件：** `.kb-fab-btn:focus-visible` 等用 `outline: 2px solid color-mix(..., var(--primary) 55%, transparent)`  
- **全局 base：** `* { outline-ring/50 }`（Tailwind `@layer base`）  
- 禁止移除焦点样式；键盘用户必须可见当前焦点

### 6.2 禁用（Disabled）

| 上下文 | 表现 |
|--------|------|
| shadcn Button | `disabled:pointer-events-none disabled:opacity-50` |
| 遗留 `.btn:disabled` | `opacity: 0.45; cursor: not-allowed` |
| 表单 | 继承 muted 色，不触发 hover |

### 6.3 Toast / 轻提示

| 项 | 规范 |
|----|------|
| 实现 | 自定义 `.kb-toast`（非 sonner）；`role="status"` |
| 位置 | 水平居中，底部 `tabbar + safe-b + 1rem` |
| 样式 | `background: var(--secondary)`、`border: var(--border)`、`z-index: 90` |
| 场景 | 复制成功、进度已保存、非阻塞操作反馈 |
| 禁止 | 用 `alert()` 阻断答题流（筛选 0 题等必要警告除外） |

### 6.4 动效

| 元素 | 动效 |
|------|------|
| 按钮 | `transition-all`；active 微位移 `translate-y-px` |
| 进度条 | 宽度 `0.25s ease` |
| Drawer / Sheet | `0.22s ease`；`prefers-reduced-motion: reduce` 时禁用 |
| 主题切换 | 无过渡（`disableTransitionOnChange`） |
| 路由 | 内容区 instant swap，无全屏过渡 |

**禁止：** 大面积 parallax、弹跳 loading、渐变骨架屏闪白。

### 6.5 键盘（刷题答题态）

| 按键 | 行为 |
|------|------|
| `←` / `→` | 上 / 下一题 |
| `1`–`4` / `A`–`D` | 选题 |
| `⌘K` / `Ctrl+K` | 全局搜索 |

设置区、知识点、关于页不抢占刷题快捷键。

### 6.6 Portal 层级

| 层 | z-index | 内容 |
|----|---------|------|
| sticky 底栏 / 顶栏 | 50 | SiteHeader、mobile tabbar |
| FAB / toast | 85–90 | kb-fab、kb-toast |
| Drawer 遮罩 | 80–120 | kb-drawer、gs-root |
| portal-channel | 200 | PortalHost 挂载点 |

## 7. 页面级差异（摘要）

### 7.1 刷题页

- 第一屏：标题 + 题量摘要 + 设置卡片；禁止首屏四宫格统计 / 日历 / 排行  
- 三态：`setup` / `quiz` / `result` 互斥，无整页刷新  
- CTA 顺序：`[开始答题]` → `[连续通关]` → `[随机打乱]`

### 7.2 知识点页

- 流式阅读 `.md-body.is-fluid`；链接 `color: var(--primary)`  
- 代码块 / 表格用 `--surface` + `--border`  
- 关联预览走 drawer，可固钉 `.kb-dock-layout`

### 7.3 关于页

- shadcn `Card` 分节  
- 合规声明置于上半部，左边框 `--warn`  
- 声明 localStorage 用途（进度、主题 `theme`、阅读位置等）

## 9. 无障碍基线

- 语义：顶栏 `<header>` + `<nav>`，主内容区，`<footer>`  
- 焦点：§6.1；图标按钮必须有 `aria-label`  
- 对比：深浅模式均须满足 WCAG AA（依赖语义令牌，不手写低对比灰）  
- 动效：`prefers-reduced-motion: reduce` 时 drawer 动画关闭  
- 主题：`<html lang="zh-CN">`；viewport `themeColor` 随系统 light/dark 分设

## 10. 禁止事项

| 禁止 | 原因 |
|------|------|
| 高饱和紫罗兰主色 / AI 渐变 hero | 破坏品牌识别 |
| 硬编码 hex 替代语义令牌 | 无法随主题切换 |
| 首屏仪表盘（图表、日历、排行） | 违背「第一屏聚焦刷题」 |
| 答题态全屏 modal 阻断导航 | 进度已本地保存 |
| 未发布知识点当正式内容展示 | 仅「筹备中」Badge |
