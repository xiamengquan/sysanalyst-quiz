# 视觉与交互规范

> 版本：v1.1 · 设计产出 · 基线：`题库/答题网页/index.html`  
> 原则：延续现有深色刷题风；不套用常见 AI 紫白模板；第一屏聚焦「开始刷题」  
> **v1.1：** 加大留白与行距，降低长时间阅读疲劳（见 §1.3）

---

## 1. 设计令牌（Design Tokens）

### 1.1 色板

从基线 `:root` 提取，全站统一使用 CSS 变量，禁止硬编码近似色：

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--bg` | `#0f1419` | 页面背景底色 |
| `--panel` | `#1a222c` | 卡片、顶栏、侧栏面板 |
| `--line` | `#2a3542` | 边框、分隔线 |
| `--text` | `#e7eef6` | 主文字 |
| `--muted` | `#8fa3b8` | 次要文字、标签、页脚 |
| `--accent` | `#3d9cf0` | 主操作、链接、当前导航 |
| `--ok` | `#3ecf8e` | 正确、成功 |
| `--bad` | `#f07178` | 错误、警示 |
| `--warn` | `#e6c07b` | 深度题、合规提示 |

**背景渐变（body）：** 两层 radial-gradient 叠加于 `--bg`：

```css
background:
  radial-gradient(1200px 600px at 10% -10%, #1b2a3d, transparent),
  radial-gradient(900px 500px at 100% 0%, #1a2e28, transparent),
  var(--bg);
```

**输入/选项底：** `#121820`（比 `--panel` 更深，形成嵌套层次）  
**默认按钮底：** `#243041`  
**选中选项底：** `#173049`（accent 色调）  
**正确选项底：** `#143028` · **错误选项底：** `#2a1719`

### 1.2 字体

```css
font-family: "SF Pro Text", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

| 层级 | 字号 | 字重 | 场景 |
|------|------|------|------|
| 站点标题 | 1.35rem | 650 | 顶栏 / 页 h1 |
| 区块标题 | 1.15rem | 600 | 结果页 h2、关于分节 |
| 题干 | 1.05rem | 400 | 刷题 `#stem` |
| 正文 | 1rem | 400 | 知识点 Markdown 正文 |
| 辅助 | 0.9rem | 400 | 副标题 `.sub` |
| 标签 | 0.82rem | 400 | `label`、meta |
| 徽章 | 0.75rem | 400 | `.badge` |
| 页脚 | 0.8rem | 400 | footer |

**行高：** 题干与正文 `1.7`（`--leading-body`）；反馈区 `1.55`；页脚 `1.5`  
**知识点正文行宽：** `max-width: var(--measure-prose)`（默认 `72ch`）  
**字距：** 全站 `letter-spacing: 0.01em`，减轻密集感

### 1.3 圆角与间距

> **v1.1 留白增强（2026-09）：** 内容区加宽、卡片与块间距加大，避免「挤在一坨」。实现见 `src/app/globals.css` 间距令牌。

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--space-1` … `--space-6` | 0.35–2.5rem | 全站节奏阶梯 |
| 卡片圆角 | `16px`（`--radius-card`） | `.card` |
| 控件圆角 | `10px` | button、select、input、`.stat` |
| 选项圆角 | `12px` | `.opt` / `.opt-btn` |
| 徽章圆角 | `999px` | `.badge` |
| 进度条圆角 | `99px` | `.progress` |
| 主栏顶距 | `--space-5` / 桌面 `--space-6` | `.site-main` |
| 卡片内边距 | 约 `1.05–1.45rem` | `.card`（桌面更大） |
| 卡片间距 | `--space-4` / 桌面 `--space-5` | 卡片之间 |
| 列表项间距 | `0.75rem` | `.list-gap` |
| 页面标题下距 | `--space-2` | `.page-title` |
| 副标题下距 | `--space-5` | `.page-lead` |
| 按钮间距 | `0.65rem` | `.btn-row` / `.sticky-actions` |

**页面标题约定：** 各业务页 h1 用 `.page-title`，说明行用 `.page-lead`；多卡片竖排优先 `.stack` / `.stack-loose`。

### 1.4 布局宽度（响应式）

| 区域 | 规则 |
|------|------|
| 全站壳层（顶栏 / `.site-main` / 页脚） | `width: min(100%, var(--content-max))`，`--content-max: 1600px` |
| 水平边距 | 随断点递增：移动 ≈1.15rem → sm 1.5rem → lg 2rem → xl/1440 2.5rem |
| 知识点正文 `.md-body` | `--measure-prose: 72ch`（壳层加宽后仍保舒适行长） |
| TOC FAB | 相对 `--content-max` 外侧定位 |

### 1.5 筛选侧栏（`.layout-split`）

| 断点 | 布局 |
|------|------|
| &lt;960px | 筛选在上、内容在下（单栏） |
| ≥960px | 左筛选（约 240–340px，sticky）+ 右主内容 |
| 适用页 | 刷题设置、案例筛选/列表、知识点目录 |

## 3. 组件规范

### 3.1 卡片 `.card`

```css
background: var(--panel);
border: 1px solid var(--line);
border-radius: 14px;
padding: 18px;
margin-bottom: 14px;
```

设置区卡片为刷题第一屏主视觉焦点，不叠加阴影或发光，保持扁平深色面板感。

### 3.2 按钮

**基础：**

```css
font: inherit;
border-radius: 10px;
border: 1px solid var(--line);
background: #243041;
color: var(--text);
padding: 10px 12px;
cursor: pointer;
transition: border-color 0.15s ease, background 0.15s ease;
```

| 变体 | 类名 | 背景 | 边框 | 字色 | 用途 |
|------|------|------|------|------|------|
| 主操作 | `.primary` | `--accent` | `--accent` | `#061018` | 开始答题、连续通关、只做错题 |
| 次要 | （默认） | `#243041` | `--line` | `--text` | 上一题、下一题 |
| 幽灵 | `.ghost` | `transparent` | `--line` | `--text` | 随机打乱、返回设置 |
| 禁用 | `:disabled` | 继承 | 继承 | 继承 | `opacity: 0.45`；`cursor: not-allowed` |

**悬停：** 非 primary 按钮 `border-color: var(--accent)`；primary 可略加深 accent（`#3490e0`）  
**第一屏 CTA 顺序：** `[开始答题]` → `[连续通关 · 当前筛选全部]` → `[随机打乱]`；前两项均为 primary，第三项 ghost

### 3.3 表单控件

`select`、`input[type="number"]`：

- 宽 100%（在 `.row` 格内）
- 底 `#121820`，边 `--line`，圆角 `10px`，内边距 `10px 12px`
- `label`：`0.82rem`，`--muted`，块级，`margin-bottom: 6px`

**筛选行 `.row`：**

- 桌面 4 列：`1.2fr 1fr 1fr 0.9fr`
- ≤800px：2 列 · ≤520px：1 列

### 3.4 进度条 `.progress`

```css
height: 8px;
background: #121820;
border-radius: 99px;
overflow: hidden;
margin: 10px 0 4px;
```

**填充 `<i>`：**

```css
height: 100%;
width: 0; /* JS 动态：(idx+1)/total */
background: linear-gradient(90deg, #2f7fd4, #3ecf8e);
transition: width 0.25s ease;
```

不显示百分比数字在条内；百分比由 `#qIndex` / 统计区承担。

### 3.5 选项 `.opt`

| 态 | 边框 | 背景 |
|----|------|------|
| 默认 | `--line` | `#121820` |
| 悬停 | `#4a5d73` | `#121820` |
| 已选 | `--accent` | `#173049` |
| 正确 | `--ok` | `#143028` |
| 错误 | `--bad` | `#2a1719` |

- 块级按钮，`width: 100%`，左对齐，`padding: 12px 14px`
- 选项间距 `margin-bottom: 8px`
- 字母前缀 `A.` `B.` 等与正文同一行，不单独着色

### 3.6 徽章 `.badge`

```css
display: inline-block;
font-size: 0.75rem;
padding: 2px 8px;
border-radius: 999px;
background: #243041;
color: var(--muted);
margin-right: 6px;
margin-bottom: 4px;
```

**深度 / 真题：** 追加 `.badge.deep` → 字色 `--warn`，边 `1px solid color-mix(in srgb, var(--warn) 40%, transparent)`

**知识点发布状态 pill：**

| 状态 | 样式 |
|------|------|
| 已发布 | 字色 `--accent`；边 accent 40% mix |
| 筹备中 | 默认 badge；字色 `--muted` |

### 3.7 反馈区 `.feedback`

- 默认 `display: none`
- 展示：`.feedback.show`
- 正确：`.feedback.ok` → 边 `color-mix(in srgb, var(--ok) 50%, var(--line))`
- 错误：`.feedback.bad` → 边 `color-mix(in srgb, var(--bad) 50%, var(--line))`
- 内边距 `12px`；底 `#121820`

### 3.8 提示条 `.hint`

- 虚线边 `1px dashed var(--line)`
- 底 `#121820`，字色 `--muted`，`0.85rem`
- 内强调 `<b>` 用 `--text`
- 用于：真题说明、合规声明（关于页上半部可复用并加左边框 `--warn`）

### 3.9 统计格 `.stat`

四宫格 `.stats`：`grid-template-columns: repeat(4, 1fr)`；≤520px 为 2 列  
每格：底 `#121820`，边 `--line`，圆角 `10px`，居中；数值 `b` 为 `1.2rem`

### 3.10 工具类

- `.hidden` → `display: none !important`（三态视图切换）
- `.sub` → 副标题，`--muted`，`0.9rem`

## 4. 页面级差异

### 4.1 刷题页

- **第一屏：** 标题 + 一行题量摘要（`#metaLine`）+ 设置卡片；**禁止**首屏四宫格统计、学习日历、排行榜
- **三态切换：** `#setup` / `#quiz` / `#result` 互斥显示；切换无整页刷新
- **meta 行：** `#qIndex` 左、`#scoreLive` 右；`0.85rem`，`--muted`

### 4.2 知识点页

- 章列表行：整行可点，悬停 `border-color: #4a5d73`（与 `.opt` 悬停一致）
- 正文：h2/h3 用 `--text`；链接 `--accent`，悬停下划线
- 代码块：底 `#121820`，边 `--line`，圆角 `10px`，横向可滚动
- 表格：边 `--line`，表头底 `#243041`

### 4.3 关于页

- 分节各一 `.card`
- **合规声明**置于页面上半部：`.hint` + 左边框 `3px solid var(--warn)`
- 版本信息用 `code` 或 muted 小字

## 5. 交互规范

### 5.1 动效

| 元素 | 动效 |
|------|------|
| 按钮 | `transition: 0.15s ease`（边框/背景） |
| 进度条 | 宽度 `0.25s ease` |
| 连续通关自动下一题 | 选题后 **650ms** 跳转（基线行为，保持不变） |
| 页面路由切换 | 无全屏过渡；内容区 instant swap |
| 顶栏 | sticky，无滚动隐藏 |

**禁止：** 大面积 parallax、弹跳 loading、渐变骨架屏闪白

### 5.2 键盘（刷题答题态）

| 按键 | 行为 |
|------|------|
| `←` | 上一题 |
| `→` | 下一题 / 完成 |
| `1`–`4` | 选 A–D |
| `A`–`D`（大小写） | 选题 |

设置区、知识点、关于页不抢占上述快捷键（仅答题态 `#quiz` 可见时生效）。

### 5.3 反馈与确认

| 场景 | 方式 |
|------|------|
| 筛选 0 题开刷 | `alert`「没有题目可刷」 |
| 无断点继续 | `alert`「没有可继续的进度」 |
| 连续模式点打乱 | `alert` 说明固定按序 |
| 手动保存进度 | `alert`「进度已保存…」 |
| 答题中切换顶栏 | 非阻塞 toast 或一行提示「进度已自动保存」（v1 可用 `console` + 轻提示，不用 modal 阻塞） |
| 知识点关联预览 | **侧滑抽屉 / 底 sheet**（见 §5.6）；可关、可整页打开；禁止全屏 modal 锁死导航 |

### 5.4 模式行为（视觉反馈）

| 模式 | 选题后 | 查看答案按钮 | 交卷按钮 |
|------|--------|--------------|----------|
| 连续通关 | 650ms 自动下一题；即时揭示 | 显示 | 末题显示 |
| 练习 | 即时揭示 + 反馈色 | 显示 | 隐藏 |
| 模拟 | 仅 selected 态，不揭示 | 隐藏 | 显示 |

### 5.5 持久化

- Key：`sysanalyst_quiz_v3`（刷题进度）
- Key：`sysanalyst_kb_last`（上次阅读章节，知识点页）
- 不上传网络；关于页声明 localStorage 用途

### 5.6 知识点关联抽屉（KbPreviewDrawer）

| 项 | 规范 |
|----|------|
| 触发 | 正文 `.kb-ref`（由 `` `*.md` `` 路径或可解析书名号生成） |
| 形态 | **Drawer**：≥640px 自右侧滑入；&lt;640px 自底部升起（sheet） |
| 层级 | `z-index` 高于 sticky 底栏，低于必要时的系统 alert |
| 遮罩 | `rgba(0,0,0,.45)`；点击关闭 |
| 动效 | 220ms ease；`prefers-reduced-motion` 时瞬时 |
| 内容 | 复用 `.md-body` 阅读样式；抽屉内标题栏固定，正文区滚动 |
| 操作 | 关闭 · 返回上篇（有栈时）· 整页打开 |
| 与 §8 | **允许**非阻断抽屉；**禁止**答题态全屏 modal |

### 5.7 知识点快速索引悬浮栏（KbQuickIndex）

| 项 | 规范 |
|----|------|
| 形态 | 右下角 FAB + 展开面板；**非**全宽侧栏（窄屏不挤占正文） |
| 位置 | `fixed`；`bottom: tabbar + safe-b`；桌面可略靠内容区右侧 |
| 色板 | `--panel` / `--line` / `--accent`；禁止紫白模板 |
| 层级 | `z-index` 低于 toast（90），高于正文；抽屉打开时仍可用 |
| 触控 | FAB / 列表项高度 ≥ 36–44px |
| 动效 | 展开无强制动画即可；`prefers-reduced-motion` 时滚动可用 `auto`（程序可选） |

## 6. 响应式

| 断点 | 调整 |
|------|------|
| ≤800px | 筛选 `.row` → 2 列 |
| ≤520px | 筛选 1 列；`.stats` 2 列；顶栏标题缩短 |
| ≥960px | 知识点可选 TOC 侧栏 sticky |

## 7. 无障碍（v1 基线）

- 语义：顶栏用 `<nav>`，主内容 `<main>`，页脚 `<footer>`
- 焦点：交互元素可见 focus ring（accent 40% mix）
- 对比：主文字 `#e7eef6` on `#0f1419` 满足 WCAG AA
- 图标：v1 以文字 Tab 为主，不依赖纯图标按钮
- 减少动效：尊重 `prefers-reduced-motion: reduce` 时禁用自动下一题延迟（可选 v1.1）

---

## 8. 禁止事项

| 禁止 | 原因 |
|------|------|
| 白底 / 浅灰卡片模板 | 破坏现有深色刷题体验 |
| 高饱和紫罗兰主色 | 常见 AI 模板感；主色锁定 `--accent` 蓝 |
| 首屏仪表盘（图表、日历、排行） | 违背「第一屏聚焦开始刷题」 |
| 答题态全屏 modal 阻断导航 | 进度已本地保存，不应 trapping |
| 知识点关联用全屏 modal 锁死顶栏 | 改用 §5.6 侧滑抽屉 / 底 sheet |
| 未发布知识点当正式内容样式展示 | 发布门禁；仅「筹备中」pill |
