## 全局壳层（Layout Shell）

根布局 `src/app/layout.tsx` 包裹全站：

| 区域 | 组件 / 类 | 行为 |
|------|-----------|------|
| 字体 | IBM Plex Sans（`--font-plex`） | 数字等宽 `tabular-nums` |
| 主题 | `ThemeProvider`（next-themes） | 默认深色；`<html>` 内联脚本防 FOUC |
| 顶栏 | `SiteHeader` | sticky；品牌 + AuthButton + ThemeToggle + GlobalSearch + 5 项导航 |
| 底栏（移动） | `SiteHeader` 内 bottom nav | `< sm` 固定 5 Tab；主内容 `--tabbar-h` 留白 |
| 主内容 | `.site-main` | 最大宽 `--content-max`；各页 `page-title` / `page-lead` |
| 页脚 | layout footer | `sm+` 显示一行部署说明 |
| 版本提示 | `UpdateNotice` | 读 `release-notes.json`；新版本 `Dialog` 一次 |
| Toast | `.kb-toast` | 知识点页轻提示，`position: fixed`，无需 Portal |

**常用 shadcn/ui 组件：** `Button`、`Card`（含 `CardHeader` / `CardContent`）、`Dialog`、`Sheet`、`Tabs`、`Badge`、`Input`、`Label`、`Switch`、`DropdownMenu`、`ScrollArea`、`Separator`。

## 1. 刷题页 `/`

**组件：** `QuizApp`（`src/app/page.tsx`）  
**目标：** 10 秒内开始答题；支持多源筛选、三种模式、断点恢复、关联知识点预览。

### 1.1 三态视图

同一页内 React 状态 `phase: setup | quiz | result`：

```text
setup ──开始/断点──► quiz ──结束──► result
  ▲                    │                │
  └──── 返回设置 ◄─────┴────────────────┘
```

| 态 | 布局 | 要点 |
|----|------|------|
| setup | `layout-split`：侧栏筛选 Card + 主区「开始本轮」Card | 显示当前筛选题量；IndexedDB 进度提示 |
| quiz | 单 Card：进度条、徽章、题干、选项、反馈、sticky 操作栏 | 可开 `KbPreviewDrawer`（Sheet 或固钉侧栏） |
| result | 四格统计 + 只做错题 / 再来 / 断点 / 返回设置 | — |

### 1.2 设置区（setup）

侧栏 `Card` 内 `<select>` / `<input>` 筛选：

| 筛选项 | 状态 | 说明 |
|--------|------|------|
| 路径 | `path` | 情景模拟 / 前端友好 / ROI 等；真题库时部分路径无效 |
| 题库 | `bank` | 自编 / 工坊 / 真题 / 论文自测 / 全部 |
| 场次 | `yearHalf` | 仅 `bank=real` 可用 |
| 章节 | `chapter` | 自编章节；对齐 `CH_NAMES` |
| 难度 | `diff` | basic / medium / deep / real |
| 模式 | `mode` | 连续通关 / 练习（即时答案）/ 模拟（交卷后） |
| 题量 | `limit` | 0 = 全部 |

主区 `Button`：**开始答题**（default）、**从断点继续**（outline）、**随机**（ghost toggle）。

数据：`fetch` `/data/questions.json`、`question-meta.json`、`paper.json`、`kb-search-index.json`。

### 1.3 答题区（quiz）

| 区块 | 实现 | 说明 |
|------|------|------|
| 进度 | 文字 `i/n` + 渐变条 | — |
| 徽章 | `.badge` | 章 / 考点 / 难度 / 题源 |
| 题干 | `RichText` | 支持换行、基础富文本 |
| 选项 | `.opt-btn` × A–D | 态：chosen / ok / bad |
| 反馈 | 条件渲染 Card 内区块 | 正确 / 错误 + 逐选项解析或 `exp` |
| 操作栏 | `Button` 组 sticky | 上一题 / 下一题或结束 / 看答案 / **知识点** / 保存 / 设置 |

**模式差异：**

| 模式 | 看答案 | 选题后 |
|------|--------|--------|
| 连续通关 | 可用 | 可自动推进 |
| 练习 | 可用 | 即时揭示 |
| 模拟 | 交卷前不揭示 | 交卷后统一 |

**关联知识点：** `findRelatedKbForQuestion` → `KbPreviewDrawer`；支持栈式预览、**固钉**（`pinned` → 右侧 `kb-dock-layout`）、相关条目 chips。

### 1.4 结果区（result）

2×2 / 4 列统计格：题量、正确、正确率、已答。操作：只做错题、再来一轮、断点继续、返回设置。

### 1.5 空态与异常

| 场景 | 展示 |
|------|------|
| 数据加载中 | setup 区 loading 态 |
| 筛选 0 题 | 开始时报错 / 提示；题量显示 0 |
| 无断点 | 「从断点继续」无效或提示无进度 |
| 无关联 KB | 知识点按钮仍可点，抽屉 emptyHint |

## 2. 案例页 `/case/`

**组件：** `CaseApp`  
**目标：** 案例练习与真题卷模拟；三问文本草稿；七步法教程；不做自动判分。

### 2.1 三态视图

`phase: setup | list | quiz`

```text
setup ──列出练习 / 点模拟包──► list ──选套题──► quiz
  ▲                                              │
  └──────── 返回概览 ◄───────────────────────────┘
```

| 态 | 内容 |
|----|------|
| setup | 侧栏筛选 Card；主区「模拟包 / 真题卷」列表 + 「自由练习」说明 |
| list | 当前 pool 套题列表；pack 提示（如五选三必答） |
| quiz | 题干 + **作答 / 七步法** Tab + 三问 `textarea` + 参考要点 |

### 2.2 设置区筛选

| 筛选项 | 说明 |
|--------|------|
| 题库 | 全部 / 自编 / 真题 |
| 场次 | 真题年份·上下半年 |
| 路径 | P0 主攻 / P1 / P2 / 止损域 / 全部 |
| 领域 / 题型 | 动态选项 |
| 题量 | 0 = 全部 |

操作：**列出练习**、**清空草稿**（confirm → 删 IndexedDB）。

### 2.3 答题区（quiz）

| Tab | 内容 |
|-----|------|
| 作答 | 三问 `textarea`；草稿自动 / 手动保存；「显示参考要点」toggle |
| 七步法 | `current.seven_steps` 逐步标题 + 说明；无数据时 Tab disabled |

徽章：真题/练习、领域、题型、路径、章节。同样支持 `KbPreviewDrawer` + 固钉。

数据：`cases.json`、`case-packs.json`；草稿 key `sysanalyst_case_v1`。

### 2.4 空态

| 场景 | 展示 |
|------|------|
| 无模拟包 | 仅显示自由练习说明 |
| 筛选 0 套 | 列表为空 |
| 无七步法 | Tab 禁用，title 提示 |
| 清空草稿 | confirm 后本地 drafts 归零 |

## 3. 知识点 `/kb/` 与 `/kb/[id]/`

### 3.1 目录页 `KbCatalog`

**目标：** 按篇章节浏览正式精炼；类型 / 篇筛选。

| 区块 | 组件 | 说明 |
|------|------|------|
| 标题 | `page-title` + `page-lead` | 版本号；引导 ⌘K 搜索 |
| 侧栏 | `Card` | kind（章节 / 速查 / 附录…）、篇筛选 |
| 列表 | 分组 `Card` + `Link → /kb/[id]/` | 标题、路径、note；按 section 折叠 |

数据：`/data/kb-index.json`。

**空态：** 加载中文案；`fetch` 失败显示错误色提示。

### 3.2 正文页 `KbReader`

**目标：** Markdown 阅读；文内关联预览；快速索引；跳转刷题。

| 区块 | 组件 | 说明 |
|------|------|------|
| 文头 | `article.kb-reader` | 标题、status badge、path、note |
| 正文 | `.md-body` | `renderKbMarkdown`；Mermaid 异步渲染 |
| 文内链接 | `data-kb-id` / `data-kb-path` | 点击 → 预览栈，不整页跳转 |
| 预览 | `KbPreviewDrawer` | 默认 `Sheet`（底/侧）；**固钉**时右侧 dock，不遮顶栏 |
| FAB | `.kb-nav-fab` | 「本章刷题」→ `/?chapter=&bank=practice`；「返回目录」 |
| 索引 | `KbQuickIndex` | 右下角 FAB；解析 h1–h3；滚动高亮当前节 |

SSG：`generateStaticParams` 从 `kb-index.json` 生成全部 `[id]`。

**空态：**

| 场景 | 展示 |
|------|------|
| 未找到 id | 「未找到该知识点条目」 |
| 目录入口项 | 「该项为目录入口，请选择具体章节阅读。」 |
| 正文加载失败 | HTTP 错误信息 |
| 关联无法解析 | toast「未找到对应知识点」 |

## 6. 全局能力

### 6.1 GlobalSearch

- 触发：顶栏按钮或 `Ctrl+K` / `⌘K`
- UI：`Dialog` + `Input`
- 结果：站点快捷导航（5 页）+ 知识点 hits（标题 / 小节 / 正文 snippet）
- 数据源：`kb-search-index.json`

### 6.2 AuthButton

- 未配置 Supabase：不渲染
- 已配置：`Dialog` 内 `Tabs`（密码登录 / 注册 / Magic Link）
- 登录后：`Switch` 云同步；立即同步按钮；LWW 冲突说明

### 6.3 UpdateNotice

- 比较 `release-notes.json` latest 与 `localStorage` `sysanalyst_release_seen`
- 新版本：`Dialog` 列 highlights；「查看全部」→ `/changelog/`；「知道了」写入 seen

### 6.4 KbPreviewDrawer

共用刷题 / 案例 / 知识点正文：

| 模式 | 表现 |
|------|------|
| 浮层 | `Sheet`；Esc / 遮罩关闭 |
| 固钉 | `pinned` + `kb-dock-layout.is-docked`；Pin / PinOff 切换 |
| 栈 | 文内再点关联 → push；ChevronLeft 出栈 |
| 整页 | `Link` → `/kb/[id]/` |
