## 全局壳层（Layout Shell）

所有页面共用：

| 区域 | 组件 | 行为 |
|------|------|------|
| 顶栏 | Logo 标题 + 导航 Tab ×3 | 固定顶部；`position: sticky; top: 0`；背景 `--panel` + 底边 `--line` |
| 主内容 | `.wrap` 容器 | `max-width: 820px`（刷题/关于）；知识点正文页可扩至 `960px` |
| 页脚 | 快捷键 + 服务地址 + 题量摘要 | 刷题答题态显示快捷键；其他页可折叠为单行 |

## 1. 刷题页

**路由：** `#/`（默认首页）  
**目标：** 让用户在 10 秒内开始答题；支持筛选、三种模式、连续通关与本地进度。

### 1.1 三态视图

同一 URL 下 JS 切换（与基线一致），避免整页刷新丢状态：

```text
┌─ 设置区 #setup ─────────────────────────┐
│ 筛选行：题库 | 年份 | 章节 | 难度        │
│ 模式行：模式 | 题量                      │
│ [开始答题] [连续通关·当前筛选全部]        │
│ [随机打乱]                               │
│ 池信息 + 提示条                          │
└─────────────────────────────────────────┘
        │ 开始
        ▼
┌─ 答题区 #quiz ──────────────────────────┐
│ 题序 / 得分          进度条              │
│ 徽章：章节 · 考点 · 难度                 │
│ 题干                                     │
│ 选项 A–D                                 │
│ 反馈区                                   │
│ [上一题][下一题][查看答案][交卷]...       │
└─────────────────────────────────────────┘
        │ 完成 / 交卷
        ▼
┌─ 结果区 #result ────────────────────────┐
│ 本轮结果 · 四格统计                      │
│ [只做错题][从断点继续][再来一轮]...      │
│ 错题列表                                 │
└─────────────────────────────────────────┘
```

### 1.2 设置区组件

| 组件 | ID / 类 | 说明 |
|------|---------|------|
| 题库筛选 | `#bankFilter` | 工坊 / 真题 / 全部 / 仅自编 |
| 年份筛选 | `#yearFilter` | 仅真题有效；含「高频错题」等专项 |
| 章节筛选 | `#chapter` | 仅自编练习；章名对齐 `CH_NAMES` |
| 难度筛选 | `#diffFilter` | 基础 / 中等 / 深度 / 真题 |
| 模式 | `#mode` | 连续通关 / 练习（即时答案）/ 模拟（交卷后） |
| 题量 | `#limit` | 0 = 全部；连续通关模式强制 0 |
| 主 CTA | `#startBtn` | **Primary**，文案「开始答题」 |
| 快捷 CTA | `#marathonBtn` | **Primary**，一键连续通关当前筛选 |
| 辅助 | `#shuffleBtn` | Ghost；连续模式禁用 |
| 池信息 | `#poolInfo` | 「当前可选：N 题（真题 x · 基础 y · 深度 z）」 |
| 提示 | `.hint` | 真题来源、案例论文索引、进度说明 |

**第一屏布局原则：**

- 设置卡片在首屏完整可见；主按钮位于首屏下半部，无需滚动（桌面 768px+）
- 题量摘要（`#metaLine`）置于标题下，一行即可，不做四宫格统计
- 不展示历史正确率曲线、排行榜、学习日历

### 1.3 答题区组件

| 组件 | 说明 |
|------|------|
| `#qIndex` | `第 i / n 题（题号 xxx）` |
| `#scoreLive` | 练习/通关：已答 + 正确；模拟：仅已答 |
| `#bar` | 进度条，宽度 = `(idx+1)/total` |
| 徽章 | `#chBadge` `#pointBadge` `#diffBadge`；深度/真题用 `.badge.deep` |
| `#stem` | 题干，行高 1.65 |
| `.opt` ×4 | 选项按钮；态：default / selected / correct / wrong |
| `#feedback` | 解析区；`.show` + `.ok` / `.bad` |
| 操作栏 | 上一题 / 下一题 / 查看答案 / 交卷 / 保存进度 / 返回设置 |

**模式差异：**

| 模式 | 查看答案 | 交卷 | 选题后 |
|------|----------|------|--------|
| 连续通关 | 显示 | 末题显示 | 650ms 自动下一题 |
| 练习 | 显示 | 隐藏 | 即时揭示 |
| 模拟 | 隐藏 | 显示 | 不揭示，交卷后统一 |

### 1.4 结果区组件

| 组件 | 说明 |
|------|------|
| `.stats` 四格 | 正确、正确率、已答、错/空 |
| `#retryWrong` | Primary，只做错题 |
| `#continueRemain` | 有 localStorage 进度时可用 |
| `#retryAll` | 清空进度再来 |
| `#wrongList` | 错题回顾列表 |

### 1.5 空态与异常

| 场景 | 展示 |
|------|------|
| 未加载 `questions.js` | 池信息：「未加载 questions.js，请用本地服务打开本页。」禁用开始按钮 |
| 筛选后 0 题 | 点击开始时 `alert`；池信息显示 0；hint 建议放宽筛选 |
| 无断点进度 | 「从断点继续」disabled 或点击提示「没有可继续的进度」 |
| 进度失效 | 提示重新开刷并 `clearPersist` |
| 连续模式点打乱 | alert 说明固定按序 |

### 1.6 键盘

答题态：← → 切题；1–4 / A–D 选题（与基线一致）。

## 2. 知识点页

**路由：** `#/kb`（目录）、 `#/kb/:chapter`（正文）  
**目标：** 只读阅读，章节目录对齐综合知识 00–22 章；支持从章节跳转刷题。

### 2.1 目录视图

```text
┌─ 知识点 ────────────────────────────────┐
│ 副标题：对照大纲的系统分析师知识精炼     │
│ ┌ 章列表 ─────────────────────────────┐ │
│ │ 第00章 · 综合与法规杂项        →   │ │
│ │ 第01章 · 绪论                  →   │ │
│ │ ...                                 │ │
│ └─────────────────────────────────────┘ │
│ [在本章刷题]（选中章后显示，链到刷题预填）│
└─────────────────────────────────────────┘
```

| 组件 | 说明 |
|------|------|
| 页标题 | `知识点` |
| 章列表 | 23 行（00–22）；每行：章号、章名、发布状态 pill |
| 状态 pill | `已发布`（accent 边）/ `筹备中`（muted） |
| 侧栏（≥960px 可选） | 当前章锚点目录，sticky |

### 2.2 正文视图

| 组件 | 说明 |
|------|------|
| 面包屑 | 知识点 / 第 NN 章 · 章名 |
| 正文 | Markdown → HTML；代码块、表格、对比表保留 |
| 页内 TOC | h2/h3 锚点（长章） |
| **快速索引悬浮栏** | 右下角 FAB「索引」；展开本页 h1–h3；跟随 `.md-body` 滚动高亮 |
| 底栏操作 | 「返回目录」「在本章刷题」 |

**阅读样式：** 正文字号略大于刷题题干（`1rem` body，`1.05rem` 段落），行宽 `65ch`，减少视觉疲劳。

### 2.3 空态与门禁

| 场景 | 展示 |
|------|------|
| 全站未发布 | 目录可见；每章「筹备中」；正文页替换为说明卡片 + 返回目录 |
| 单章未发布 | 该章正文不可进入，或进入后显示「该章尚未通过审计发布」 |
| 无 kb 数据文件 | 「内容筹备中，请稍后再来」+ 链到关于页数据来源 |
| 加载失败 | 重试按钮 + 控制台错误提示（开发态） |

**程序门禁：** 仅挂载 `知识点工坊/审计委员会/正式发布/` 内已有文件的章节为「已发布」。

### 2.4 与刷题联动

「在本章刷题」跳转 `#/?chapter=12&bank=practice`，刷题设置区预填并 `updatePoolInfo`。

### 2.5 知识点关联预览（抽屉）

**目标：** 正文里引用另一篇知识点（如 `` `速查/UML-….md` ``、《需求工程-体系化学习路径》）时，**不离开当前阅读页**，用侧滑抽屉预览关联篇。

```text
┌─ 当前正文 ──────────────┬─ 关联预览抽屉 ─────┐
│ …见 `速查/UML….md`      │ [关闭] 标题          │
│ （可点的 kb-ref 链接）   │ 正式 · path          │
│                         │ ─────────────        │
│                         │ Markdown 正文滚动    │
│                         │ [整页打开] [返回上篇]│
└─────────────────────────┴─────────────────────┘
```

| 组件 | 说明 |
|------|------|
| `.kb-ref` | 正文内可点关联；accent 色，下划线 |
| `KbPreviewDrawer` | 桌面右侧抽屉宽 ≈ `min(520px, 92vw)`；窄屏底部 sheet 高 ≈ `85vh` |
| 遮罩 | 半透明，点击关闭；**不**全屏阻断顶栏路由 |
| 栈 | 抽屉内再点关联 → 压栈；「返回上篇」出栈 |
| 整页打开 | `Link` → `/kb/{id}/`，关闭抽屉 |

**空态：** 无法解析路径时 toast/行内提示「未找到对应知识点」，不打开空抽屉。

**禁止：** 用全屏 modal 盖住顶栏导航（对齐视觉规范 §8）。

### 2.6 快速索引悬浮栏（KbQuickIndex）

**目标：** 长篇知识点正文内，一点即可跳到章节标题，无需在 `.md-body` 里反复手滑找节。

```text
                              ┌─ 本页索引 ─[关闭]─┐
                              │ §1 …               │
                              │   §1.1 …           │
                              │   §1.2 …（当前）   │
                              └────────────────────┘
                                         [ 索引 · N ]
```

| 项 | 说明 |
|----|------|
| 触发 | 右下角固定 FAB（避让底栏 `--tabbar-h` / safe-area） |
| 数据源 | 渲染后的 `.md-body` 内 `h1–h3[id]`（与 hash / 搜索 slug 一致） |
| 标题 &lt; 2 | 不展示 FAB |
| 点击项 | 在正文容器内平滑滚动；`history.replaceState` 写 `#id`；面板收起 |
| 高亮 | 随 `.md-body` scrollTop 更新当前节 |
| 关闭 | 再点 FAB、「关闭」、点外部、Esc |

## 3. 关于页

**路由：** `#/about`  
**目标：** 说明站点用途、启动方式、数据来源与合规声明。

### 3.1 内容区块

```text
┌─ 关于 ──────────────────────────────────┐
│ § 站点说明                               │
│   本地个人学习用刷题站点，无需登录。      │
│ § 如何启动                               │
│   ./启动.sh 或 python -m http.server     │
│ § 数据来源                               │
│   · 自编练习 / 真题 / 工坊 及 merge 说明  │
│   · 知识点发布状态                        │
│   · 案例论文见 真题/00-真题索引.md        │
│ § 隐私                                   │
│   进度仅存本机 localStorage               │
│ § 合规声明（醒目）                        │
│   个人学习使用；真题及解析请勿对外传播。  │
│ § 版本                                   │
│   题库 meta 版本、站点 v1                 │
└─────────────────────────────────────────┘
```

| 组件 | 说明 |
|------|------|
| `.card` 分节 | 每节一个 card，与刷题页视觉一致 |
| 合规声明 | `.hint` 或左边框 `warn` 色强调，置于页面上半部 |
| 版本信息 | 读 `meta.json` / `QUESTION_META` 动态填充 |

### 3.2 空态

| 场景 | 展示 |
|------|------|
| meta 不可用 | 静态 fallback 文案，版本显示「未知」 |
