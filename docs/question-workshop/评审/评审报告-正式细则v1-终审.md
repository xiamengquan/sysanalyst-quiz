### 2.5 主要改善（相对初审）

1. 模板题干与模板解析 **清零**（§9.5、§9.6）。

1. **2 题重复**（§9.10）：同一章、同一 `point`、同一正确项文本「状态模式」，答题体验重复。

## 4. 对旧题库的系统性建议

1. **现网策略**：512 题可继续使用；**no 350、363 建议临时从答题页剔除**（或仅展示其一直至重写完成），避免重复考点。
2. **闭合最后一环**：完成 2 题打回后全库可达 **100% 机审通过**，满足 §10.4「机审硬规则清零」流程终点。
3. **结构增补（非紧急）**：按 §10.3 分批新增——联动组（§4.3）、计算型（目标 ~30%）、否定型（~10%）；不必大改现有 512 题。
4. **难度重平衡**：后续新题增加 `medium` 占比，逐步将 `deep` 从 58.8% 压向 §6 的 20%–25%（通过新题增量而非回改全库）。
5. **去重机制**：入库前脚本校验 `(chapter, point, options[answer])` 唯一性，防止 §9.10 复发。

## 5. 对出题者下一批的约束补丁

1. **重复零容忍**：同章同 `point` 且正确项文本相同 → 直接驳回（§9.10）；换情景但答案字面相同亦视为重复。
2. **联动轨启动**：下一批 60 题中联动题位 ≥24（40%），每联动组须通过 §4.3 抽查（删一空后其余空仍依赖背景）。
3. **计算/否定配额**：新批计算型 ≥18、否定型 ≥6（§10.3），弥补全库结构欠账。
4. **medium 层补位**：新题 `medium` 占比 ≥40%，避免「basic/deep 两极化」。
5. **沿用已达标项**：模板题干 ≤30%、解析 ≥35 字、禁 §5.3 干扰项——**维持现状，不得回退**。
