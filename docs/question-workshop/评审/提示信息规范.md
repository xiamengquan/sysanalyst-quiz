# 提示信息规范（提示信息官）

> 配套角色：提示信息官（Skill：`sysanalyst-hint-officer`）  
> 与细则关系：遵守正式细则 §7 / R02/R03；本规范补充**简洁 · 合理 · 通俗**的可读性标准。

## 1. 展示场景

答题页对同一段 `explain`/`exp`：

| 场景 | 页头 | 解析应帮考生 |
|------|------|----------------|
| 答对 | 「正确」 | 确认理解，可一带主要易混点 |
| 答错 | 「错误 · 你的…正确…」 | 说明正解理由 + 点出常见混淆 |

## 2. 推荐写法（一句公式）

```text
【正解要点】一句话说明为何对。
【易错点】A/C 等主要干扰错在哪（1 句即可）。
```

可写成连续短句，不必强制两个小标题。

## 3. 门槛

| 项 | 要求 |
|----|------|
| 下限 | ≥35 字（细则硬阈值） |
| 建议上限 | 约 120 字；超额须有计算步骤或必要对比才保留 |
| 禁止 | 「正确项阐述了…」「考点：XXX。」空壳；只写「选 B」 |
| 禁止 | 与答案矛盾、抄题干复读、未解释的缩写堆砌 |

## 4. 结论档

- **通过** / **润色后通过** / **打回**（见提示信息官 Skill）

## 5. 口令

- 「提示信息官质检批次 A/B」
- 「检查练习题对错提示是否通俗」
- 「润色 all.jsonl 解析文案」
