## 1. 执行摘要（给你本人的一页纸）

1. **你的优势域**：Web（第16章）、移动（第18章）、微服务/BFF/集成（第20章 + EAI/SOA）。与日常前端工作高度同构。  
2. **必答题不是送分也不是天坑**：近年试题一稳定考**需求获取方法、用例/DFD、问题分析/FAST** 等「方法+对比+限字」——前端也能得分，靠的是**背对比维 + 回扣题干**，不是写代码。  
3. **选答默认路径**：在二～五题中优先选 **Web / 移动 / 微服务·集成**；大数据仅作保底；嵌入式/CPS **能认题型即可**，非硬实时调度题尽量避开。  
4. **2025 下回忆卷侧面印证**：试题一 = 需求获取五法对比；试题二 = 电商大促缓存/击穿/穿透 —— 正是前端主场。  
5. **得分公式**：题型对了（对比表 / 填空 / 限字简答 / 改进）+ 每问 ≥2 个题干约束词 + 权衡句（「虽更先进，但题干要求…」）。  
6. **8 周底线**：每周 1 套完整案例限时 + 3 张对比表默写 + 1 次 200 字压缩练；累计约 20+ 题手写。  
7. **练习入口**：站内案例页按域筛 **Web / 移动 / 微服务 / 集成**；弱域只读解析。  
8. **论文热点可借力不可照搬**：近五年论文测试/DevOps 热，案例里常变成「性能改进/安全/验收」子问——用你的压测、灰度、契约测经验，但必须贴题干。

## 2. 五选三：选卷决策（考场 ≤60 秒）

```
开卷 → 扫五题标题+首问
  ├─ 试题一（必答）：识别题型（对比/填空/简答）→ 不挑题，只排时间（约 25–30 分钟）
  └─ 试题二～五：打标签
        🟢 熟域：Web / 移动 / 微服务·集成，且首问是对比表或限字简答
        🟡 可啃：大数据（架构对比/一致性），无重计算
        🔴 止损：嵌入式硬实时调度 / CPS 工控闭环 / 纯数仓重 ETL
规则：
  1. 优先两道 🟢；仅一道 🟢 则配一道 🟡
  2. 题型尽量错开（一对比 + 一设计）
  3. 若多道 🔴：选「填空/填表」多的弱域题（标准词踩分）
  4. 30 秒定案，不反复改选
```

## 3. 复习重点地图（按优先级）

### 3.1 P0 · 必答底座（约 40% 时间）

| 主题 | 教材锚点 | 你怎么学 |
|------|----------|----------|
| 需求获取方法对比 | 第11章、教程案例节 | 访谈/JRP/问卷/文档/观察：广度·深度·参与度·集成度 |
| 业务/用户/系统需求 | 第11章 | 三类定义 + 各举题干式例子（勿写空话） |
| 用例 / DFD / 因果·FAST | 第10—11章 | 补图填空风格题；先看已有格再填 |
| 方案对比万能维 | 答题教程 §3.A | 耦合、扩展、成本、遗留友好、风险、一致性 |

### 3.2 P0 · 选答主攻（约 45% 时间）

| 域 | 章 | 前端可迁移素材 |
|----|----|----------------|
| **Web** | 16 | 前后端分离、BFF、缓存/CDN、会话、大促限流、安全鉴权、Web 测试 |
| **移动** | 18 | 原生/混合/小程序、MVC/MVVM、审核与热更新、多端统一规则 |
| **微服务·集成** | 20 + 6.8/12 | 网关、注册发现、熔断、契约测；SOA/ESB vs 点对点；防腐层对接 ERP |

### 3.3 P1 · 保底（约 10%）

| 域 | 目标 |
|----|------|
| 大数据（19） | Lambda vs Kappa、批流、读写分离——**只记对比卡** |
| 安全/测试/运维交叉 | 鉴权、分层测、灰度——作为子问「措施×3」素材 |

### 3.4 P2 · 止损（约 5%）

| 域 | 目标 |
|----|------|
| 嵌入式（17） | 硬/软实时、优先级反转、看门狗——**信号→对策表** |
| CPS（21） | 感知-决策-执行、MQTT/Modbus 等填空词 |

## 5. 建议常备的 10 张速查卡

1. SOA/ESB vs 点对点集成  
2. 单体 vs 微服务  
3. 强一致 vs 最终一致  
4. 直连 vs API 网关/BFF  
5. 缓存 / CDN / 读写分离  
6. 原生 vs 混合 vs 小程序  
7. MVC vs MVVM vs 前后端分离  
8. 同步 vs 异步消息  
9. Lambda vs Kappa（保底）  
10. 实时调度 / 优先级反转（止损）  

另备 1 张：**五种需求获取方法 × 四维对比**（直击近年试题一）。

## 6. 站内题库怎么用

- 路径：站点「案例」页，按域筛选。  
- **P0**：Web、移动、微服务、集成 —— 各练 8–10 套手写。  
- **P1**：大数据、安全、测试、数据库 —— 各 2–3 套。  
- **P2**：嵌入式、CPS —— 各读 2 套解析即可。  
- 练法：先看问题再读案例 → 25 分钟/题 → 标「题干句 ↔ 采分点」。
