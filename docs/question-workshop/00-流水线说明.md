# 出题工坊 · 流水线说明（含细则审计委员会）

## 角色总览

| 阶段 | 角色 | 产出 |
|------|------|------|
| 起草 | 分析师（起草） | `reports/出题细则报告.md`（草稿） |
| **审计** | **委员会甲∥乙∥丙** | `委员会/意见/分析师*.md` |
| **发布** | **主席** | 仅全员通过 → `委员会/正式发布/` |
| 改造题库 | 出题者 | 按**正式细则**调整/重写 |
| 质检 | 评审员 | 按**正式细则**审计命题合规；不合规打回重编 |
| **提示** | **提示信息官** | 检查每道习题的**正确与错误提示**是否简洁、合理、通俗易懂 |

Skill：`sysanalyst-committee-{a,b,c,chair}` + `sysanalyst-{analyst,setter,reviewer,hint-officer}`

## 硬门禁

```text
正式细则未发布  ≠⇒  全库合规打回（禁止）
正式细则已发布  ⇒  出题者改造 → 评审员审计 → 提示信息官文案质检 → 打回/润色循环
```

**全员通过** = 甲、乙、丙表决均为「通过」（有条件通过/驳回均不可发布）。

## 目录

- `委员会/00-委员会章程.md`
- `委员会/细则结构模板.md` — 正式稿分级结构
- `委员会/意见/` — 三人意见与修订任务单
- `委员会/正式发布/` — 盖章生效稿
- `agents/提示信息官.md` / `评审/提示信息规范.md` — 对错提示文案标准
