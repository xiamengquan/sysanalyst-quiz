## 2. 分级结构专项审计

### 2.1 「总则 → 依据 → 规范 → 清单 → 配额 → 附录」分层

| 层级 | 现状 | 问题 |
|------|------|------|
| 总则 | 无 | 执行摘要（第 1 节）属归纳性内容，不能替代 1.1–1.3 的规范入口 |
| 依据 | 第 2–3 节 | 第 3 节混入规范边界（3.4 案例/论文可考表），应拆至第 3 章 |
| 规范 | 第 4–6 节 | 上午/案例/论文未分章，双轨风格（长卷/机考）仅散见摘要与 §4.2 |
| 清单 | 第 7–8 节 | 合格 |
| 配额 | 第 10 节 | 缺 10.4 旧库改造；难度配比占用错误编号 |
| 附录 | A/B | 与模板功能错位 |

**结论**：六层逻辑**部分成立**（5–9 节较清晰），但**前段（0–4）与后段（10、附录）未按模板分层**，整体不能评为「良好分级」。

### 2.2 § 编号可引用性

- 现有编号为「第 N 节 / N.M」，**未采用模板约定的 §x.y 引用惯例**，且章节序号与模板语义不一致（如「第 3 节」在模板中应为科目分层，在当前稿中为考点分布）。
- 评审 Checklist 引用「第 4–6 节」「第 10 节」——在**结构重组前**，出题者/评审员跨角色引用易产生**指代漂移**。
- 建议：正式发布稿统一改为模板章节号，文内交叉引用一律写 `§4.2`、`§10.3` 等形式。

### 2.3 科目（上午/案例/论文）分层

- **未独立成第 3 章**；上午规范主要在 §4.1–4.4，案例在 §4.5，论文在 §4.6，边界表在 §3.4。
- 难度、题型比例、Checklist 均以「上午 JSONL 60 题批次」为主轴，**案例/论文缺少对等的硬性 Checklist 或科目级配额**（仅模板级描述）。
- 不符合模板「3.1 / 3.2 / 3.3 分章而非混写」要求。

### 2.4 Checklist 与禁止事项

- **第 7、8 节**：独立、可勾选、条目可判定 — **合格**。
- **第 9 节**：10 条集中，与第 7 节「避免模板化」、第 8 节「机考适配」等**无直接矛盾** — **合格**。
- 轻微结构问题：第 8 节「细则符合：对照本报告第 4–6 节」在重组后须同步改引用号（不阻塞，但应列入改稿任务）。

### 2.5 扁平 1–10 是否达「良好分级结构」

**结论：否。**

理由简述：

1. **缺 3 个模板强制一级章**（0、1、3）及 **2 个强制附录功能**（机审对照、修订历史）。
2. **10.4 编号语义错误**，旧库改造（all.jsonl 514 题如何处理）在正文中仅有差异对照（§2.2），**无保留/重写/降级策略**，与章程「生效后出题者按正式细则调整题库」的流水线衔接不足。
3. **证据章与规范章边界模糊**（第 3 节整章偏统计，却含命题边界表），不符合模板「第 2 章只描述样本事实、不写必须」的分级原则。
4. 虽有 10 个主节，但**节名与模板不对齐**，不能视为「结构等价于模板的扁平变体」。
