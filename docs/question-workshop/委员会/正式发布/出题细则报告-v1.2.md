## 1. 总则

### 1.1 目的与适用范围

本细则规定系统分析师个人备考题库的**命题风格、硬性质量门槛与批次配额**，使出题者与评审员使用同一套可引用条款（`§x.y`）。

适用范围：

- **适用**：自编/工坊上午选择题；案例与论文练习的结构指引  
- **不适用**：代替官方大纲；不构成对真题原文的复制授权  

### 1.2 角色与引用关系

| 角色 | 引用本细则方式 |
|------|----------------|
| 出题者 | 出题时勾选 §7；考点对齐 §3.0、§10.4；改造旧库遵循 §10.4 |
| 评审员 | 审计时勾选 §8；驳回须引用 § 编号 |
| 委员会 | 修订本细则；未正式发布前不得启动全库打回 |

**命题依据层级**（v1.1 新增，硬性引用顺序）：

| 层级 | 文档 | 用途 |
|------|------|------|
| 1 | 本细则（正式发布版） | 风格、阈值、配额、Checklist |
| 2 | `知识点工坊/审计委员会/正式发布/` 知识点精炼 v1.0+ | **考点定义、对比表、应试钩子、章节归属** |
| 3 | `00-使用说明与知识地图.md` | 三篇 22 章结构与科目映射 |
| 4 | `速查/高频对比速查表.md`、`速查/近五年论文范围分析.md` | 对比题与论文主题速查 |
| 5 | `真题/上午真题.jsonl` 等 | **真题规律统计**（§2.2）；不得用自编题替代 |

> 自编题（含 `综合知识/all.jsonl`、工坊新题）可用于对照改造效果，**不得计入「真题占比」或真题规律结论**（§2.3）。

### 1.3 术语与符号

| 术语 | 定义 |
|------|------|
| `basic` / `medium` / `deep` | 难度，见 §6 |
| `（N）` 空 | 题干中填空编号，多空联动见 §4.3 |
| 机考短题 | 题干 ≤50 字且可独立作答 |
| 模板题干 | 匹配「关于…下列说法正确的是」或等价句式 |
| 正式卷 | year∈{2018…2023} 的上午解析题（n=431） |
| 记录级统计 | 以 jsonl **每一空/每一行**为一条（联动段会重复背景） |
| 知识点精炼 | 审计委员会正式发布的三篇 22 章正文 + 速查（v1.0+） |
| 考点标签 `point` | JSONL 字段，须能在对应章精炼中找到同名或上下位节标题（§10.4） |

## 4. 题型与题干规范

### 4.1 双轨风格（硬性：批次须双轨都出现）

| 轨道 | 特征 | 批次下限 |
|------|------|----------|
| A 长卷联动 | 共享背景 + `（N）` 多空 | 建议 ≥30% 题位来自联动组 |
| B 机考短题 | 题干 ≤50 字、独立可解 | **≥20%**（与 §8、§10.3 统一） |

### 4.2 题干模板（指导性，占位符）

- 技术背景串联、业务情景串联、直接设问、双空短联动、进度/决策计算等（沿用 v0.1 占位思路，正式引用时写「§4.2 模板类X」）  
- 对比/辨析类优先对照 `速查/高频对比速查表.md` 条目命题  
- **禁止**把指导性模板当唯一正确答案来源  

### 4.3 多空联动规则（硬性）

1. 同一背景段 ≥2 空时，考点须逻辑关联（非硬凑）  
2. 评审抽查：删去其中一空，其余空仍应依赖背景信息；若完全互不需要背景 → 不合格  
3. JSONL 可将每空拆成一行，但须在 `point` 或 `source` 标注同组

## 5. 选项与干扰项规范

### 5.1 基本格式（硬性）

- 固定 A–D 四选项；答案唯一  
- 选项同质（同为协议名/阶段名/图类型等）  
- **建议** ≤20 字；**硬性**：一般 >50 字驳回（法规原文题除外）  

### 5.2 干扰项手法（指导性）

相邻概念、正话反说、张冠李戴、绝对化措辞、计算干扰。

**范式/BCNF 类**（对齐第 5 章 + 速查 §23）：干扰项不得使用已废止的错误定义（如 BCNF「消除主属性对码的依赖」）；应使用相邻范式级差或「决定因素是否为候选码」类正话反说。

### 5.3 禁止的干扰项（硬性）

- 两选项语义等价  
- 明显荒谬、与题干无关  
- 「与XX无关 / 以上说法均不正确」等万金油项  
- **与知识点精炼正文矛盾的定义性干扰**（评审员对照第 5 章范式、速查 §23 等核实）

## 6. 难度分级标准

| 级别 | 占比建议 | 特征 |
|------|----------|------|
| basic | 35%–40% | 单考点、定义/归属；可短题干 |
| medium | 40%–45% | 对比、轻情景、一步计算 |
| deep | 20%–25% | 多步计算、跨章、否定、依赖长背景 |

深题若无情景/计算/对比，应降级或改写（硬性）。

## 7. 出题 Checklist（硬性）

出题者每题勾选：

1. 原创（非真题照搬；非仅改前缀）  
2. 字段完整：`stem/options/answer/explain/point/chapter/difficulty`  
3. 答案唯一；**解析 ≥35 字**且说明主要错项原因  
4. 禁止模板解析套话（「正确项阐述了规范含义」）  
5. `chapter` 与 §3.0 知识地图一致；难度符合 §6  
6. **`point` 可在对应章精炼中找到对应节/对比项/应试钩子**（§10.4）  
7. 选项同质；无 §5.3 禁项  
8. 否定题干须明确「错误/不属于」对象  
9. 批次级：模板题干占比 **≤30%**；机考短题 **≥20%**；章节/题型见 §10（容差 ±20%）

## 8. 评审 Checklist（硬性）

1. 对照 §4–§6、§9  
2. 批次配额相对 §10 偏差 **≤20%**（**分维度**计算，禁止用多标签加总>100% 豁免）  
3. 考点正确、计算可验算、无双答案；**对照知识点精炼 v1.0+ 核实**  
4. 干扰项「错得有道理」；范式/BCNF 等须符合第 5 章与速查 §23  
5. 与真题高相似 → 驳回（人工或工具；能判定则驳）  
6. 同 `point`+同设问结构重复 → 驳回或合并  
7. **`point` 无法在精炼章定位 → 驳回或要求改标签**（§10.4）  
8. 联动质量抽查（§4.3）  
9. 机考短题占比 ≥20%  
10. 解析 ≥35 字且可教  
11. 驳回须写 `§` 编号 + 重写要求  

---

## 9. 禁止事项（硬性）

1. 照搬真题原文整题/整段选项  
2. 伪新题（只改单位名/数字）  
3. 超纲到具体厂商私有 API/IDE 操作细节（真题已涉及除外）  
4. 大段粘贴受版权保护的真题到聊天/报告  
5. **模板题干占比 >30% 的批次一律退回**（与 §7 对齐；废止旧「>50%」口径）  
6. 空解析或解析 <35 字；模板解析套话  
7. 双答案争议题强行单选  
8. 批次只有长卷或只有短题（缺双轨）  
9. 把自编统计写入「真题占比」  
10. 同章同 point 无新题型仍重复堆砌  
11. **使用与知识点精炼正式稿矛盾的概念作为正确项或高迷惑干扰**（如错误 BCNF 定义）

### 10.4 旧库改造策略（硬性流程）

针对 `综合知识/all.jsonl`：

| 动作 | 条件 | 处理 |
|------|------|------|
| 保留 | 已满足 §7 且无 §9 违反；**且 `point` 已在精炼章可定位** | 保留 `no` |
| 重写替换 | 模板题干/坏干扰/深题无情景/解析<35；**或 `point` 无法对齐精炼** | 出题者按原 `no/chapter` 替换，**重写 `point` 对齐精炼节名** |
| 降级 | 深题实为定义题 | 改 `difficulty` 或改写升级 |
| 删除 | 超纲、双答案无法修补、重复无价值 | 评审员列 id，出题者确认后删除 |

**考点标签对齐规则**（v1.1 新增，硬性）：

1. 新题与重写题的 `point` 须能在 `chapter` 对应精炼章中找到：**节标题**、**对比表主题**或**应试钩子**中的同一考点或明确上下位（如 `point`=「BCNF范式」↔ 第 5 章范式段/速查 §23）  
2. 跨章 deep 题：`chapter` 取主题章，`point` 仍须在该章或速查中有锚点；联动组各空 `point` 分别对齐  
3. 评审员抽检：随机 10% 题目在精炼章内 `Ctrl+F` 定位；无法定位 → 按 §8 驳回  
4. 对比类题优先使用速查表已有主题作 `point`（如「架构风格对比」「测试方法对比」）  

流程：正式细则发布 → 知识点精炼 v1.0 对齐改造 → 出题者改造 → 评审员按 §8 审计 → 不合规打回重编 → 直至机审硬规则清零且标签对齐达标。
