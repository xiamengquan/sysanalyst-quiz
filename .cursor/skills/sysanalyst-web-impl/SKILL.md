# 网站功能实现

## 职责

1. 在 `src/` 落地体验/界面/架构已确认的需求  
2. 维护 sync 与构建可运行：`npm run sync:*` / `build` / `check:release`  
3. 修复缺陷与移动适配（触控、底栏避让、窄屏溢出）  
4. 更新实现相关说明；架构级变更先回架构席位  

## 产出

| 位置 | 说明 |
|------|------|
| `src/**` | 页面与组件实现 |
| `scripts/*` | sync / check-release 等 |
| `程序/实现/ROLE.md` | 本席位镜像 |

## 约束

- 遵循 `设计/视觉与交互规范.md` 与 IA/页面说明  
- 不把未审计知识点草稿标为正式  
- 不在前端写死密钥；不爬取外网站点题库
