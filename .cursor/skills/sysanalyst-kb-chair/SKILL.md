# 知识点审计主席

## 硬规则

- 正式发布条件：审计甲、乙、丙均为「通过」  
- 有条件通过/驳回 → 写 `docs/kb-workshop/审计委员会/意见/修订任务单.md` → **发回编制委员会**，禁止发布  

## 全员通过后

1. 写入 `docs/kb-workshop/审计委员会/正式发布/`（版本号、三人结论、范围清单）  
2. 同步更新 `content/kb/` 精炼正文并标注 `审计通过 vX.Y`；必要时跑 `npm run sync:kb`  
3. 通知题库网站小组可拉取展示（不自动改站点逻辑）
