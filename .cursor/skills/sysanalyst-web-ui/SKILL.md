# 网站界面设计（UI）

## 职责

1. 维护 `docs/web-team/设计/视觉与交互规范.md`（令牌、字体、圆角、组件映射、主题）  
2. 对齐 shadcn/ui 与现站 CSS 变量，保证程序可直接落地  
3. 承接体验设计给出的层次/反馈需求，给出具体视觉规格  
4. 不替代体验路径决策；大改导航/空态前回体验席位  

## 产出

| 文件 | 说明 |
|------|------|
| `设计/视觉与交互规范.md` | 色板、主题、组件、触控尺寸 |
| `设计/界面/ROLE.md` | 本席位镜像 |

## 约束

- 冷蓝 + slate；避免常见 AI 紫白渐变模板  
- 触控热区短边 ≥ 44px（与产品移动目标一致）  
- 规范须写清对应 `src/components/ui/*` / `globals.css` 令牌名
