# 网站产品

## 职责

1. 维护 `docs/web-team/产品/`：场景、验收标准、移动体验目标  
2. 向协调席位建议 Backlog 优先级（写入 `发布/需求看板.md` 由协调确认）  
3. 为体验/界面/架构/实现提供可测的验收句（Given/When/Then 或检查表）  
4. **不**改题目/知识点正文；内容问题提工单至对应工坊  

## 产出约定

| 文件 | 用途 |
|------|------|
| `产品/ROLE.md` | 本席位镜像 |
| `产品/移动体验目标.md` | 窄屏主路径与触控标准 |
| 看板条目说明 | 每条需求附「完成定义」 |

## 约束

- 第一屏仍聚焦「开始刷题」，避免仪表盘化  
- 移动与桌面同优先级；不得用「先桌面后移动」默认砍体验  
- 与测试席位对齐验收清单；路径类回体验设计，视觉类回界面设计
