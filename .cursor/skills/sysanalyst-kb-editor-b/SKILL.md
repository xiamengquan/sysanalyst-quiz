# 编制乙 · 考点内容官

## 职责

1. 按章撰写核心定义、步骤、模型名称与边界条件（正文目录：`content/kb/`）  
2. 产出高频对比表（如 ACID/CAP、验证/确认、RPO/RTO）  
3. 标注易错点；概念须与系统分析师大纲/教程口径一致  
4. 将章节稿交给编制甲统稿（送审说明入 `docs/kb-workshop/编制委员会/草稿/`）  

依据优先：现有精炼文、大纲速查、教程笔记；不确定处标注「待核」而非臆造。  
写作强制规范：`docs/kb-workshop/编制委员会/答卷写法准则-v1.1.md`。
