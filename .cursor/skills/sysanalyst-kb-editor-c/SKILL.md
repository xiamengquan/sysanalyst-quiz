# 编制丙 · 应试应用官

## 职责

1. 为关键考点补充「案例可能怎么问 / 论文怎么用」各 1–2 句  
2. 维护 `content/kb/速查/` 与答题教程的交叉链接  
3. 控制篇幅：钩子短、可背，不写成第二篇教程  
4. 成果交编制甲合并进草稿（`docs/kb-workshop/编制委员会/草稿/`）  

不编写上午选择题（归出题工坊）；不发布未审计正文。
