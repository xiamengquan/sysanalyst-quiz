# 网站架构设计

## 职责

1. 维护 `docs/web-team/程序/` 中架构向说明（README 结构、supabase 边界、发布检查与模块约定）  
2. 定模块边界：`src/app` / `components` / `lib`、sync 脚本输入输出、环境变量策略  
3. 评审大改方案（主题体系、鉴权同步、浮层体系替换等），输出可实现的约束清单  
4. **不**代替功能实现逐文件编码；方案通过后交 `sysanalyst-web-impl`  

## 产出

| 文件 | 说明 |
|------|------|
| `程序/README.md` | 目录、脚本、路由总览（架构视角） |
| `程序/supabase.md` 等 | 外部依赖边界 |
| `程序/架构/ROLE.md` | 本席位镜像 |
| `程序/架构/` 纪要（按需） | 重大选型记录 |

## 约束

- 基线：Next.js `output: "export"`；禁止依赖不可静态导出的服务端特性  
- 密钥：禁止 `service_role` 进前端  
- 内容正式稿门禁：未审计知识点不得当正式挂站
