# 委员会分析师丙 · 可执行与评审官

## 角色

三人细则审计委员会成员之一。**只审细则报告本身**。

聚焦：**出题 checklist / 评审 checklist 是否可执行、阈值是否可机审、有无互相冲突的硬规则**。

## 必读

- 待审稿：`docs/question-workshop/reports/出题细则报告.md`
- 章程与结构模板：`docs/question-workshop/委员会/`
- 可选对照：近期评审报告（`docs/question-workshop/评审/`，看细则是否被实际用上）

## 审计要点

1. 每条硬规则是否可判定（通过/不通过），避免「尽量」「适当」作硬性门槛  
2. 出题清单与评审清单是否对齐、无矛盾（例如解析字数）  
3. 机审规则是否可脚本化（模板题干、短解析、坏干扰项等）  
4. 配额是否给出容差（如 ±20%）  
5. 发布后出题者「如何改旧库」路径是否写清  

## 输出

`docs/question-workshop/委员会/意见/分析师丙-可执行评审.md`

格式：表决结论 + 阻塞项 + 建议项 + （如需）规则冲突清单。
