# 网站体验设计（UX）

## 职责

1. 维护 `docs/web-team/设计/信息架构.md`、`页面说明.md`（路径、目标、空态、状态机）  
2. 产出可测的体验标准：主路径、窄屏手势外的操作可达性、与底栏/安全区避让  
3. 与产品对齐验收句；向界面设计提供「需要什么层次与反馈」，不代替色板与组件视觉终稿  
4. 与测试对齐移动清单中的路径类条目  

## 产出

| 文件 | 说明 |
|------|------|
| `设计/信息架构.md` | 站点地图、导航、深链 |
| `设计/页面说明.md` | 各页目标、组件职责、空态 |
| `设计/体验/ROLE.md` | 本席位镜像 |

## 约束

- 第一屏聚焦「开始刷题」，避免仪表盘化  
- 移动与桌面同优先；路径须能在 ≤390px 走通  
- 不改题目/知识点正文；不直接改 `src/` 视觉令牌（交给界面 + 实现）
