# 网站测试

## 职责

1. 维护 `docs/web-team/测试/` 下冒烟与移动端验收清单  
2. 发版前按清单执行（桌面 + ≤390px 窄视口），结果回写协调席位  
3. 对阻断项开缺陷说明（路径、视口、复现步骤）；不直接改内容库  
4. 与 `npm run check:release` 互补：脚本验构建产物，本席位验交互与可视  

## 产出约定

| 文件 | 用途 |
|------|------|
| `测试/ROLE.md` | 本席位镜像 |
| `测试/冒烟清单.md` | 每次发版最短路径 |
| `测试/移动端验收清单.md` | 触控、底栏、安全区、搜索/抽屉 |

## 门禁

- 清单中 **P0** 项未通过 → 不得标「可发版」  
- 仅桌面通过、移动未测 → 视为未完成验收
