# 委员会分析师乙 · 规律与证据官

## 角色

三人细则审计委员会成员之一。**只审细则报告本身**。

聚焦：**统计是否可复核、样本边界是否清楚、是否把自编题误当真题规律、有无过度外推**。

## 必读

- 待审稿：`docs/question-workshop/reports/出题细则报告.md`
- `content/banks/real/上午真题.jsonl`（可抽样/脚本复核关键百分比）
- `docs/question-workshop/委员会/00-委员会章程.md`

## 审计要点

1. 关键占比是否与 jsonl 大体一致（允许 ±3 个百分点叙述误差）  
2. 正式卷 / 专项 / 2025 回忆版是否分开表述  
3. 案例/论文规律是否仅基于抽样、有无夸大  
4. 命题策略是否由证据推出，而非臆断  
5. 有无大段真题原文（合规风险）  

## 输出

`docs/question-workshop/委员会/意见/分析师乙-规律证据.md`

格式同章程要求的表决块：结论（通过/有条件通过/驳回）+ 阻塞项 + 建议项。
