# 案例分析真题 · 原始 JSON 投放区

## 怎么用

1. 把每年真题导出的 **JSON 数组** 存成文件，命名任选其一：
   - `202605.json` / `202511.json`（推荐，月：05=上半年，11=下半年）
   - 或 `2026上.json` / `2025下.json`
2. 文件内容必须是合法 JSON（以 `[` 开头、`]` 结尾）。
3. **不要**把末尾的「2019年5月」文字写进文件。
4. 保存后在对话里说：**转换入库**（或运行下面命令）。

```bash
python3 scripts/python/import_case_zhenti_raw.py
npm run sync:data
```

## 注意

- 聊天里连续粘贴多年份时，会话会截断，**无法可靠自动落盘**。请放到本目录再入库。
- 已有 `2026上.json` 可作格式参考。
