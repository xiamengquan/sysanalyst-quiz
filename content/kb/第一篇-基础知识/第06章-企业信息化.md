## 核心知识点/概念

### 企业信息化概述

- **内涵**：信息技术应用、信息资源开发、信息人才建设。
- **目标**：提高竞争力、优化流程、辅助决策。

### 信息资源管理(IRM)

- **内容**：规划、组织、控制、技术、经济。
- **信息资源规划(IRP)**：梳理业务流程→建立信息体系→建立数据库体系。
- **标准**：数据元素标准、信息分类编码标准、用户视图标准。

### 信息化规划

**与战略规划关系**：信息化战略服从/支撑企业战略；BITA(业务与IT整合)、EITA(企业IT架构)。

**信息系统战略规划方法**：

| 方法 | 特点 |
|------|------|
| **BSP** | 企业系统规划，U/C矩阵，由业务到IS |
| **CSF** | 关键成功因素，识别CSF→确定IS需求 |
| **SST** | 战略集转化，将组织战略转为IS战略 |

**ERP**：

- **定义**：建立在IT基础上，以系统化管理思想提供决策和运营手段的管理平台。
- **三个角度**：管理思想(MRP II扩展)、软件产品(模块化→集成化)、管理系统(六大功能目标)。
- **主要模块**：生产、财务、供应链、人力资源、销售等。
- **实施阶段**：前期准备→试运行→交付收尾。
- **开发模式**：套装二次开发 / 定制开发。

**CRM**：

- 以客户为中心，客户关怀；功能：销售/营销/服务自动化 + 分析。
- 组成：触发中心 + 挖掘中心；须与ERP集成。

**SCM**：

- 集成管理思想；内容：**计划、采购、制造、配送、退货**。
- 关键：需求预测、库存优化、供应商协同。

**PDM/PLM**：

- **PDM**：产品数据管理，管理研发过程数据。
- **PLM**：产品生命周期管理，覆盖概念→报废全过程。

**KM(知识管理)**：知识获取、存储、共享、应用。

**BI(商业智能)**：

- 四阶段：数据预处理→数据仓库→数据分析→数据展现。
- 三大组件：**数据仓库 + OLAP + 数据挖掘**。

**企业门户(EIP)**：信息聚合、个性化、单点访问。

**DSS(决策支持系统)**：模型库+知识库+数据库，辅助半结构化决策。

### 电子商务

| 类型 | 说明 |
|------|------|
| B2B | 企业对企业 |
| B2C | 企业对消费者 |
| C2C | 消费者对消费者 |
| B2G/C2G | 对政府 |
| O2O | 线上到线下 |

- **特征**：全球性、虚拟性、交互性、低成本、高效性。
- **标准**：EDI、ebXML、RosettaNet。
- **技术**：Web、EDI、支付、安全(加密/认证/CA)。

### 电子政务

| 模式 | 说明 |
|------|------|
| G2G | 政府间 |
| G2B | 政府对企 |
| G2C | 政府对民 |
| G2E | 政府对雇员 |

### 业务流程重组(BPR)

- **定义**：对企业业务流程根本性再思考、彻底性再设计，以实现成本/质量/服务/速度改善。
- **原则**：以流程为中心、以客户为导向、IT使能。
- **与BPI区别**：BPR=根本性/彻底性；BPI=渐进式改进。

### 企业应用集成(EAI)

| 层次 | 内容 |
|------|------|
| 数据集成 | 共享/复制数据 |
| 应用集成 | API/中间件 |
| 界面集成 | 门户聚合 |
| 过程集成 | 工作流/BPM |

- **事件驱动EAI**：基于消息/事件的松耦合集成。

## 易混对比

| 对比项 | BSP | CSF | SST |
|--------|-----|-----|-----|
| 出发点 | 业务过程 | 关键成功因素 | 组织战略 |
| 工具 | U/C矩阵 | CSF分析 | 战略映射 |
| 特点 | 系统性 | 重点突出 | 战略导向 |

| 对比项 | ERP | CRM | SCM |
|--------|-----|-----|-----|
| 核心 | 内部资源集成 | 客户关系 | 供应链 |
| 目标 | 资源优化 | 客户价值 | 供需协同 |
| 范围 | 企业全局 | 前端客户 | 上下游 |

| 对比项 | PDM | PLM |
|--------|-----|-----|
| 范围 | 产品数据 | 全生命周期 |
| 重点 | 研发数据管理 | 概念到报废 |

| 对比项 | BPR | BPI |
|--------|-----|-----|
| 变革程度 | 根本性/彻底性 | 渐进式 |
| 风险 | 高 | 低 |
| 适用 | 流程严重落后 | 局部优化 |

| 对比项 | BI | DSS |
|--------|-----|-----|
| 数据 | 历史海量 | 模型+数据 |
| 功能 | 分析展现 | 辅助决策 |
| 用户 | 管理层 | 决策者 |

| 对比项 | BITA | EITA |
|--------|------|------|
| 侧重 | 业务与IT对齐 | 企业IT架构 |
| 适用 | IS不能满足业务 | 架构规划 |

## 常考数字/结论/口诀

- SCM五环节：**计采制配退**。
- BI三组件：**仓库+OLAP+挖掘**。
- ERP实施三阶段：**准备→试运行→交付**。
- 电商类型：**B2B/B2C/C2C/B2G/O2O**。
- 政务模式：**G2G/G2B/G2C/G2E**。
