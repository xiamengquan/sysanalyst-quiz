## 本章考什么

安全体系与等级保护、**加密/认证/密钥管理**、防火墙/VPN/SSL/IPSec/SSO、**访问控制模型(DAC/MAC/RBAC/BLP/Biba)**、**容灾(RPO/RTO)**、**可靠性(MTTF/MTBF/可用性)**、**冗余与容错(N版本/恢复块/防卫式)**。综合案例与选择题均高频。

## 核心知识点/概念

### 信息系统安全体系

**安全威胁三类**：稳定性/可靠性破坏、设备管理问题、信息保密完整性风险。

**安全层次**：

| 层次 | 内容 |
|------|------|
| 实体安全 | 物理环境 |
| 运行安全 | 系统运行管理 |
| 信息安全 | 数据与通信 |
| 人员安全 | 管理培训 |

**技术层次**：物理层→OS→网络→应用→安全管理。

**TCSEC/等保五级**：

| 级别 | 名称 |
|------|------|
| 1 | 用户自主保护级 |
| 2 | 系统审计保护级 |
| 3 | 安全标记保护级 |
| 4 | 结构化保护级 |
| 5 | 访问验证保护级 |

**安全策略**：统一身份认证、统一安全管理、安全保密体系、网络边界防护。

### 数据安全与保密

**加密 vs 认证**：

| 对比项 | 加密 | 认证 |
|--------|------|------|
| 目的 | 保密性 | 真实性、完整性 |
| 防攻击 | 被动(截获) | 主动(冒充/篡改/重放) |

**加密算法**：

| 类型 | 特点 | 代表 |
|------|------|------|
| 对称(私钥) | 加解密同钥，快 | DES、IDEA、AES |
| 非对称(公钥) | 公钥加密私钥解，慢 | RSA(512+位) |
| 传统 | 代换+置换 | 简单，已淘汰 |
| Hash | 单向，不可逆 | MD5、SHA |

**数字签名**：基于非对称加密；功能=鉴别+不可否认+完整性。

**数字证书**：CA签发，X.509标准；含用户信息、公钥、有效期、CA签名。

**身份认证方式**：

| 方式 | 特点 |
|------|------|
| 口令 | 最常用，**极不安全** |
| 动态口令 | 一次一密，令牌 |
| 生物特征 | 指纹/虹膜/人脸 |

**密钥管理**：

| 方式 | 说明 |
|------|------|
| 点对点 | 对称/非对称 |
| KDC | 密钥分发中心 |
| PKI | 公钥基础设施，CA+证书 |

**数字信封**：对称密钥加密数据，公钥加密对称密钥。

### 通信与网络安全

**防火墙**：

| 模式 | 结构 |
|------|------|
| 双宿/多宿 | 双网卡，路由禁用 |
| 屏蔽主机 | 堡垒机+内部主机 |
| 屏蔽子网 | DMZ+内外网隔离(最安全) |

- 功能：访问控制、内容控制、日志审计。
- 局限：防不了内部攻击、不经过防火墙的攻击、病毒。

**VPN关键技术**：隧道、加解密、密钥管理、身份认证、访问控制。

**安全协议**：

| 协议 | 层次/用途 |
|------|----------|
| SSL/TLS | 传输层，HTTPS基础 |
| IPSec | 网络层，端对端，AH/ESP |
| PPTP/L2TP | 隧道协议 |
| HTTPS | HTTP+SSL |
| PGP | 邮件加密 |

**SSL握手6阶段**：接通→密码交换→会谈密码→检验→客户认证→结束。

**SSO(单点登录)**：一次认证，访问多系统；Kerberos基于KDC对称加密。

### 系统访问控制 ★必考

**三要素**：主体、客体、控制策略。

**五种策略**：登录访问控制、操作权限、目录安全、属性安全、服务器安全。

**访问控制模型**：

| 模型 | 关注点 | 规则 |
|------|--------|------|
| **BLP** | 保密性(MAC) | **上读下写**（不可读高、不可写低） |
| **Biba** | 完整性(MAC) | **下读上写**（与BLP相反） |
| **Lattice** | 保密(扩展BLP) | 安全集束内同上 |
| **DAC** | 自主 | 用户自主授权(ACL) |
| **MAC** | 强制 | 安全属性决定访问 |
| **RBAC** | 角色 | 用户→角色→权限 |
| **TBAC** | 任务 | 面向任务/工作流 |
| **OBAC** | 对象 | 控制规则基于对象属性 |

**RBAC模型演进**：RBAC0(基本)→RBAC1(层次)→RBAC2(约束)→RBAC3(层次+约束)。

**BLP详细**：

- 安全级别：公开、受限、秘密、机密、高密。
- **上读(no read up)**：不能读高于自身级别的数据。
- **下写(no write down)**：不能写低于自身级别的数据。

**Biba详细**：

- **下读(no read down)**：不能读低于自身级别的数据。
- **上写(no write up)**：不能写高于自身级别的数据。

### 容灾与业务持续 ★必考

**关键指标**：

| 指标 | 含义 |
|------|------|
| **RPO** | 恢复点目标，允许丢失的数据量/时间 |
| **RTO** | 恢复时间目标，允许中断的时间 |

**容灾分类**：

| 类型 | 关注点 | 级别 |
|------|--------|------|
| **数据容灾** | 数据不丢失 | 低(磁带)到高(实时复制) |
| **应用容灾** | 业务不中断 | 高(完整应用复制) |

**灾难恢复规划步骤**：风险分析→业务影响评估→确定恢复目标→方案设计→建设实施→演练维护。

**业务持续性规划(BCP)**：比容灾更广，含预防、响应、恢复、恢复后。

### 安全管理

- **安全审计**：记录安全事件，事后分析。
- **私有信息保护**：法律法规+技术(加密/访问控制/脱敏)。

### 系统可靠性 ★必考

**定义**：规定时间、规定条件下完成规定功能的能力。

**ISO 25010可靠性子特性**：成熟性、容错性、易恢复性、依从性。

**指标**：

| 指标 | 公式/含义 |
|------|----------|
| **MTTF** | 平均无故障时间，∫R(t)dt |
| **MTTR** | 平均故障修复时间，1/μ |
| **MTBF** | 平均故障间隔，≈MTTF+MTTR |
| **可用性** | MTTF/(MTTF+MTTR)×100% = MTTF/MTBF×100% |

**指数分布**：R(t)=e^(-λt)，MTTF=1/λ。

**可靠性模型**：时间模型、故障植入模型、数据模型。

**组合模型条件**：各部件独立、已知可靠度、仅两种状态(工作/失效)、串联/并联结构。

**系统结构**：

| 结构 | 可靠度 |
|------|--------|
| 串联 | R=R1×R2×…×Rn（任一部件失效则系统失效） |
| 并联 | R=1-(1-R1)(1-R2)…（冗余，一个工作即可） |
| 模冗余(2n+1) | 表决，容忍n个故障 |

### 冗余技术 ★必考

**避错 vs 容错**：避错=预防(评审/测试)；容错=冗余消除故障影响。

**冗余四类**：

| 类型 | 说明 |
|------|------|
| **结构冗余** | 硬件/软件冗余(静态/动态/混合) |
| **信息冗余** | 检错码/纠错码(奇偶/海明/CRC) |
| **时间冗余** | 重复执行，以时间换可靠性 |
| **冗余附加** | 实现冗余所需的资源 |

**结构冗余三种**：

| 类型 | 别名 | 方式 |
|------|------|------|
| 静态冗余 | 屏蔽/被动冗余 | 表决比较(三模冗余) |
| 动态冗余 | 主动冗余 | 检测→定位→恢复(备用切换) |
| 混合冗余 | — | 静态+动态，成本最高 |

### 软件容错技术 ★必考

| 方法 | 类型 | 策略 | 特点 |
|------|------|------|------|
| **N版本程序设计** | 静态/设计冗余 | **前向恢复** | N个独立版本同时运行，表决 |
| **恢复块方法** | 动态/设计冗余 | **后向恢复** | 主块失败→备用块，Roll-back |
| **防卫式程序设计** | 非传统容错 | — | 插入检查，小程序适用 |

- **N版本**：静态故障屏蔽，表决器选正确结果。
- **恢复块**：动态故障屏蔽，验证测试+备份切换。
- **防卫式**：不采用传统容错，灵活易实现。

## 易混对比

| 对比项 | BLP(保密) | Biba(完整) |
|--------|----------|-----------|
| 读 | 上读(不读高) | 下读(不读低) |
| 写 | 下写(不写低) | 上写(不写高) |
| 目标 | 防泄密 | 防篡改 |

| 对比项 | DAC | MAC | RBAC |
|--------|-----|-----|------|
| 控制 | 自主授权 | 强制策略 | 角色映射 |
| 灵活性 | 高 | 低 | 中 |
| 适用 | 通用OS | 军事/高安全 | 企业大型系统 |

| 对比项 | 对称加密 | 非对称加密 |
|--------|---------|-----------|
| 密钥 | 同一密钥 | 公钥+私钥 |
| 速度 | 快 | 慢 |
| 用途 | 大量数据 | 密钥交换/签名 |
| 代表 | DES/AES | RSA |

| 对比项 | 加密 | 认证 | 授权 |
|--------|------|------|------|
| 目的 | 保密 | 验明身份 | 权限控制 |
| 防 | 窃听 | 冒充 | 越权 |

| 对比项 | 数据容灾 | 应用容灾 |
|--------|---------|---------|
| 关注 | 数据不丢 | 业务不停 |
| 成本 | 较低 | 较高 |
| 恢复 | 需重建应用 | 直接切换 |

| 对比项 | RPO | RTO |
|--------|-----|-----|
| 关注 | 丢多少数据 | 停多久 |
| 单位 | 时间/数据量 | 时间 |

| 对比项 | 静态冗余 | 动态冗余 | 混合冗余 |
|--------|---------|---------|---------|
| 别名 | 屏蔽/被动 | 主动 | — |
| 方式 | 表决 | 切换备用 | 两者结合 |
| 成本 | 中 | 中 | 高 |

| 对比项 | N版本 | 恢复块 | 防卫式 |
|--------|-------|--------|--------|
| 冗余类型 | 静态/设计 | 动态/设计 | 无传统冗余 |
| 恢复 | 前向(表决) | 后向(回退) | 检查纠正 |
| 开销 | 大(N份程序) | 中(备份块) | 小 |

| 对比项 | 串联系统 | 并联系统 |
|--------|---------|---------|
| 可靠度 | 乘积(降低) | 1-∏(1-Ri)(提高) |
| 含义 | 都工作才工作 | 一个工作即可 |
| MTBF | 减小 | 增大 |

| 对比项 | MTTF | MTTR | MTBF |
|--------|------|------|------|
| 含义 | 无故障运行 | 修复时间 | 故障间隔 |
| 关系 | — | — | ≈MTTF+MTTR |

| 对比项 | 防火墙 | VPN | IDS |
|--------|--------|-----|-----|
| 功能 | 访问控制/隔离 | 加密隧道 | 入侵检测 |
| 层次 | 边界 | 网络 | 检测分析 |

| 对比项 | SSL | IPSec |
|--------|-----|-------|
| 层次 | 传输层 | 网络层 |
| 模式 | — | 传输/隧道 |
| 特点 | HTTPS | 端对端 |

## 常考数字/结论/口诀

- BLP：**上读下写**；Biba：**下读上写**（相反！）。
- 可用性 = **MTTF/MTBF × 100%**。
- 指数分布：**R(t)=e^(-λt)**，**MTTF=1/λ**。
- 串联：**R=∏Ri**；并联：**R=1-∏(1-Ri)**。
- 模冗余 **2n+1** 个模块，容忍 **n** 个故障。
- 等保 **5** 级：**自审标结验**。
- 口令认证**极不安全**；动态口令**一次一密**。
- N版本=**前向恢复/静态**；恢复块=**后向恢复/动态**。
- RPO看**数据**，RTO看**时间**。
- 冗余四类：**结信时附**（结构/信息/时间/附加）。

## 应试钩子

**案例可能怎么问**：按场景选访问控制模型（DAC/MAC/RBAC/BLP/Biba）；防火墙类型与部署位置；给定 RPO/RTO 要求设计备份与容灾等级；N 版本/恢复块/防卫式程序容错对比。

**论文怎么用**：DevSecOps/安全运维类可写「左移测试+流水线门禁+密钥/权限最小化」；可靠性段落用 MTBF/可用性公式、冗余策略与 RPO/RTO 目标对齐业务连续性。
