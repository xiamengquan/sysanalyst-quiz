2. **按 DDD 限界上下文**（统一语言、聚合根）

## 服务治理清单

| 能力 | 案例写法 |
|------|----------|
| 注册发现 | 实例上下线、健康检查 |
| API 网关 | 鉴权、路由、限流、协议转换 |
| 配置中心 | 动态配置、灰度 |
| 熔断/降级 | 依赖故障不拖垮全链路 |
| **Service Mesh** | 流量/安全/可观测下沉 Sidecar |

## 与单体/SOA 论证

对比表维度：**耦合、独立部署、数据一致、运维复杂度、团队自治**；结论回扣题干（工期/遗留/峰值）。
