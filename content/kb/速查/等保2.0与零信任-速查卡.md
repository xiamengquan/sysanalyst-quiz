# 速查 · 等保 2.0 与零信任

> **docType**：reference · 对齐第 9 章安全体系 + 近年综合知识热点  
> **关联**：`kp-网络安全-数据安全-系统安全` · [第09章 信息安全](../第一篇-基础知识/第09章-信息安全.md)

## 网络安全等级保护 2.0（要点）

| 项 | 内容 |
|----|------|
| **标准** | GB/T 22239-2019 等，**分保、域保、关保** 协同 |
| **定级** | 根据业务受损对社会、国家安全的影响 → 1～5 级 |
| **扩展要求** | 云计算、移动互联、物联网、工业控制 **扩展要求** |
| **测评** | 技术 + 管理；**符合性测评** 与 **风险评估** 区分 |
| **答卷句** | 按等级落实物理/网络/主机/应用/数据/管理制度与技术措施 |

## 零信任（Zero Trust）

| 项 | 内容 |
|----|------|
| **核心** | **从不默认信任，始终验证**；身份为中心，最小权限 |
| **与边界安全** | 传统边界防火墙 ≠ 零信任；内网流量也须认证授权 |
| **典型能力** | 强身份（MFA）、微隔离、持续评估、加密传输、设备健康 |
| **案例/论文** | 远程办公、多分支接入、微服务东西向流量 |

## 易混

- **等保** = 合规等级与测评框架；**零信任** = 架构与安全模型（可支撑等保技术措施）
- **RBAC** 是授权模型；零信任是 **整体策略**，可组合 RBAC/ABAC
