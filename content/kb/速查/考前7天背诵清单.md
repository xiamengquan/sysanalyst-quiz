## 第 7 天 · 软件过程与规划（T−7）

### 开发模型（对照 [§1 软件开发模型](./高频对比速查表.md#1-软件开发模型对比)）

| 模型 | 关键词 | 选型 |
|------|--------|------|
| **瀑布** | 顺序、文档、里程碑 | 需求明确、技术成熟 |
| **V 模型** | 开发与测试阶段对称 | 质量要求高 |
| **螺旋** | 风险驱动、原型+瀑布迭代 | 大型、高风险 |
| **喷泉** | OO、阶段界限模糊、迭代 | 面向对象项目 |
| **RAD** | 原型+构件、快 | 工期紧、需求较清晰 |
| **RUP** | 用例驱动、架构中心、迭代增量 | 中大型 |
| **敏捷/Scrum** | 拥抱变更、短迭代 | 需求不确定 |

**口诀**

- 需求稳 → **瀑布 / V**；风险大 → **螺旋**；要快 → **RAD / 敏捷**；OO → **喷泉 / RUP**。
- 螺旋每轮四步：**计风实评**（计划→风险分析→工程→客户评估）。
- RAD 五阶段：**业数过应测**（业务建模→数据建模→过程建模→应用生成→测试）。
- RUP 四阶段：**初细构移**（初始→细化→构建→移交）。
- CMMI 五级：**初可已定优**（初始→可重复→已定义→已管理→优化）。

### 规划方法（对照 [§2 规划方法](./高频对比速查表.md#2-信息系统规划方法对比)）

| 方法 | 出发点 | 记一句 |
|------|--------|--------|
| **BSP** | 业务过程 | U/C 矩阵、数据类 |
| **CSF** | 关键成功因素 | 目标→CSF→需求 |
| **SST** | 战略集合 | 战略→IS 战略 |
| **SDP** | 数据 | 主题数据库 |
| **VCA** | 价值链 | 找信息化切入点 |

**易混**：BSP 重**过程与数据**；CSF 重**管理层目标**；SST 重**战略转化**；SDP 重**数据架构**。

**练手**：综合知识第 7 章、第 10 章；关键词「RUP」「CMMI」「BSP」。

## 第 6 天 · UML 与面向对象（T−6）

> 深度：[UML 体系化学习指南](./UML-体系化学习指南.md) · 考点 API：`kp-面向对象技术`

### 坐标系

- **结构图** = 系统**长什么样**（类、组件、部署）。
- **行为图** = 系统**怎么动**（用例、序列、状态、活动）。
- **必考图顺序**：用例 → 类 → 序列/通信 → 状态 → 活动 → 组件/部署。

### 六种关系（答卷必背）

| 关系 | 线型 | 记法 |
|------|------|------|
| **依赖 Dependency** | 虚线开放箭头：客户端→供应者 | 供应者变更**可能**影响客户端；较弱 |
| **关联 Association** | 实线 | 实例**链接**；聚合/组合是特殊关联 |
| **泛化 Generalization** | 实线空心三角在**一般**端 | **is-a**；子类型可替父类型 |
| **实现 Realization** | 虚线空心三角在**规约**端 | 类兑现接口契约 |
| **聚合 Aggregation** | 实线**空心菱**在**整体** | 弱拥有；部分可独立、可共享 |
| **组合 Composition** | 实线**实心菱**在**整体** | 强拥有；部分生命周期绑整体 |

**口诀**

- **菱形永远贴整体**。
- 强度：依赖 &lt; 关联 &lt; 聚合 &lt; 组合（泛化/实现不参与菱形序）。

### 五图一句话

| 图 | 作用 |
|----|------|
| **用例图** | 参与者与用例，界定功能范围 |
| **类图** | 类及静态关系 |
| **序列图** | 按**时间**的消息交互 |
| **通信图**（协作图） | 按**对象链接**+消息序号 |
| **状态机图** | **单对象**状态迁移 |
| **活动图** | 流程、分支、**并行**、泳道 |

### 用例与 BCE

- **include**：基用例**必含**子用例（箭头 **基→被含**）。
- **extend**：**可选**扩展（箭头 **扩展→基**）。
- **BCE**：**边界**（对外交互）· **控制**（编排用例，不长期存业务数据）· **实体**（持久业务信息与规则）。

**练手**：第 7 章 UML；案例填空「选图种 / 填关系符号」。

## 第 5 天 · 需求与结构化（T−5）

> 深度：[需求工程学习路径](./需求工程-体系化学习路径.md) · [需求获取五法](./案例必答-需求获取五法对比卡.md)

### 三类需求（§23a）

| 层次 | 记法 |
|------|------|
| **业务需求** | 组织**为什么要做** |
| **用户需求** | 用户**要达成什么** |
| **系统需求** | 系统**必须做什么**（可验证、可测试） |

### 获取方法选型（§23d）

| 方法 | 何时选 |
|------|--------|
| **访谈 / 观察** | 要**深**、要澄清细节 |
| **问卷** | 要**广**、样本多 |
| **JRP / JAD 研讨会** | 要**快共识**、**消冲突** |
| **文档 / 采样** | 已有系统、现成材料 |

### DFD 四要素

**外部实体 · 加工 · 数据流 · 数据存储**（勿与 ER 图职责混淆）。

### 耦合与内聚（§25）

- **耦合**（越低越好）：数据 &lt; 标记 &lt; 控制 &lt; 外部 &lt; 公共 &lt; 内容。
- **内聚**（越高越好）：偶然 &lt; 逻辑 &lt; 时间 &lt; 过程 &lt; 通信 &lt; 顺序 &lt; **功能**。

**练手**：第 11 章；案例「需求获取选法」「DFD 填空」。

## 第 4 天 · 架构 · Web · 微服务（T−4）

> 对照：[§7 架构风格](./高频对比速查表.md#7-软件架构风格对比) · [§13 Web](./高频对比速查表.md#13-web-架构对比) · [§16 微服务](./高频对比速查表.md#16-微服务架构模式对比) · [REST 学习卡](./REST架构风格-体系化学习卡.md)

### 架构风格关键词

| 风格 | 记一句 |
|------|--------|
| **管道-过滤器** | 数据流经阶段处理 |
| **仓库（黑板）** | 共享数据、多消费者 |
| **C/S、B/S** | 胖客户端 vs 浏览器瘦客户端 |
| **4+1 视图** | 逻辑/开发/进程/物理 + **场景** tying |

### REST 与 HTTP

- **GET** 查 · **POST** 建 · **PUT** 全量更 · **DELETE** 删。
- **PUT / DELETE** 通常**幂等**；POST 创建一般**不幂等**。

### 微服务保护

| 机制 | 记一句 |
|------|--------|
| **限流** | 控**请求速率上限** |
| **熔断** | 失败率高时**短路**、快速失败；冷却后半开试探 |
| **灰度/金丝雀** | 小流量验证再全量，便于回滚 |

**易混**：限流管**量**；熔断管**依赖是否已坏**。

**练手**：第 12、16 章；案例 Web 峰值方案（缓存+限流+异步+灰度+幂等）。

## 第 2 天 · 存储 · 备份 · 安全 · 数据库（T−2）

> 对照：[§4 RAID](./高频对比速查表.md#4-raid-与存储对比) · [§5 备份](./高频对比速查表.md#5-备份类型对比) · [§6 访问控制](./高频对比速查表.md#6-访问控制对比) · [§22 容灾](./高频对比速查表.md#22-容灾等级对比简要) · [§23 范式](./高频对比速查表.md#23-数据库范式对比)

### RAID 与网络存储

- **RAID0** 无冗余；**RAID1** 镜像约 50% 容量；**RAID5** 1 盘容错；**RAID10** 镜像+条带。
- **DAS** 直连 · **NAS** 文件级/IP · **SAN** 块级/FC。

### 备份与容灾

- **完全 / 增量 / 差异**：空间 vs 恢复链长度。
- **RPO** = 允许多少**数据丢失**；**RTO** = 允许多久**恢复业务**。

### 访问控制与安全模型

| 模型 | 记法 |
|------|------|
| **DAC** | 自主，属主授权 |
| **MAC** | 强制，安全标签 |
| **RBAC** | **角色**授权 |
| **BLP**（保密） | **不上读、不下写** |
| **Biba**（完整） | **不上写、不下读** |

### 加密（§20 摘要）

- **对称**：快，适合大数据量；**非对称**：密钥交换/数字签名。
- **摘要**：防篡改；**数字签名** = 摘要 + 私钥签。

### 范式

**1NF** 原子 · **2NF** 消部分依赖 · **3NF** 消传递依赖 · **BCNF** 更强（主属性不依赖非超键）。

**练手**：第 3、5、9 章；计算题：子网/Cache/可靠性可另见 [数学白话卡](./前端友好-数学白话卡.md)。

## 第 1 天 · 挣值 · 信息化 · 案例论文（T−1）

> 对照：[§27 挣值](./高频对比速查表.md#27-项目管理挣值对比) · [§11 BPR/ERP](./高频对比速查表.md#11-bpr--erp--crm--scm-对比) · [近五年论文范围](./近五年论文范围分析.md)

### 挣值（必会公式）

| 符号 | 含义 |
|------|------|
| **PV** | 计划值 |
| **EV** | 挣值（已完成工作的预算） |
| **AC** | 实际成本 |
| **SV = EV − PV** | 进度偏差（&lt;0 滞后） |
| **CV = EV − AC** | 成本偏差（&lt;0 超支） |
| **SPI = EV/PV** | 进度绩效 |
| **CPI = EV/AC** | 成本绩效（&lt;1 不好） |

**进度压缩**

- **赶工 crashing**：加资源压**关键活动**工期（通常增成本）。
- **快速跟进 fast tracking**：**重叠**原串行活动（增风险）。

**其他**：**范围蔓延** = 未控变更导致范围无声扩大；**资源平衡** = 在时差内调资源。

### 企业信息化

- **BPR** 流程再造 · **ERP** 资源集成 · **CRM** 客户 · **SCM** 供应链。
- **EAI 层次**：数据 → 应用 → 界面 → **过程**集成（由浅到深）。
- **遗留系统演化**：**淘汰 / 继承 / 改造 / 集成**（按成本、风险、停机约束选）。

### 案例 / 论文「少而精」句（背结构不背长文）

| 场景 | 答题要点 |
|------|----------|
| 需求冲突 | 排**优先级** + **业务规则** + 分层方案 + **书面确认** |
| Web 高并发 | **缓存 + 限流 + 异步** + **灰度** + **幂等** + 对账 |
| 分布式副作用 | 主路径快速返回，**领域事件异步**消费（非关键路径） |
| 论文摘要 | 约 **300～400 字**：背景、系统规模、**本人角色**、论点与结论 |

**练手**：第 8 章挣值计算；案例库 P0 域；论文见 `论文范文/…/00-统一结构记忆卡.md`。
