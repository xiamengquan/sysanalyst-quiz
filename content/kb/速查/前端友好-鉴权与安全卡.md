# 速查 · 鉴权与前端安全

## 登录与授权

| 概念 | 白话 |
|------|------|
| Cookie + Session | 浏览器持 ID，服务器认人 |
| JWT | 自带信息的令牌（仍要校签名、控过期） |
| OAuth | 第三方授权，不交密码 |
| HTTPS | 传输加密，防偷密码 |

## 前端三连坑

| 风险 | 成因 | 防护 |
|------|------|------|
| XSS | 输入当 HTML/JS 执行 | 转义、CSP |
| CSRF | 异站借 Cookie 发请求 | Token、SameSite |
| 乱跨域 | 浏览器同源策略 | 服务器 CORS 头 |

## 同源

协议 + 域名 + 端口 都相同才同源。
