## 概述

**开发（容器、注册发现、通信、安全、监控）**：- 服务多、依赖链长 - 需契约测试（Consumer-Driven Contract） - 需测试替身（Mock/Stub）与测试容器 - 分布式环境搭建复杂。

## 定义

- 契约测试（答卷·定义）：契约测试（Consumer-Driven Contract）是由消费方定义期望的 API 契约、由提供方验证是否满足的测试方式；用于在微服务独立发布时保障接口兼容性，减少集成阶段才发现的接口不匹配。
- **契约测试（答卷·定义）**：契约测试（Consumer-Driven Contract）是由消费方定义期望的 API 契约、由提供方验证是否满足的测试方式；**用于**在微服务独立发布时保障接口兼容性，减少集成阶段才发现的接口不匹配。

## 要点

### 3.1 测试特点

- 服务多、依赖链长
- 需契约测试（Consumer-Driven Contract）
- 需测试替身（Mock/Stub）与测试容器
- 分布式环境搭建复杂

### 3.2 测试过程与类型

**过程**：单元（单服务）→ 集成（服务间）→ 端到端 → 性能 → 容错 → 安全

| 类型 | 要点 |
|------|------|
| 功能 | API 正确性、业务规则 |
| 性能 | 单服务与链路延迟、吞吐 |
| 容错 | 熔断、降级、故障注入 |
| 安全 | 认证授权、传输加密、漏洞扫描 |
